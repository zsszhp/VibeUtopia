阶段 3 实现：模型优化 + 人生故事生成

新增功能：
- 多模型路由系统：支持 Qwen-VL, DeepSeek-VL, GLM-VL等多模态 API
- 阿里 Paraformer 音频转写 API 接入
- 硬件自动检测：根据 GPU/VRAM推荐模型级别
- 人生故事驱动人格系统（A/B/C三级）：
  * A-tier: AI访谈生成器（6 轮结构化访谈→数万字人生故事）
  * B-tier: CGSS 采样+LLM丰富（人口统计采样→千字故事）
  * C-tier: 模板变体（原型模板 + 随机参数→百字梗概）
- ChromaDB 向量检索接入（替代 Milvus）
- Memory Stream 记忆存储与三因子检索（Recency+Importance+Relevance）
- 人格质量验证流水线（7 维度+Big Five 一致性检查）
- 模型运行时覆盖：支持强制指定厂商和模型
- 多 Key 智能调度：配额耗尽自动切换

新增 API：
- POST /api/v3/analyze-multimodal - 多模态内容分析
- POST /api/v3/upload-image-analyze - 上传图片分析
- POST /api/v3/transcribe-audio - 音频转写
- POST /api/v3/generate-persona - 人格生成
- POST /api/v3/generate-persona-batch - 批量人格生成
- POST /api/v3/retrieve-memory - 向量检索记忆
- POST /api/v3/store-memory - 存储记忆
- GET /api/v3/hardware-info - 硬件信息
- GET /api/v3/recommended-models - 推荐模型列表
- GET /api/v3/available-models - 所有可用模型
- GET /api/v3/model-status - 模型 Key 池状态
- POST /api/v3/set-model-override - 设置模型覆盖
- GET /api/v3/llm-test - 测试 LLM 调用

配置文件：
- config/model_config.yaml - 多模型路由配置
- .env.example - 更新 API Key 配置项

技术改进：
- 模型配置路径修正为 config/model_config.yaml
- 默认 provider 改为 aliyun（支持多模态）
- 新增硬件检测服务自动推荐模型级别
- ChromaDB 内嵌式部署，降级为数据库检索
- 人格生成质量自动验证和修复
