# 阶段 3：模型优化 + 人生故事生成

## 阶段目标

基于阶段 2 的完整人格画像（32 个原型 + 5 个平台人格 + 完整价值观体系），实现以下核心功能：

1. **LLM 模型优化**：使用 LoRA 微调 LongCat 模型，提升风险评估准确率和人格推理能力
2. **人生故事生成**：基于人格画像，自动生成个体的人生关键节点故事
3. **人格演化模拟**：模拟个体在不同阶段的人格变化和成长轨迹

## 核心功能模块

### 1. LLM 模型微调（T6）

#### T6.1 LoRA 微调实现
- **目标**：在 LongCat-Flash-Thinking-2601 基础上进行 LoRA 微调
- **训练数据**：使用回测案例库（33 个案例）+ 人格画像数据
- **微调重点**：
  - 风险等级判断准确性（目标：red 类准确率从 57% 提升至 80%+）
  - 人格原型识别一致性
  - 价值观维度推理逻辑
- **输出**：微调后的模型权重文件（`models/lora_adapter/`）

#### T6.2 推理引擎集成
- **模型加载**：在 `backend/services/llm_service.py` 中集成 LoRA 适配器
- **推理模式切换**：支持基础模式（原生长猫）和微调模式（LoRA 增强）
- **缓存机制**：对高频推理结果进行缓存（Redis）
- **API 端点**：`POST /api/v1/risk/assess` 支持 `model_version` 参数

### 2. 人生故事生成（T7）

#### T7.1 人生时间线构建
- **输入**：完整人格画像（32 原型 + 5 平台人格 + 价值观体系）
- **生成逻辑**：
  - 根据 MBTI 类型和 Enneagram 类型推导关键人生决策模式
  - 结合 Big Five 特质推导职业发展路径
  - 结合依恋类型推导重要关系节点
- **时间线结构**：
  - 童年期（0-12 岁）：原生家庭影响、早期创伤/滋养
  - 青少年期（13-18 岁）：身份认同、价值观形成
  - 成年早期（19-35 岁）：职业选择、亲密关系
  - 成年中期（36-55 岁）：事业巅峰/转型、家庭责任
  - 成年晚期（56 岁+）：传承、意义整合
- **输出**：`data/stories/{user_id}/timeline.json`

#### T7.2 关键场景故事生成
- **场景类型**：
  - 转折点（重大决策时刻）
  - 挑战期（困难与突破）
  - 高光时刻（成就与认可）
  - 关系节点（重要他人相遇/分离）
- **生成方式**：
  - LLM 基于人格特质生成场景描述（800-1500 字）
  - 融入认知扭曲模式和防御机制
  - 体现价值观冲突与选择
- **输出**：`data/stories/{user_id}/scenes/{scene_id}.md`

#### T7.3 人生叙事整合
- **叙事弧线**：英雄之旅 / 成长弧线 / 悲剧弧线（根据人格特质自动选择）
- **主题提炼**：从人生故事中提取核心主题（如"寻找归属"、"超越创伤"、"追求意义"）
- **输出格式**：
  - 完整人生故事（`data/stories/{user_id}/life_story.md`）
  - 精简版传记（500 字，用于展示）
  - 主题解读（心理分析视角）

### 3. 人格演化模拟（T8）

#### T8.1 演化触发事件库
- **事件类型**：
  - 正向事件：成就、认可、爱的获得、自我实现
  - 负向事件：失败、丧失、创伤、背叛
  - 中性事件：迁徙、职业转换、关系变化
- **事件影响矩阵**：不同人格原型对不同事件的情感反应模式
- **存储**：`data/events/trigger_events_db.json`

#### T8.2 人格特质动态调整
- **调整规则**：
  - 连续性创伤 → Neuroticism 提升
  - 持续性成就 → Extraversion/Conscientiousness 提升
  - 关系丧失 → Attachment 类型可能转变（安全→焦虑/回避）
  - 价值观冲击 → Moral Foundations 权重调整
- **演化算法**：基于贝叶斯更新的人格特质后验分布调整
- **时间粒度**：支持按年/按月模拟

#### T8.3 多阶段人格画像对比
- **输入**：初始人格画像 + 演化事件序列
- **输出**：
  - 不同阶段的人格画像快照（`data/evolution/{user_id}/stage_{n}.json`）
  - 特质变化曲线图（可视化）
  - 关键转折点分析（哪些事件导致了显著变化）
- **可视化**：人格雷达图对比、时间轴演化图

## 验收标准

### T6 微调验收
- [ ] 使用 33 个回测案例进行测试，综合准确率≥75%（当前基线 69%）
- [ ] red 类（高风险）识别准确率≥80%（当前基线 29%）
- [ ] green 类（低风险）识别准确率≥95%（保持当前水平）
- [ ] 单次推理响应时间≤15 秒（与基础模型相比延迟增加不超过 30%）

### T7 故事生成验收
- [ ] 生成的人生时间线包含≥5 个人生阶段，每个阶段≥3 个关键事件
- [ ] 关键场景故事字数在 800-1500 字范围内
- [ ] 故事内容体现人格特质一致性（心理学专家审核）
- [ ] 支持至少 3 种叙事弧线选择

### T8 演化模拟验收
- [ ] 支持模拟≥10 种不同类型的触发事件
- [ ] 人格特质调整符合心理学理论（专家审核）
- [ ] 演化前后人格画像对比报告完整
- [ ] 可视化图表正确生成

### 整体验收
- [ ] 所有 API 端点通过 Postman 测试
- [ ] 单元测试覆盖率≥80%
- [ ] 完成 10 个完整案例的端到端测试（从人格画像到人生故事到演化模拟）
- [ ] 文档完整且准确

## 开发优先级

1. **T7 人生故事生成**（核心用户价值，独立于微调）
2. **T6 LLM 模型微调**（依赖 API 配额，可并行准备训练数据）
3. **T8 人格演化模拟**（依赖前两者完成）

## 风险与依赖

### 风险
- **API 配额限制**：LoRA 微调需要大量 API 调用，可能受限于双 Key 配额
- **训练数据不足**：33 个案例可能不足以支撑高质量微调
- **故事生成质量**：LLM 生成的故事可能缺乏心理学深度

### 应对措施
- **LoRA 微调**：优先使用 LoRA 轻量级微调（而非全量微调），减少训练数据需求
- **数据增强**：使用现有案例进行数据增强（改写、扩展、变体）
- **质量审核**：引入心理学专家对生成故事进行人工审核和评分

## 时间估算

- **T6 微调**：3-4 天（数据准备 1 天 + 训练 1-2 天 + 集成 1 天）
- **T7 故事生成**：2-3 天（时间线 1 天 + 场景生成 1 天 + 整合 1 天）
- **T8 演化模拟**：2-3 天（事件库 1 天 + 演化算法 1 天 + 可视化 1 天）
- **测试与验收**：1-2 天
- **总计**：8-12 天

## 备注

- 阶段 3 完成后，系统应具备完整的人格画像→人生故事→演化模拟能力
- 微调后的模型应显著提升风险识别准确率，特别是 red 类识别
- 人生故事生成功能可作为独立产品功能对外提供服务
