## 架构约束

### Python 后端
- **异步优先**：使用 `async/await`，避免同步阻塞
- **依赖注入**：Service 层通过参数注入，不使用全局变量
- **配置管理**：通过 `pydantic-settings` 读取环境变量
- **数据库会话**：使用 context manager 或 dependency 注入

### 前端 Vue
- **Composition API**：`<script setup>` 语法
- **TypeScript**：禁止 `any`，使用泛型和接口
- **状态管理**：Pinia Store 集中管理共享状态
- **组件规范**：PascalCase 命名，props 校验

## 代码质量

### 禁止
- 禁止硬编码业务参数（阈值、超参等通过配置文件管理）
- 禁止 TODO/FIXME 遗留不处理
- 禁止硬编码路径（使用环境变量或相对路径）
- 禁止重复代码（抽离工具函数和公共组件）

### 必须
- 所有外部调用必须加 try/catch 和超时
- 关键函数必须有文档字符串
- 日志记录关键操作
- 输入校验和 sanitize

## 注释规范

- **注释说明"为什么"**：代码本身说明"做什么"
- **关键算法必须注释**：复杂逻辑、设计决策
- **类和公共 API 必须有文档**：说明用途、参数、返回值

## 性能要求

- **数据库查询**：使用索引，避免 N+1 查询
- **外部 API**：并发请求，合理超时
- **前端渲染**：大列表虚拟化，避免重复渲染
- **内存泄漏**：及时释放资源，禁用未使用的定时器

## 错误处理

- **向上传播**：禁止静默吞异常
- **分级处理**：WARNING（可恢复）→ ERROR（需关注）→ CRITICAL（需报警）
- **用户通知**：关键错误必须反馈给用户

## 安全要求

- **输入校验**：所有用户输入必须校验
- **SQL 注入**：使用 SQLAlchemy ORM，不用原始 SQL
- **XSS**：前端对渲染内容做 sanitize
- **敏感信息**：禁止硬编码，存储在 .env
