- 新增 UI 必须与 Naive UI + TailwindCSS 的设计体系一致，禁止冲突的自定义样式
- 布局用 Flex/Grid，禁止绝对定位，适配 1920×1080
- 所有操作必须有视觉反馈（成功/失败/加载中），耗时操作显示加载提示，禁止无反馈阻塞
- 状态颜色：正常=绿、警告=黄、错误=红、禁用=灰，沿用项目色彩体系
- 确认按钮右侧、取消按钮左侧；危险操作二次确认弹窗默认聚焦取消
- 图标用项目已有图标库，禁止引入外部未审核图标
- 弹窗居中，错误提示含解决方案而非仅错误代码
- 大列表必须虚拟化渲染，避免性能问题
- 响应式设计：核心页面适配 1280px~1920px 宽度
