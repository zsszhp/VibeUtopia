# VibeUtopia 测试用例目录

## 目录结构

```
test/
  paperwork/          # 正式测试案例（手工编写的真实案例文案）
  video_transcript/   # 视频转写文本（B站等平台视频的ASR转写结果，用于转写质量检测验证）
  link/               # 视频链接测试（用于视频提取功能测试）
```

## 文件命名规范

- paperwork: `{简要事件描述}.md`，如 `网红小英卖惨塌房.md`、`张雨绮代孕风波.md`
- video_transcript: `{BV号}.md`，如 `BV1mVSUBrEz5.md`
- 文件名不超过15个汉字，避免特殊符号
