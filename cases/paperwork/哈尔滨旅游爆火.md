# 案例：哈尔滨旅游"讨好型市格"爆火

2023 年冬，哈尔滨旅游在社交媒体上现象级爆火。当地政府和市民展现出的"讨好型市格"引发网友热情追捧。

正面亮点：
- 冻梨切盘、豆腐脑加糖等"宠客"操作
- 志愿者免费接送游客
- 政府快速响应投诉（出租车宰客立即处理）
- 市民自发让路、让景给游客
- 冰雪大世界退票事件快速解决

争议点：
- 部分网友质疑"本地人被区别对待"
- "讨好型市格"是否可持续
- 商家涨价投诉偶有发生
- 热度退去后的隐忧

舆情走向：整体高度正面，被称为"政通人和"的典范。但也引发了对"网红城市"可持续性和"本地人权益"的讨论。

**实际结果**：
- 舆情方向：整体正面，少量争议
- 影响平台：抖音、小红书、微博、B 站
- 持续时间：约 3 个月（冬季旅游季）
- 关键群体：游客、本地居民、旅游爱好者
