## 1. 产品定位与价值主张

### 1.1 核心问题（不变）

网红因视频内容、言行不当「塌方」。发布前缺乏：多平台反应预判、红线识别、可操作的修改建议。

### 1.2 价值主张（强化「不压抑创意」）

| 主张 | 产品表达 |
|------|----------|
| **先看见雷** | 句级/秒级证据定位，而不是笼统低分 |
| **改得动** | 每条高风险至少 2 个保留原意的安全改写 |
| **敢决策** | 明确「可发 / 改后可发 / 建议缓发 / 不建议发」+ 置信度 |
| **不越权** | 只提示较高风险，不否定创意；说明预测不确定性 |

### 1.3 北极星指标

**周活跃创作者有效风险拦截数（ERB）**：创作者在发布前采纳系统提示并完成规避/修改的风险条目数。

支撑指标：
- 改写采纳率
- 风险避免确认率（事后回访/自评）
- 首次价值时间（TTFV ≤ 10 分钟）
- 7 日留存

## 2. 用户画像与分阶段策略

### 2.1 主画像（P0）

**中小创作者 / 区域 UP 主 / 知识区与生活区博主**
- 场景：脚本写完、剪辑完成，发布前最后检查
- 痛点：怕踩政治/性别/地域/广告法红线；怕被断章取义
- 非目标：不需要复杂仿真大屏，需要「能不能发」答案

### 2.2 扩展画像

| 阶段 | 用户 | 关键能力 |
|------|------|----------|
| P1 | MCN 编审 | 多账号、批量、审核工作流、留痕 |
| P2 | 品牌投放 | 博主/内容尽调报告 |
| P3 | 平台审核辅助 | 批量筛查、人机协同 |

## 3. 核心用户旅程（V5 To-Be）

```
[输入] 粘贴文案 / 上传视频 / 混合
   ↓  字数提示·文件校验·平台选择（可选）
[深度] 快速 60s | 标准 3min | 深度 10min   ← 显示代价（时长/成本/Agent规模）
   ↓
[分析] 流水线进度 + 阶段 ETA + 可取消 + 失败可重试（断点续传）
   ↓
[结论] ★ Verdict Banner：能否发布 + 总分 + 一句话
   ↓
[下钻] 风险句/秒 · 证据 · 为什么 · 置信度 · 不确定性
   ↓
[行动] 采用改写 / 一键替换 / 调整后再验
   ↓
[复验] 对比前后分数与风险条目（History Comparison）
```

## 4. 功能全景（修订后的优先级）

### 4.1 P0 · 信任与闭环（V5.1，本轮主实施）

| 模块 | 需求 | 验收 |
|------|------|------|
| Verdict Banner | 顶部显著结论：等级词 + 总分 + 建议句 | 3 秒内可决策 |
| 证据下钻 | 点风险 → 原句/时间码 + 理由 | PRD 可解释承诺落地 |
| 改写闭环 | 改写建议 → 一键复验 → 前后对比 | 全链路无死链 |
| 状态与错误 | 全局错误可见、上传失败可重试、分析中不可重复提交 | 无静默失败 |
| 设计系统 | tokens + Naive 暗色 + 风险阈值统一 30/60/80 | 视觉一致 |
| 死功能接线 | 历史对比/博主/图谱/信号 入口 | 手册功能可找到 |
| 启动与文档 | 一键启动、真实 API 文档、/health | 新人 10 分钟跑通 |
| 测试门禁 | pytest 可一键运行并绿 | 回归有保障 |

### 4.2 P1 · 可信与度量（V5.2）

| 模块 | 说明 |
|------|------|
| 评测集回归 | 25+ 黄金案例自动回测；valid_accuracy + valid_ratio 双口径 |
| 成本计量 | 每次分析 token/费用/耗时落库；成本口径统一 |

### 4.3 P1.5 · 视频理解升维（V5.3，战略）

见 docs/02_系统设计/31：事件层/叙事弧/多时尺/选段智能体/细粒度猎手层。

### 4.4 P2 · 原始需求闭环深化

## 6. 14 维风控体系（核心11+扩展3，强化表达）

红线 5：政治敏感、法律合规、民族宗教、事实错误、平台禁区  
高敏感 4：性别议题、群体冒犯、道德伦理、时事踩雷  
动态 2：情绪极化、价值观倾向

扩展 3：未成年人保护、隐私侵犯、知识产权  

**产品化要求：**
1. 每个维度：分数、等级、触发句/秒、依据、置信度
2. 等级词统一中文：安全 / 需留意 / 较高风险 / 高风险（红）
3. 阈值全局唯一：30 / 60 / 80
4. 红线维度触碰即升高优先级，并在 Verdict 中置顶

├─────────────────────────────────────────────┤

│ 世界层  知识图谱 · 人格 · 记忆（增强，非主链）    │

关键产品约束：
- 仿真默认「够用就好」，大规模仿真仅在用户显式选择
- 所有增强能力必须能回答：「对『能不能发』改变了什么」

## 9. 风险与边界

1. **法律边界**：产品是「风险提示」不是「法律意见」；需免责与留痕
2. **伪精确风险**：仿真数字必须带不确定性说明
3. **误报伤创意**：提供「忽略并记录」反馈回路，优化校准
4. **内容安全**：产品自身不得生成违规内容；改写建议需过红线复核

## 10. 成功标准（V5.1 验收）

| 指标 | 目标 |
|------|------|
| TTFV | 新用户 ≤10 分钟完成首次有效预审 |
| 主闭环完成率 | ≥90%（输入→看到 Verdict→完成至少一次改写或确认） |
| 3 秒决策 | 可用性测试中 5/5 用户能复述「能不能发、为什么」 |
| 静默失败 | 0（所有错误可见可恢复） |
| 测试 | pytest 一键绿；关键路径 smoke 通过 |
| 文档 | README 快速启动 10 分钟可复现 |
