# VibeUtopia 产品需求文档 (PRD)

## 1. 项目愿景与目标
构建一个面向内容创作者的**发布前文本风控与内容评估平台**。在博主发布文案、视频脚本前，通过模拟多平台真实用户的反应，预测舆论风险（如性别歧视、价值观争议等高压线），避免翻车，同时提供改写建议。

## 2. 演进路线规划 (短长期规划)

### 2.1 短期目标：MVP阶段 (最小可行性产品)
**核心策略**：快速跑通核心闭环，用最轻量的技术（本地部署、直接调LLM）实现高效的风控评估，同时满足“结合现实世界”的要求。
- **输入**：纯文本/脚本文案。
- **核心逻辑**：
  1. **现实映射**：轻量化爬取现实世界（小红书/知乎/B站/抖音）的热点与典型评论数据，作为语料喂给系统。
  2. **LLM角色扮演**：使用 DeepSeek 或 阿里云 模型，结合爬取的真实语料作为上下文，动态模拟四大平台的用户真实反应。
  3. **专业评估**：进行 7 个维度的风险评估，输出 0-100 分风险分。
- **输出**：句子级风险点、平台反应预测、总体评分、修改建议。

### 2.2 长期目标：V2 深度服务与完整仿真
- **多Agent社会级仿真**：当MVP验证成功后，引入类似 OASIS 的完整多Agent框架，进行更复杂的社交裂变模拟。
- **博主深度服务**：结合博主历史数据，推荐选题、预测流量。
- **竞品对标分析**：深挖对标账号，拆解成功要素。
- **视频内容解析**：支持直接上传视频进行多模态分析。

## 3. MVP 阶段详细需求

### 3.1 风险评估流水线
- **单次评估**：用户输入文案，系统返回多维度的评估报告。
- **句子级定位**：精确定位可能引发争议的句子，打上风险标签，并保留原文引用。
- **多平台视角预测**：区分 B站（二次元/年轻化）、小红书（女性/种草）、知乎（逻辑/思辨）、抖音（下沉/泛娱乐）的用户情绪倾向。
- **发布建议与改写**：给出“可发/建议修改/不建议发”综合判断，并对高风险句子提供2个保留原意的安全改写版本。

### 3.2 现实增强的 Agent 人格构建
为了满足“尽可能仿真现实世界去完善Agent人格”，MVP阶段的构建机制设计如下：
1. **真实数据抓取**：定时或触发式从各平台抓取热榜事件及高赞/争议评论。
2. **上下文动态注入**：在 LLM 扮演某个平台用户群体时，将近期该平台的真实评论情绪、流行梗、敏感点作为 Prompt 上下文动态注入。
3. **人格特征动态演化**：基于真实世界的舆论风向（例如近期某个热点翻车事件），LLM能够自适应调整对某些词汇或议题的敏感度。

## 4. 核心维度定义 (7维风险体系)
1. **政治敏感**（涉政、领土、外交红线）
2. **性别议题**（性别对立、物化歧视）
3. **民族宗教**（民族歧视、宗教冒犯）
4. **道德伦理**（违背公序良俗、主流价值观冲突）
5. **法律合规**（广告法、侵权、虚假宣传）
6. **群体冒犯**（地域黑、职业歧视、年龄歧视）
7. **时事踩雷**（不当蹭热点事件、翻车事件波及）
