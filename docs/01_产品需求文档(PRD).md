# VibeUtopia 产品需求文档 (PRD)

## 1. 项目愿景

**构建一个高保真平行数字世界，让数千个具备独立人格、长期记忆与行为逻辑的智能体自由交互与社会演化，最终实现预测未来走向、辅助决策。**

VibeUtopia 不仅仅是内容风控工具，而是一个"社会模拟器"——它从现实世界采集种子信号，构建出完整的平行数字社会，让AI Agent扮演不同身份、立场、性格的"数字市民"自由互动，观察舆论如何裂变、情绪如何蔓延、立场如何极化，从而**在事件发生之前就看到可能的未来**。

## 2. 产品定位与核心价值

### 2.1 为什么世界需要 VibeUtopia

在信息爆炸时代，一条内容、一个决策可能引发意想不到的舆论风暴。传统方法（人工经验、简单关键词审核）无法应对：
- **舆论的复杂性**：同一事件在不同平台、不同群体中引发截然不同的反应
- **传播的非线性**：一个普通帖子可能因为关键节点人物的转发而瞬间引爆
- **立场的不确定性**：看似无害的内容可能触碰到特定群体的敏感神经
- **决策的紧迫性**：舆论爆发后，每一分钟的应对策略都影响最终结果

VibeUtopia 的核心价值：**在真实事件发生或内容发布之前，通过仿真推演看到可能的未来，从而做出更好的决策。**

### 2.2 核心价值主张

| 价值 | 描述 |
|------|------|
| **预见性** | 在事件发生前预测舆论走向，而非事后分析 |
| **高保真** | 仿真结果逼近真实世界，而非简单的情绪标注 |
| **可干预** | 不仅能预测，还能推演不同应对策略的效果 |
| **可解释** | 每个预测都有完整的传播路径和因果链可追溯 |

## 3. 用户画像

### 3.1 核心用户

| 用户类型 | 典型场景 | 核心需求 |
|----------|----------|----------|
| **内容创作者** | 发布前检查文案风险，优化内容策略 | 句子级风险标注、改写建议、各平台反应预测 |
| **品牌公关** | 危机预警、应对策略推演 | 舆论传播预测、反事实仿真、最优应对策略 |
| **政策研究者** | 政策草案的社会影响评估 | 大规模Agent仿真、立场分化预测、群体反应分析 |
| **社会学者** | 社会动力学研究、群体行为建模 | 仿真参数控制、传播网络分析、Agent行为追溯 |
| **投资决策者** | 金融信号→社会反应→市场影响链路 | 突发事件仿真、市场情绪预测、黑天鹅事件推演 |

### 3.2 用户旅程

**旅程1：内容创作者的日常风控**
1. 写完一篇文案，粘贴到 VibeUtopia
2. 系统即时返回：7维风险评估、各平台反应预测、高风险句标记
3. 对高风险句，查看改写建议，一键生成安全版本
4. 如需深入了解，启动"社会仿真"模式，观察该文案在不同平台上的传播路径

**旅程2：品牌公关的危机应对**
1. 收到预警：某话题正在微博发酵
2. 在 VibeUtopia 中输入种子事件，启动24小时仿真
3. 观察舆论传播路径：哪些大V会表态？评论区如何分化？会不会上热搜？
4. 推演3种应对策略：沉默/回应/道歉，各运行一个仿真分支
5. 对比结果，选择最优策略和时机

**旅程3：政策研究者的社会影响评估**
1. 输入一份政策草案文本
2. 生成1000个覆盖各阶层/地域/行业的Agent
3. 运行72小时仿真，观察不同群体的反应
4. 识别最大争议点和潜在反对势力
5. 生成社会影响评估报告

**旅程4：投资决策者的黑天鹅推演**
1. 系统检测到金融信号（如"A股大跌3%"）
2. 自动触发仿真，生成不同类型投资者的反应
3. 预测市场情绪走向和潜在连锁反应
4. 推演不同政策干预的效果

**旅程5：博主的深度运营**
1. 输入B站/抖音账号链接，系统分析历史视频
2. 生成博主风格画像：常用词汇、表达风格、内容主题偏好
3. 结合当前热点，推荐选题和切入点
4. 预测每个选题的预期流量和风险
5. 对标竞品账号，分析差异化机会

### 4.2 信号采集模块

**目标**：从现实世界提取种子信息，作为平行世界的输入

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 多源热榜聚合 | 聚合微博/B站/知乎/抖音等11+平台热搜，统一格式 | P0 |
| RSS深度源 | 接入财经/科技/国际等RSS源，补充热点深度 | P1 |
| 定向评论爬取 | 根据热点关键词，爬取各平台高赞/争议评论 | P0 |
| 情感标注 | 对爬取的评论进行正/负/中性+强度标注 | P0 |
| 事件检测与关联 | 识别同一事件在不同平台的表现，自动关联 | P1 |
| 信号强度评估 | 根据上榜速度/排名变化/多平台共振评估信号强度 | P1 |
| 因果链推理 | 推理事件间的因果关系（A事件导致B事件） | P2 |
| 定时调度 | 灵活配置采集频率和模式（实时/定时/手动） | P0 |

### 4.3 世界构建模块

**目标**：从种子事件构建完整的高保真平行数字世界

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 知识图谱引擎 | 从种子文档自动构建实体-关系图谱（Neo4j） | P0 |
| 7层人格生成 | 生成具备7层独立人格结构的Agent Profile | P0 |
| 批量人格生成 | 支持一次生成100-1000个差异化Agent | P0 |
| 社会关系网络 | 基于Agent属性构建关注/社群/对立关系网络 | P1 |
| 长期记忆系统 | 三层记忆架构（工作/情景/语义），支持检索和遗忘 | P1 |
| 人格动态演化 | Agent人格随重大事件和时间自然演化 | P2 |
| 世界状态持久化 | 平行世界状态的存储、版本管理、回溯 | P1 |

### 4.4 社交仿真模块

**目标**：让千级Agent在模拟社交平台上自由交互

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 三层Agent架构 | 协调Agent(3-5) + 市民Agent(1000+) + 功能子Agent | P0 |
| Agent行为决策 | 感知→思考→行动→反馈 的自主决策循环 | P0 |

| 舆论裂变模拟 | 从小众争议到大众舆论的5阶段传播模型 | P1 |

### 4.5 预测决策模块

## 5. 七维风险体系定义

### 5.1 维度详情

| 维度 | 定义 | 典型触发场景 | 严重度分级 |
|------|------|-------------|-----------|
| **1. 政治敏感** | 涉及政治人物、领土主权、外交关系等红线话题 | 不当评价政策、触及领土争议、调侃政治人物 | 🔴 任何触及均属高风险 |
| **2. 性别议题** | 性别对立、物化歧视、刻板印象强化 | 强化性别刻板印象、挑动性别对立、物化任何性别 | 🟡 依语境而定，对立性内容升级为🔴 |
| **3. 民族宗教** | 民族歧视、宗教冒犯、文化禁忌 | 不当引用宗教符号、地域歧视隐射民族问题 | 🔴 任何触及均属高风险 |
| **4. 道德伦理** | 违背公序良俗、与主流价值观冲突 | 鼓励不道德行为、挑战社会底线 | 🟠 依严重程度分级 |
| **5. 法律合规** | 广告法违规、侵权、虚假宣传 | 绝对化用语、未标注广告、虚假功效宣传 | 🟠 法律红线不可触碰 |
| **6. 群体冒犯** | 地域黑、职业歧视、年龄歧视 | "某省人都XXX"、贬低特定职业群体 | 🟡 依群体敏感度分级 |
| **7. 时事踩雷** | 不当蹭热点、关联翻车事件 | 在敏感事件期间发布可能被关联的内容 | 🟡 随时事热度动态变化 |

## 6. 产品能力指标

| 能力 | 指标 | 目标值 |
|------|------|--------|
| 信号采集延迟（热榜） | 从热搜上线到系统捕获 | < 5分钟 |
| 信号采集延迟（深度） | 从事件识别到评论爬取完成 | < 30分钟 |
| 世界构建速度 | 从种子事件到1000个Agent就绪 | < 30分钟 |
| 仿真速度 | 1000 Agent × 24小时仿真完成时间 | < 30分钟 |
| 风险评估延迟 | 单次文案评估响应时间 | < 30秒 |

| 人格一致性 | 同Agent在相似场景下行为相关性 | > 0.8 |
| LLM仿真成本 | 单次完整仿真的LLM调用费用 | < ¥5 |
| 系统可用性 | 服务正常运行时间 | > 99% |

## 7. 演进策略

### 7.1 MVP → V2 演进逻辑

```
MVP (已完成)                    V2 (蓝图)
─────────────                  ──────────────
静态Prompt人格         →       7层独立人格 + 动态演化
单LLM直接调用          →       LiteLLM多模型分层
4平台文本模拟          →       5平台社交仿真引擎
句子级风险评估          →       全链路舆论仿真 + 趋势预测
手动输入文案           →       自动信号采集 + 事件检测
SQLite + 静态语料      →       MySQL + Neo4j + Milvus + Redis
Streamlit前端          →       Vue3 + ECharts + D3.js
```

### 7.2 阶段核心假设与验证目标

| 阶段 | 核心假设 | 验证目标 |
|------|----------|----------|
| MVP (已完成) | LLM角色扮演能产生有价值的平台反应预测 | 用户是否觉得评估结果有帮助？ |
| V2.1 信号采集 | 实时热搜聚合能提供足够的"现实感" | 采集的信号是否与用户感知的热点一致？ |
| V2.2 世界构建 | 7层人格结构能产生比静态Prompt更真实的反应 | Agent行为是否比MVP的静态人格更可信？ |
| V2.3 社交仿真 | 千级Agent交互能涌现出与真实舆论相似的模式 | 仿真中的舆论传播路径是否与现实相似？ |
| V2.4 裂变传播 | 舆论裂变模型能准确预测传播范围和速度 | 预测的热搜事件是否真的上了热搜？ |
| V2.5 预测决策 | 反事实仿真能帮助选择更优应对策略 | 推荐的策略是否确实优于其他选项？ |

### 7.3 风险与缓解

| 风险 | 概率 | 影响 | 缓解策略 |
|------|------|------|----------|
| LLM成本过高 | 中 | 高 | 分层使用+本地小模型+批处理 |
| 仿真结果不可信 | 高 | 极高 | 多次仿真取共识+历史回测验证+不确定性标注 |
| 爬虫被封 | 高 | 中 | API优先+代理池+多源冗余 |
| Agent行为失控 | 低 | 高 | Guardian Agent监控+行为边界约束 |
| 知识图谱质量低 | 中 | 中 | 人工审核入口+LLM质量校验+增量优化 |
