# VibeUtopia 产品需求文档 (PRD)

## 文档定位
- 本文档在主线中的角色：定义产品目标、边界、核心功能与验收标准
- 与"发前风控优先"的关系：PRD是产品风控目标的源头，所有功能必须回答"是否提升风险判断准确率"

## 本文档边界
- 本文档负责：产品目标、唯一用户入口、核心流程、准确率指标、功能优先级
- 本文档不负责：技术架构细节（见`02_系统架构设计.md`）、实施计划（见`03_MVP实施计划.md`）、路线图（见`04_V2深化路线图.md`）

## 对准确率的直接贡献
- 机制1：定义7维风险评估体系，确保风险识别有结构化标准
- 机制2：定义准确率/漏报率/误报率指标，使改进可量化
- 验证方式：回测案例对比、用户反馈

---

## 1. 项目愿景

**博主发布视频/文案前，模拟多平台用户反应，预测舆论风险，避免翻车。**

VibeUtopia 是一个**内容发前风控工具**：博主将待发布的内容（视频/文案）提交到系统，系统自动理解内容，在多个社交平台上模拟不同用户群体的反应，预测可能出现的舆论风险，并给出具体修改建议。

> 仿真是增强模块，不是独立产品主线。所有能力围绕"让风控更准"展开。

## 2. 产品定位与核心价值

### 2.1 核心问题

博主发布内容前面临的风险：
- **舆论的复杂性**：同一内容在不同平台、不同群体中引发截然不同的反应
- **传播的非线性**：一句看似无害的话可能触碰到特定群体的敏感神经
- **多模态风险**：视频画面、音频语气、文案文字任何一个都可能踩雷
- **缺乏预判工具**：目前只能凭经验或发布后亡羊补牢

### 2.2 核心价值主张

| 价值 | 描述 |
|------|------|
| **预见性** | 在内容发布前预测舆论走向，而非事后分析 |
| **全面性** | 覆盖25+国内社交平台的用户反应 |
| **可操作** | 不只指出风险，还给出具体修改建议和替代方案 |
| **可解释** | 每个风险判断都有证据链（哪句话/哪个画面/哪段音频触发了风险） |

## 3. 用户画像

### 3.1 唯一目标用户：内容创作者

| 属性 | 描述 |
|------|------|
| **角色** | 即将发布视频/文案的博主、自媒体人、品牌内容团队 |
| **核心场景** | 内容发布前，检查是否存在舆论风险 |
| **核心需求** | 风险标注（句子级/画面级）、各平台反应预测、改写建议 |
| **使用频率** | 每次发布前使用 |

> 其他用户类型（品牌公关、政策研究者、社会学者、投资决策者）的功能需求降级为**后置能力**，不在阶段1-3的范围内。

### 3.2 唯一用户旅程：内容发前风控

1. **输入内容**：上传本地视频 / 粘贴文案脚本 / 混合输入（视频+文案+脚本）
2. **系统自动理解**：
   - 视频：关键帧提取 → 画面理解（多模态API）→ OCR → 音频转写 → 自动生成文案描述
   - 文案：语义分析 → 情感检测 → 敏感词识别
   - 混合：跨模态一致性校验（画面与文案是否矛盾/互补/冲突）
3. **舆论推演**：在25+平台上模拟不同人格用户的反应
4. **风险报告**：
   - 总体风险评级（红/橙/黄/绿）
   - 各平台反应预测（正面/中性/负面比例）
   - 风险点清单（按严重度排序，标注触发的句子/画面/音频）
   - 传播推演（关键节点、传播路径、极化趋势）
   - 修改建议（具体到句子级的改写方案）

## 4. 核心功能需求

### 4.1 唯一用户入口：内容预审工作台

**一个页面，一个流程。** 所有功能围绕"提交内容→获取风险报告"串联，用户无需切换页面。

```
┌──────────────────────────────────────────────────────────┐
│                    内容预审工作台                            │
├──────────────────────────────────────────────────────────┤
│  输入区（三种模式，用户自由选择）：                           │
│                                                          │
│  📹 视频上传：本地视频文件，后台自动提取关键帧+OCR+音频转写    │
│  📝 文案输入：粘贴文案、脚本、标题、描述                      │
│  📎 混合输入：视频+文案+脚本同时上传，综合分析+跨模态校验      │
│                                                          │
│  [开始预审]                                               │
├──────────────────────────────────────────────────────────┤
│  分析过程（实时展示）：                                      │
│  Step1 视频理解 → Step2 文案理解 → Step3 舆论推演 → 报告    │
├──────────────────────────────────────────────────────────┤
│  输出区：                                                  │
│  - 总体风险评级 + 7维风险雷达图                             │
│  - 各平台反应预测（25+平台热力图）                           │
│  - 风险点清单（句子级/画面级/音频级标注）                     │
│  - 传播推演可视化                                          │
│  - 修改建议                                                │
└──────────────────────────────────────────────────────────┘
```

### 4.2 内容理解（后台自动）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 视频关键帧提取 | FFmpeg + 场景切换检测，提取代表性画面 | P0 |
| 画面理解 | 多模态API理解画面内容（物体/场景/人物/动作） | P0 |
| 画面OCR | 提取画面中的文字（弹幕/字幕/水印/标题） | P0 |
| 音频转写 | 语音→文本（faster-whisper本地/Paraformer API） | P0 |
| 文案语义分析 | 情感倾向、敏感度、隐喻识别 | P0 |
| 跨模态一致性 | 视频画面与文案内容是否矛盾/冲突 | P1 |

### 4.3 舆论推演（仿真增强）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 平台自动匹配 | 基于内容主题自动选择相关平台（如游戏内容→B站+NGA+贴吧+TapTap） | P0 |
| 多Agent仿真 | 100-10000个具备7层人格+人生故事的Agent模拟反应 | P0 |
| 平台反应统计 | 各平台正面/中性/负面比例、典型评论、关注焦点 | P0 |
| 传播推演 | 从种子→扩散→爆发→长尾→沉淀的5阶段传播模型 | P1 |
| 极化检测 | 群体态度分裂程度、争议点识别 | P1 |
| 仿真启用条件 | 静态评估达到风险阈值或用户主动选择深度分析时启动 | P0 |

### 4.4 风险报告

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 7维风险评估 | 政治/性别/民族/道德/法律/群体/时事 7维度评估 | P0 |
| 证据链标注 | 每个风险点标注触发的原文/画面/音频片段及解释 | P0 |
| 置信度标注 | 风险判断的稳定性量化（基于多次仿真一致性） | P0 |
| 改写建议 | 高风险句子的替代方案 | P0 |
| 各平台差异对比 | 同一内容在不同平台引发的不同反应 | P1 |
| 不确定性说明 | 标注预测的不确定性来源 | P1 |

### 4.5 后台能力（用户不可见，系统自动调用）

| 功能 | 描述 | 与风控的关系 |
|------|------|-------------|
| 信号采集 | 从11+平台聚合热搜，为风控提供当前热点上下文 | "你的文案与当前热搜XX相关" |
| 知识图谱 | 实体关系图谱（Neo4j），为实体风险链提供支撑 | "你提到的A品牌近期有B争议" |
| 人格工厂 | 7层人格+人生故事生成，为仿真提供多样化Agent | 仿真需要真实多样化的人格 |
| Agent记忆 | Memory Stream记忆流，为Agent反应提供依据 | Agent基于记忆做出反应更真实 |

> 这些后台能力不暴露独立用户入口，仅在预审流程中自动调用。

## 5. 七维风险体系定义

### 5.1 维度详情

| 维度 | 定义 | 典型触发场景 | 严重度分级 |
|------|------|-------------|-----------|
| **1. 政治敏感** | 涉及政治人物、领土主权、外交关系等红线话题 | 不当评价政策、触及领土争议、调侃政治人物 | 🔴 任何触及均属高风险 |
| **2. 性别议题** | 性别对立、物化歧视、刻板印象强化 | 强化性别刻板印象、挑动性别对立、物化任何性别 | 🟡 依语境而定，对立性内容升级为🔴 |
| **3. 民族宗教** | 民族歧视、宗教冒犯、文化禁忌 | 不当引用宗教符号、地域歧视隐射民族问题 | 🔴 任何触及均属高风险 |
| **4. 道德伦理** | 违背公序良俗、与主流价值观冲突 | 鼓励不道德行为、挑战社会底线 | 🟠 依严重程度分级 |
| **5. 法律合规** | 广告法违规、侵权、虚假宣传 | 绝对化用语、未标注广告、虚假功效宣传 | 🟠 法律红线不可触碰 |
| **6. 群体冒犯** | 地域黑、职业歧视、年龄歧视 | "某省人都XXX"、贬低特定职业群体 | 🟡 依群体敏感度分级 |
| **7. 时事踩雷** | 不当蹭热点、关联翻车事件 | 在敏感事件期间发布可能被关联的内容 | 🟡 随时事热度动态变化 |

## 6. 准确率指标

| 指标 | 定义 | 阶段1-3目标 | 验证方式 |
|------|------|------------|---------|
| **风险识别准确率** | 与人工标注一致的比例 | 持续提升 | 回测对比 |
| **漏报率** | 高风险内容未识别的比例 | 持续下降 | 人工复检 |
| **误报率** | 低风险内容被误判的比例 | 持续下降 | 人工复检 |
| **平台覆盖有效率** | 已覆盖平台中可稳定输出结果的比例 | 持续提升 | 自动化测试 |
| **单次预审时延** | 输入到报告输出耗时 | <5分钟(标准模式) | 计时测试 |

### 6.1 性能参考

| 场景 | Agent数 | 仿真时长 | 预估耗时 | LLM成本 |
|------|---------|---------|---------|---------|
| 快速评估 | 100 | 6h | 1-2分钟 | ~¥0.5 |
| 标准评估 | 500 | 24h | 3-5分钟 | ~¥2 |
| 深度评估 | 2000 | 48h | 10-15分钟 | ~¥5 |
| 大规模评估 | 10000 | 72h | 20-40分钟 | ~¥10-20 |

## 7. 演进策略

### 7.1 蓝图路线（6阶段）

| 阶段 | 主题 | 核心交付 | 对准确率的贡献 |
|------|------|----------|---------------|
| **1. 回归核心** | 单入口串联 | Vue工作台+三模式输入+核心流程 | 建立准确率基线 |
| **2. 全平台覆盖** | 25+平台 | P0/P1/P2平台补全+原型扩展 | 提升平台覆盖率 |
| **3. 模型+人生故事** | 人格质量提升 | 最新多模态API+人生故事驱动人格+ChromaDB | 提升仿真真实度→准确率 |
| **4. 效果提升** | Memory Stream | 平台浸泡+反思机制+社交网络 | Agent反应更真实→准确率 |
| **5. 规模化仿真** | 万级Agent | GA-S3 Group Agent+极化检测 | 更大样本→更稳定的准确率 |
| **6. 扩展功能** | 后置 | 博主历史、竞品对比等 | 附加价值，非准确率核心 |

### 7.2 Go/No-Go 决策点

| 阶段 | Go条件 | No-Go处理 |
|------|--------|----------|
| 阶段1 | 核心流程端到端跑通，输出可读报告 | 继续修核心流程，不进入阶段2 |
| 阶段2 | 平台覆盖有效率>60% | 缩减平台范围，优先质量 |
| 阶段3 | 人生故事Agent比属性Agent仿真准确率提升>15% | 保留属性Agent，人生故事降级为实验 |
| 阶段4 | Memory Stream Agent反应一致性>0.7 | 简化记忆机制 |
| 阶段5 | 1000+Agent仿真结果稳定性（3次一致性>60%） | 控制规模，不追求万级 |

### 7.3 仿真启用与保留条件

- **启用条件**：静态评估达到风险阈值或用户主动选择深度分析
- **保留条件**：仿真相对静态评估在回测中带来稳定准确率提升
- **降级条件**：若提升不稳定，保留热点关联与实体风险链，减少仿真成本

### 7.4 风险与缓解

| 风险 | 概率 | 影响 | 缓解策略 |
|------|------|------|----------|
| 仿真结果不可信 | 高 | 极高 | 多次仿真取共识+回测验证+不确定性标注 |
| LLM成本过高 | 中 | 高 | 分层使用+本地小模型+批处理+硬件自适应 |
| Agent人格质量低 | 中 | 高 | 人生故事+验证流水线+Big Five一致性测试 |
| 平台覆盖不全 | 中 | 中 | 优先P0平台，渐进扩展 |

## 关键流程/结构

- 输入：本地视频/文案脚本/混合内容
- 处理：内容理解→平台匹配→Agent仿真→风险评估
- 输出：风险报告（评级+证据链+置信度+建议）

## 依赖与降级

- 依赖：多模态API（视觉/OCR/音频）、LLM API（仿真/评估）
- 失败降级策略：
  - 多模态API不可用 → 跳过对应模态，仅做文本分析
  - 仿真超时 → 降级为静态评估
  - 部分平台不可用 → 输出可用平台的结果，标注缺失

## 验收标准

- 指标：风险识别准确率、漏报率、误报率、平台覆盖率、预审时延
- 阈值：见第6节
- 通过条件：所有核心指标达到阶段目标值
