# VibeUtopia 系统架构设计

## 1. 技术栈选型

### 1.1 MVP阶段（已完成）

| 领域 | 技术 | 状态 |
|------|------|------|
| 后端框架 | Python FastAPI | ✅ 已实现 |
| 前端框架 | Streamlit | ✅ 已实现（V2迁移到Vue3） |
| 数据库 | SQLite | ✅ 已实现 |
| LLM接入 | OpenAI兼容API（LongCat-Flash-Lite） | ✅ 已实现 |
| 视频提取 | yt-dlp | ✅ 已实现 |
| 部署 | 本地（uvicorn + streamlit） | ✅ 已实现 |

### 1.2 V2阶段（蓝图）

| 领域 | 技术 | 选型理由 |
|------|------|----------|
| 前端框架 | Vue3 + Vite + ECharts + D3.js | 成熟生态，强大可视化 |
| LLM网关 | LiteLLM | 统一多模型接口，100+供应商，自带fallback |
| Agent框架 | 自研三层架构 | 借鉴OASIS思想但不依赖外部框架 |
| 知识图谱 | Neo4j | 专业图数据库，支持复杂图查询和路径推理 |
| 向量库 | Milvus | 高性能向量检索，支持大规模Agent记忆 |
| 关系数据库 | MySQL | 成熟稳定，SQLite升级版 |
| 缓存 | Redis | 热数据缓存、会话管理、Agent工作记忆、消息总线 |
| 消息队列 | Redis Streams | 高性能事件驱动，支持消费者组 |
| 任务调度 | Celery + Redis | 成熟分布式任务队列 |
| 对象存储 | MinIO | S3兼容，存储原始数据和报告 |
| 情感分析 | BERT-LoRA微调 | 中文情感分析，轻量高效 |
| 本地小模型 | Qwen2.5-7B | C级Agent决策，降低成本 |
| 爬虫 | API优先 + Playwright降级 | 性能与覆盖率的平衡 |
| 容器化 | Docker + Docker Compose | 一键部署，环境一致性 |

### 2.2 核心数据流

```
现实世界种子信号
    │
    ▼
[信号采集层] ── 多源聚合 ── 事件检测 ── 信号增强 ──▶ 种子事件库 (MySQL + Neo4j)
    │
    ▼
[世界构建层] ── 图谱更新 ── 人格生成/演化 ── 关系建立 ──▶ 平行世界状态 (Neo4j + Milvus)
    │
    ▼
[仿真运行层] ── Agent调度 ── 社交交互 ── 裂变传播 ──▶ 仿真轨迹数据 (Redis + MySQL)
    │
    ▼
[分析决策层] ── 趋势提取 ── 风险评估 ── 预测推演 ──▶ 决策建议报告 (MySQL + MinIO)
    │
    ▼
[用户交互层] ── 可视化 ── 交互式探索 ── 预警推送 ──▶ 用户决策
```

### 2.3 各层职责与依赖

| 层级 | 核心职责 | 上游依赖 | 下游产出 |
|------|----------|----------|----------|
| 信号采集层 | 从现实世界提取种子信息 | 外部API/RSS | 种子事件 |
| 世界构建层 | 构建高保真平行数字世界 | 种子事件 | Agent Profile + 社会关系图 + 世界状态 |
| 仿真运行层 | 让Agent在模拟平台上自由交互 | Agent + 世界状态 + 种子事件 | 仿真轨迹数据 |
| 分析决策层 | 从仿真中提取洞察和预测 | 仿真轨迹 + 种子事件 | 趋势预测 + 风险评估 + 决策建议 |
| 用户交互层 | 提供直观的用户界面 | 所有层的输出 | 用户操作入口 |

## 4. LLM分层使用策略

### 4.1 三级模型体系

| Tier | 模型 | 用途 | 单次成本 |
|------|------|------|----------|
| **Tier 1 最强** | DeepSeek-V3 / Qwen-Max | 复杂推理、人格生成、仿真分析、趋势预测 | ¥0.01-0.05 |
| **Tier 2 均衡** | DeepSeek / Qwen-Plus | Agent行为决策、内容生成、评论撰写 | ¥0.002-0.01 |
| **Tier 3 轻量** | 本地Qwen2.5-7B / Qwen-Turbo | C级Agent决策、简单分类、内容审核 | ¥0(本地) / ¥0.0005 |

### 4.2 LiteLLM路由规则

```python
# 通过LiteLLM统一路由
litellm_config = {
    "model_list": [
        {"model_name": "tier1", "litellm_params": {"model": "deepseek/deepseek-chat"}},
        {"model_name": "tier2", "litellm_params": {"model": "deepseek/deepseek-chat"}},
        {"model_name": "tier3", "litellm_params": {"model": "openai/qwen2.5-7b", "api_base": "http://localhost:8000"}},
    ],
    "fallbacks": [{"tier1": ["tier2", "tier3"]}, {"tier2": ["tier3"]}],
    "rate_limit": {"tier1": "10rpm", "tier2": "30rpm", "tier3": "100rpm"}
}
```

### 4.3 任务-模型映射

| 任务类型 | 默认Tier | 理由 |
|----------|----------|------|
| 种子事件分析 | Tier 1 | 需要复杂因果推理 |
| 人格Profile生成 | Tier 1 | 需要高质量人格细节 |
| A级Agent决策 | Tier 2 | 需要自然语言生成 |
| B级Agent决策 | Tier 2 | 需要基本推理 |
| C级Agent决策 | Tier 3 | 简单态度表态 |
| 内容审核 | Tier 3 | 分类任务 |
| 仿真总结 | Tier 1 | 需要综合分析 |
| 趋势预测 | Tier 1 | 需要复杂推理 |

## 6. 数据模型设计

### 6.1 核心实体

#### SeedEvent — 种子事件

```python
class SeedEvent:
    event_id: str                    # UUID
    title: str                       # 事件标题
    description: str                 # 事件描述
    category: str                    # 政治/经济/社会/文化/科技
    signal_strength: float           # 0-1, 信号强度
    sources: List[SignalSource]      # 来源列表
    comments: List[AnnotatedComment] # 带情感标注的评论
    related_events: List[str]        # 关联事件ID
    created_at: datetime
    ttl: int                         # 事件有效期(小时)
    status: str                      # active/expired/archived

class SignalSource:
    platform: str                    # 平台名
    url: str                         # 原始链接
    rank: int                        # 排名
    first_seen: datetime
    title: str

class AnnotatedComment:
    text: str
    platform: str
    sentiment: str                   # positive/negative/neutral
    sentiment_score: float           # -1 to 1
    like_count: int
    source_url: str
```

#### AgentProfile — Agent人格（7层结构）

```python
class AgentProfile:
    agent_id: str
    version: int

    # Layer 1: 基础属性
    age: int
    gender: str
    region: str
    profession: str
    income_level: str                # low/mid/high
    education: str

    # Layer 2: 价值观
    political_lean: str              # left/center/right
    social_stances: Dict[str, str]   # {议题: 立场}

    # Layer 3: 知识背景
    expertise: List[str]
    info_sources: List[str]
    cognitive_blindspots: List[str]

    # Layer 4: 行为模式
    posting_habits: str
    interaction_style: str
    active_hours: List[TimeSlot]
    expression_preference: str

    # Layer 5: 纠偏层
    behavioral_boundaries: List[str]
    self_constraints: List[str]
    conflict_resolution: str
```
