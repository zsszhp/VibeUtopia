# VibeUtopia 系统架构设计

## 1. 技术栈选型

### MVP阶段（已完成）
- **后端框架**：Python `FastAPI`（轻量级、响应快，AI生态最友好）
- **前端框架**：`Streamlit`（MVP快速验证，V2迁移到 Vue3）
- **数据库**：`SQLite`（本地零配置，后续可迁移 MySQL）
- **LLM接入**：直接调用兼容 OpenAI 格式的 API（当前 LongCat-Flash-Lite）
- **视频提取**：`yt-dlp`（支持B站/抖音等平台字幕/简介提取）
- **部署方式**：本地启动（uvicorn + streamlit）

### V2阶段（规划中）
- **前端框架**：`Vue3` + `Vite` + `ECharts`
- **LLM接入**：`LiteLLM`（统一封装多模型，支持 fallback）
- **Agent框架**：自研多Agent仿真引擎（参考 MiroFish/OASIS）
- **情感分析**：`faster-whisper` + `DistilBERT`
- **数据库**：`MySQL` + 向量库

## 2. 系统整体架构

### MVP架构（已实现）
```text
[ Streamlit UI ]
      │  (REST API)
      ▼
[ FastAPI 后端 ]
      │
      ├──▶ 文本预处理 (分句切分)
      ├──▶ 平台人格模拟 (4平台 Prompt + 静态背景语料)
      ├──▶ 七维风险评估 (LLM JSON输出)
      ├──▶ 改写建议生成 (LLM)
      ├──▶ 结果聚合与评分
      ├──▶ 视频文案提取 (yt-dlp)
      │
      ▼
[ SQLite ] (历史记录)
```

### V2目标架构
```text
[ Vue3 前端 ] ──(REST API)──▶ [ FastAPI 后端 ]
                                    │
                    ┌───────────────┼───────────────┐
                    ▼               ▼               ▼
            [ 分析引擎 ]    [ 仿真引擎 ]    [ 服务引擎 ]
            - 风险评估      - 多Agent仿真   - 博主画像
            - 情感分析      - 社交裂变      - 选题推荐
            - 多模态审核    - 舆论传播      - 竞品对标
                    │               │               │
                    └───────┬───────┘───────┬───────┘
                            ▼               ▼
                    [ LLM 集群 ]    [ 数据抓取模块 ]
                    (LiteLLM多模型)  (热搜+评论爬虫)
                            │               │
                            └───────┬───────┘
                                    ▼
                            [ MySQL + 向量库 ]
```

## 3. API 设计

### MVP已实现
- `POST /api/v1/analyze`：提交文案进行风控评估
- `GET /api/v1/analyze/{task_id}`：获取分析结果
- `GET /api/v1/history`：历史评估记录
- `POST /api/v1/extract-video`：从视频链接提取文案
- `POST /api/v1/analyze-video`：提取视频文案并分析

### V2规划
- `POST /api/v1/simulation`：启动多Agent社交仿真
- `GET /api/v1/simulation/{id}`：获取仿真结果与传播路径
- `POST /api/v1/blogger/analyze`：博主账号深度分析
- `POST /api/v1/blogger/recommend`：选题推荐
- `POST /api/v1/competitor/compare`：竞品对标分析

## 4. 数据模型

### MVP已实现
- **Task**: 分析任务状态（processing/completed/failed）
- **RiskItem**: 风险句子、维度、严重程度、判定依据
- **PlatformReaction**: 各平台情绪分布与原因
- **AnalysisSummary**: 总分、建议、各维度分数、改写方案

### V2规划
- **Agent**: Agent人格属性（5层结构）、知识背景、情绪状态
- **SimulationRun**: 仿真运行状态与结果
- **BloggerProfile**: 博主风格画像、历史数据分析
- **TopicRecommendation**: 选题推荐与流量预测
- **CompetitorAnalysis**: 竞品对标分析结果
