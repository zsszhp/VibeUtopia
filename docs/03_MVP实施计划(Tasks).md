# VibeUtopia MVP 实施任务计划

## 文档定位
- 本文档在主线中的角色：记录MVP阶段已完成的任务及其准确率收益，并为后续6阶段演进提供按准确率收益排序的任务清单
- 与"发前风控优先"的关系：每个任务必须回答"预期准确率收益是什么"，确保投入有可验证的产出

## 本文档边界
- 本文档负责：MVP已完成任务清单、预期准确率收益标注、后续任务排序与阶段映射
- 本文档不负责：各层技术设计细节（见06-12专项文档）、路线图Go/No-Go规则（见`04_V2深化路线图.md`）

## 对准确率的直接贡献
- 机制1：按准确率收益排序任务，确保最高收益的工作优先执行
- 机制2：每个任务标注预期准确率收益，使改进可量化追溯
- 验证方式：回测对比、人工复检

## 关键流程/结构
- 输入：蓝图6阶段路线图（见`04_V2深化路线图.md`）
- 处理：任务按准确率收益排序 → 映射到蓝图阶段 → 执行 → 验收
- 输出：可量化准确率提升的任务交付物

## 依赖与降级
- 依赖：LLM API可用性、MySQL/SQLite数据库、多模态API
- 失败降级策略：某任务无法完成时，跳过并记录，不阻塞后续更高收益任务

## 验收标准
- 指标：各任务的预期准确率收益是否在回测中得到验证
- 阈值：核心风控任务（Phase 3）预期收益需在回测中体现≥5%提升
- 通过条件：每个已完成任务的准确率收益可追溯、可量化

---

**核心目标**：去除重型框架（如OASIS多体仿真），用最快速度在本地跑起第一版，验证核心价值，为未来的系统迭代打底。

## 已完成任务（按准确率收益排序，高→低）

### Phase 3: 核心风控评估流水线 — 准确率收益最高

> 直接决定风控准确率的核心流水线，是整个系统的价值所在。

- [x] **3.3 编写「七维风险评估 Prompt」**：让 LLM 根据明确的7个风险体系对高危句子进行打分、分类并提取证据。
  - 预期准确率收益：**+25%** — 7维体系是风控的结构化基础，直接决定风险识别的覆盖面和精度
- [x] **3.2 编写「平台人格模拟 Prompt」**：在调用 LLM 时，注入静态背景语料，让 LLM 扮演四个平台的用户对句子做出模拟评价。（当前为静态语料，Phase 2完成后改为动态注入）
  - 预期准确率收益：**+20%** — 多平台多视角评估，补全单一视角的盲区
- [x] **3.4 编写「改写建议 Prompt」**：针对识别出的高风险句子，让 LLM 给出两个风格的安全改写方案。
  - 预期准确率收益：**+15%** — 从"发现问题"到"解决问题"，闭环风控价值
- [x] **3.1 开发文本切分器**：将用户输入的长文案按段落和完整句子精准切分。
  - 预期准确率收益：**+10%** — 句子级切分是风险评估粒度的前提，切分不准则评估失真
- [x] **3.5 结果聚合与存储**：将 LLM 零散的输出整合打分（0-100），并持久化存入 SQLite。
  - 预期准确率收益：**+5%** — 聚合与持久化为后续回测和迭代优化提供数据基础

### Phase 4: 前端界面与全链路联调

> 将核心风控能力可视化呈现给用户，完成端到端闭环。

- [x] **4.2 开发报告展示组件**：
  - 总分仪表盘
  - 七维风险评估条形图
  - 句子级风险高亮展示及详细解释
  - 平台预测情绪条形图
  - 安全改写方案对比卡片
  - 预期准确率收益：**+5%** — 可视化让用户能定位和修正风险，间接提升风控实际效果
- [x] **4.1 开发主工作台界面**：左侧提供大文本输入区（支持提交），右侧展示"分析中"的动态进度效果。
  - 预期准确率收益：**+2%** — 完整的用户入口确保核心流程可运行
- [x] **4.3 前后端联合调试**：走通一条文案的完整分析流。
  - 预期准确率收益：**+2%** — 端到端联调确保风控能力不被传输损耗
- [x] **4.4 编写本地启动脚本**：编写一键启动 `.bat` 和 README 文档，确保可以在本地丝滑启动跑通。
  - 预期准确率收益：**+0%** — 运维效率，不直接贡献准确率

### Phase 5: 视频文案提取 (MVP增强)

> 扩展输入模态，覆盖视频场景。

- [x] **5.1 集成 yt-dlp**：从B站/抖音等视频链接提取字幕、简介或标题。
  - 预期准确率收益：**+5%** — 视频输入扩展风控覆盖面
- [x] **5.2 新增视频分析 API**：`/extract-video` 和 `/analyze-video` 端点。
  - 预期准确率收益：**+3%** — API化确保视频分析可被主流程调用
- [x] **5.3 前端视频链接标签页**：支持粘贴链接一键提取并评估。
  - 预期准确率收益：**+2%** — 前端入口确保视频分析能力可达用户

### Phase 1: 基础脚手架搭建

> 基础设施层，不直接贡献准确率，但为所有准确率提升任务提供运行基础。

- [x] **1.1 初始化 FastAPI 后端项目**：配置路由、CORS跨域、连接本地 SQLite 数据库，建立核心数据表模型。
  - 预期准确率收益：**+0%** — 基础设施
- [x] **1.2 初始化前端项目**：使用 Vue3 + Naive UI 搭建前端界面。
  - 预期准确率收益：**+0%** — 基础设施（MVP阶段曾用快速原型验证，已迁移至Vue3）
- [x] **1.3 连通大模型接口**：接入兼容 OpenAI 格式的 LLM API，编写基础的封装类测试对话联通性。
  - 预期准确率收益：**+0%** — 基础设施，但LLM质量间接影响评估质量

### Phase 2: "现实增强"轻爬虫模块（MVP阶段延后）

> 为风控提供实时热点上下文，但MVP阶段用静态语料替代。

- [ ] **2.1 开发轻量级热搜爬虫**：针对 微博/B站/知乎 等获取每日Top热点事件标题与摘要。
  - 预期准确率收益：**+8%** — 热点上下文为风险评估补充实时信号，减少"过时评估"
- [ ] **2.2 开发定向评论抓取脚本**：根据特定热点关键词，抓取几个平台上的真实高赞评论和极端评论。
  - 预期准确率收益：**+5%** — 真实评论为平台人格模拟提供动态注入源
- [ ] **2.3 构建「平台人格背景库」**：将抓取到的内容定期汇总为一段精简的文本（Context），供后续给 LLM 注入"现实世界情绪"。
  - 预期准确率收益：**+3%** — 背景库为Agent人格提供实时情绪基础
