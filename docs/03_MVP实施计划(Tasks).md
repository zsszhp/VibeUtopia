# VibeUtopia MVP 实施任务计划

**核心目标**：去除重型框架（如OASIS多体仿真），用最快速度在本地跑起第一版，验证核心价值，为未来的系统迭代打底。

## Phase 1: 基础脚手架搭建 (约1-2天)
- [ ] **1.1 初始化 FastAPI 后端项目**：配置路由、CORS跨域、连接本地 SQLite 数据库，建立核心数据表模型。
- [ ] **1.2 初始化 Vue3 前端项目**：配置基础页面骨架、安装组件库（如 Element Plus 或 Tailwind）、配置 Axios 请求。
- [ ] **1.3 连通大模型接口**：接入 DeepSeek 或 阿里云大模型 API，编写基础的封装类测试对话联通性。

## Phase 2: “现实增强”轻爬虫模块 (约2-3天)
*(满足“多爬取现实世界平台信息，完善人格”诉求)*
- [ ] **2.1 开发轻量级热搜爬虫**：针对 微博/B站/知乎 等获取每日Top热点事件标题与摘要。
- [ ] **2.2 开发定向评论抓取脚本**：根据特定热点关键词，抓取几个平台上的真实高赞评论和极端评论。
- [ ] **2.3 构建「平台人格背景库」**：将抓取到的内容定期汇总为一段精简的文本（Context），供后续给 LLM 注入“现实世界情绪”。

## Phase 3: 核心风控评估流水线开发 (约3-4天)
- [ ] **3.1 开发文本切分器**：将用户输入的长文案按段落和完整句子精准切分。
- [ ] **3.2 编写「平台人格模拟 Prompt」**：在调用 LLM 时，注入 Phase 2 获取的真实背景库，让 LLM 扮演四个平台的用户对句子做出模拟评价。
- [ ] **3.3 编写「七维风险评估 Prompt」**：让 LLM 根据明确的7个风险体系对高危句子进行打分、分类并提取证据。
- [ ] **3.4 编写「改写建议 Prompt」**：针对识别出的高风险句子，让 LLM 给出两个风格的安全改写方案。
- [ ] **3.5 结果聚合与存储**：将 LLM 零散的输出整合打分（0-100），并持久化存入 SQLite。

## Phase 4: 前端界面与全链路联调 (约2-3天)
- [ ] **4.1 开发主工作台界面**：左侧提供大文本输入区（支持提交），右侧展示“分析中”的动态Loading效果。
- [ ] **4.2 开发报告展示组件**：
  - 核心总分雷达图 / 仪表盘
  - 句子级风险高亮展示及详细解释弹窗
  - 平台预测情绪条形图
  - 安全改写方案对比卡片
- [ ] **4.3 前后端联合调试**：走通一条文案的完整分析流。
- [ ] **4.4 编写本地启动脚本**：编写一键启动 `.bat` 或 `README` 文档，确保可以在本地丝滑启动跑通。
