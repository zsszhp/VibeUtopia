## V2.1: 现实增强 — 信号采集体系

> **目标**：从现实世界实时采集种子信息，构建种子事件库

### 交付物

- [x] 热榜聚合引擎（NewsNow API + 11平台）
- [x] RSS补充源（财经/科技/国际）
- [x] 增量检测器（新上榜 + 排名变化追踪）
- [x] LLM关键词提取器
- [x] 定向评论爬取（API优先 + Playwright降级）
- [x] BERT-LoRA情感标注器（V2.1先行使用LLM情感标注，后续可替换为BERT-LoRA降成本）
- [x] 事件检测器（主题聚类 + 因果推理 + 信号强度评估）
- [x] 种子事件库（SQLite先行 + MySQL预留，Neo4j推迟到V2.2）
- [x] Celery Beat定时调度器（V2.1使用APScheduler，V2.4引入Celery+Redis时迁移）
- [x] API端点：`GET /signals/hot`, `GET /signals/events`, `POST /signals/crawl`

### 技术依赖

- TrendRadar的DataFetcher（验证可行的NewsNow API）
- BettaFish的MindSpider（两阶段爬取策略）
- LiteLLM（统一LLM调用）
- Celery + Redis（任务调度）
- BERT-LoRA微调模型（情感标注）

### 验收标准

1. 11个平台热搜数据5分钟内聚合完成
2. 新上榜事件10秒内检测到
3. 信号强度>0.7的事件自动触发深度爬取
4. 情感标注准确率>85%
5. 种子事件包含完整的来源+评论+情感标注

### 主要风险

| 风险 | 概率 | 缓解 |
|------|------|------|
| NewsNow API不稳定 | 中 | 备用直接爬取各平台 |
| Playwright被封 | 高 | API优先+代理池 |
| BERT-LoRA中文效果差 | 低 | 降级到LLM情感判断 |

## V2.2: 知识图谱 — 世界模型构建

> **目标**：从种子事件构建知识图谱，为Agent生成提供世界上下文

### 交付物

- [x] Neo4j图谱服务部署
- [x] 本体生成器（LLM从文档生成实体类型+关系类型）
- [x] 实体关系抽取器（LLM+NER，文档分块批量抽取）
- [x] 图谱存储与查询接口（CRUD + 图遍历 + 路径推理 + 社区检测）
- [x] 增量更新机制（新种子事件自动更新图谱）
- [x] 图谱可视化界面（简单版）

### 技术依赖

- MiroFish的GraphBuilder思想（LLM生成本体）
- Neo4j（替代Zep Cloud）
- LiteLLM

### 验收标准

1. 10篇种子文档5分钟内完成本体生成
2. 实体抽取F1>0.7
3. 支持增量更新，不重建整个图谱
4. 图查询响应<1秒（万级节点）

### 主要风险

| 风险 | 概率 | 缓解 |
|------|------|------|
| LLM本体生成不稳定 | 中 | 人工审核+模板兜底 |
| 实体去重困难 | 高 | LLM辅助合并+人工确认 |
| Neo4j学习曲线 | 低 | 使用成熟ORM（neomodel） |

## V2.3: 人格工厂 — 7层人格与关系网络

> **目标**：生成具备7层人格结构和真实社会关系的Agent群体

### 交付物

- [ ] 人格原型模板库（20+原型覆盖主要人群）
- [ ] 7层人格LLM生成器（含Prompt模板）
- [ ] 图谱关系注入器（知识图谱实体→Agent知识背景层）
- [ ] 批量并行生成器（3-5并发LLM，1000个Agent/5分钟）
- [ ] 人格质量校验器（一致性检查+LLM修复）
- [ ] 社会关系网络生成器（5种关系类型+4步算法）
- [ ] 长期记忆系统（三层：Redis工作记忆+Milvus情景记忆+MySQL语义记忆）
- [ ] 记忆整合器（工作→情景→语义 + 遗忘机制）
- [ ] 人格版本管理
- [ ] API端点：`POST /agents/generate`, `GET /agents/{id}`, `PUT /agents/{id}`

### 技术依赖

- MiroFish的OasisProfileGenerator（LLM增强人格生成思想）
- ex-skill的5层人格结构（扩展为7层）
- Milvus（向量记忆存储）
- Neo4j（社会关系图谱）

### 验收标准

1. 生成1000个差异化Agent<5分钟
2. 人格一致性校验通过率>95%
3. 社会关系网络符合小世界+幂律特性
4. 记忆检索响应<100ms
5. 同原型Agent在相似场景下行为相关性>0.8

### 主要风险

| 风险 | 概率 | 缓解 |
|------|------|------|
| LLM人格生成成本高 | 中 | 批量生成+Tier2模型 |
| 人格一致性差 | 高 | 自动校验+LLM修复 |
| Milvus部署复杂 | 中 | 使用Milvus Lite简化 |

## V2.4: 社交仿真 — 多Agent交互引擎

> **目标**：让Agent在5个模拟社交平台上自由交互

### 交付物

- [ ] 三层Agent架构（Director/Watcher/Injector/Guardian + 市民Agent + 功能子Agent）
- [ ] Agent行为决策引擎（感知-思考-行动循环 + LLM Prompt模板）
- [ ] C级Agent规则引擎（规则+本地小模型）
- [ ] Redis Streams消息总线（5种通道）
- [ ] 5平台社交仿真器（微博/B站/小红书/知乎/抖音 + 统一PlatformAction接口）
- [ ] 仿真时间模型（8时段+Agent个性化时间表）
- [ ] 仿真主循环（异步流水线优化）
- [ ] ABC三级Agent分层调度
- [ ] API端点：`POST /simulation`, `GET /simulation/{id}`, WebSocket推送

### 技术依赖

- BettaFish的ForumEngine协作思想（升级为消息总线）
- MiroFish的OASIS仿真（借鉴行为模型，自研引擎）
- Redis Streams（高性能消息总线）
- Qwen2.5-7B本地模型（C级Agent决策）

### 验收标准

1. 1000个Agent×24小时仿真<30分钟完成
2. 单次仿真LLM成本<¥5
3. 5个平台各自行为正确（微博有热搜机制、B站有弹幕等）
4. 消息总线延迟<50ms
5. 仿真可暂停/恢复/回放

### 主要风险

| 风险 | 概率 | 缓解 |
|------|------|------|
| LLM成本超预期 | 高 | 严格ABC分级+批处理+本地模型 |
| Agent行为失控 | 中 | Guardian Agent监控+行为边界 |
| 仿真速度慢 | 中 | 异步流水线+C级规则引擎 |

## V2.5: 裂变传播 — 舆论动力学

> **目标**：精确模拟舆论从小众到大众的裂变过程

### 交付物

- [ ] 5阶段传播模型（种子注入→初级传播→社群扩散→立场分化→主流化/消退）
- [ ] 传播影响因素量化模型（Agent因素+内容因素+平台因素）
- [ ] 舆论极化指数计算
- [ ] 传播动能计算（互动增速×情感强度）
- [ ] Watcher实时监控（态势感知+异常检测）
- [ ] Guardian应急干预
- [ ] 仿真回放时间轴
- [ ] 传播路径可视化

### 技术依赖

- V2.4的仿真引擎基础
- D3.js力导向图（传播网络可视化）

### 验收标准

1. 舆论传播路径可追溯（每条内容的传播链完整）
2. 极化指数计算准确反映讨论分化程度
3. 大V转发后传播范围增长5-10倍（符合现实）
4. 仿真中实时监控延迟<5秒

### 主要风险

| 风险 | 概率 | 缓解 |
|------|------|------|
| 传播模型不准 | 高 | 多轮仿真+历史回测调参 |
| 极化计算不准 | 中 | 参考真实案例校准 |

## V2.6: 预测决策 — 趋势推演与反事实

> **目标**：从仿真中提取趋势预测，支持反事实推演

### 交付物

- [ ] 4阶段趋势预测引擎（态势感知→模式识别→走势预测→决策建议）
- [ ] 5种舆论模式分类器（快速爆发/缓慢升温/争议分裂/短暂热度/持续发酵）
- [ ] 短/中/长期走势预测（含概率分布+不确定性标注）
- [ ] 风险等级评估（红/橙/黄/绿）
- [ ] 反事实仿真引擎（多分支创建+干预注入+并行仿真+结果对比）
- [ ] 决策建议生成器（应对策略+时机建议）
- [ ] 报告生成引擎（4类报告+7种可视化组件+HTML/PDF/JSON输出）
- [ ] 多轮仿真共识机制
- [ ] 人工审核入口
- [ ] API端点：`POST /report/risk`, `POST /report/simulation`, `POST /simulation/{id}/branch`

### 验收标准

1. 短期趋势方向预测准确率>70%（基于历史回测）
2. 反事实仿真3个分支对比完成<90分钟
3. 报告生成<1分钟
4. 预测不确定性标注覆盖率100%

### 主要风险

| 风险 | 概率 | 缓解 |
|------|------|------|
| 预测准确性不够 | 高 | 多轮共识+不确定性标注+历史回测 |
| 反事实仿真成本高 | 中 | 使用较少Agent(500)+较短时长(12h) |
| LLM分析不稳定 | 中 | 3阶段JSON解析+重试 |
