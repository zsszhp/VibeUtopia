# VibeUtopia V2 深化路线图

基于 MVP 验证成果和原始需求（docs/archive/需求.md），制定以下深化计划。

## V2.1: 现实增强 - 动态爬虫与人格演进
> 对应原始需求第4点："怎么更好的完善人格，更好的模拟现实世界"

- [ ] 开发轻量热搜爬虫（微博/B站/知乎热搜API）
- [ ] 开发定向评论抓取（热点关键词 → 平台高赞/极端评论）
- [ ] 构建平台人格背景库（定时汇总为 Context，动态注入 Prompt）
- [ ] 人格特征动态演化（基于真实舆论风向自动调整敏感度）
- [ ] 人格背景库持久化与版本管理

## V2.2: 多Agent社会级仿真
> 对应原始需求第1点："需要多个AI模拟人格，多个平台的声音"
> 参考项目: MiroFish (OASIS多Agent框架)

- [ ] 引入多Agent框架，每个Agent有独立人格/三观/情绪状态
- [ ] Agent之间可以交互、争论、影响（社交裂变模拟）
- [ ] 5层人格结构构建（参考 ex-skill）：基础属性 → 价值观 → 知识背景 → 行为模式 → 纠偏层
- [ ] Agent群体动力学：模拟从小众争议到大众舆论的裂变过程
- [ ] 仿真结果可视化：展示舆论传播路径和关键节点

## V2.3: 博主深度服务
> 对应原始需求第2点："深入熟悉博主视频风格，分析博主多个视频"

- [ ] 博主账号分析：输入B站/抖音账号链接，批量提取历史视频文案
- [ ] 博主风格画像：分析博主常用词汇、表达风格、内容主题偏好
- [ ] 选题推荐引擎：结合热点 + 博主风格，推荐选题和切入点
- [ ] 流量预测：基于历史数据和热点匹配度，预测每个选题的预期效果
- [ ] 文案生成辅助：根据选题和博主风格，生成初稿文案

## V2.4: 竞品对标分析
> 对应原始需求第3点："也可以做对标账号的分析"

- [ ] 对标账号识别与绑定
- [ ] 对标账号内容拆解（主题、风格、互动策略）
- [ ] 成功要素提炼与量化
- [ ] 差异化建议生成
- [ ] 持续跟踪对标账号动态

## V2.5: 情感分析与报告引擎
> 参考项目: BettaFish (情感分析 + 报告引擎)

- [ ] 多模型情感分析（DistilBERT / BERT-LoRA）
- [ ] ForumEngine 多Agent协作分析
- [ ] 结构化报告自动生成（PDF/HTML）
- [ ] 可视化报告模板（雷达图、传播路径图、时间线）

## V2.6: 多模态支持
> 对应原始需求："每个画面，可能有什么风险"

- [ ] 视频画面关键帧提取与OCR
- [ ] 画面风险评估（视觉内容审核）
- [ ] 音频情感分析
- [ ] 视频+文案综合评估

## V2.7: 前端升级
- [ ] 从 Streamlit 迁移到 Vue3 + Vite 正式前端
- [ ] 雷达图可视化（ECharts）
- [ ] 社交裂变传播动画
- [ ] 博主画像仪表盘
- [ ] 对标账号对比面板

## 技术演进路线

| 阶段 | LLM | Agent | 前端 | 数据 |
|------|-----|-------|------|------|

| V2.3-2.4 | + Fine-tuned模型 | Agent + 博主画像 | Vue3迁移 | + 博主历史数据 |
