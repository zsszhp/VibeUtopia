# VibeUtopia 信号采集层设计

> 从现实世界提取种子信息，作为平行数字世界的输入。三层采集体系：广度热榜 + 深度爬取 + 信号增强。

## 1. 设计理念

信号采集层是VibeUtopia感知现实世界的"感官系统"。它需要回答三个核心问题：

1. **现在发生了什么？**（广度信号 - 热搜聚合）
2. **人们怎么看？**（深度信号 - 评论爬取）
3. **意味着什么？**（信号增强 - 事件检测与关联）

设计原则：
- **多源冗余**：同一事件从多个渠道获取，交叉验证
- **轻重分离**：轻量采集实时运行，重量采集按需触发
- **增量优先**：只处理新增/变化的数据，避免重复
- **成本可控**：根据信号强度决定爬取深度

### 2.3 增量检测机制

**参考来源**：TrendRadar的`detect_latest_new_titles()`。

**核心逻辑**：
1. 获取当前批次所有标题
2. 与历史标题库对比（按`first_time`判断）
3. 识别新上榜标题（新事件）
4. 识别排名变化（事件升温/降温）
5. 识别下榜标题（事件消退）

**数据结构**：

```python
class Signal:
    """标准化信号"""
    signal_id: str                   # UUID
    source_platform: str             # 来源平台
    title: str                       # 标题
    url: Optional[str]               # 原始链接
    rank: Optional[int]              # 当前排名
    rank_timeline: List[RankPoint]   # 排名变化时间线
    first_seen: datetime             # 首次发现时间
    last_seen: datetime              # 最近发现时间
    appearance_count: int            # 出现次数
    is_new: bool                     # 是否新上榜
    signal_type: str                 # hotlist/rss

class RankPoint:
    """排名时间点"""
    timestamp: datetime
    rank: int
```

### 4.3 信号强度评估

```python
class SignalStrengthEvaluator:
    """信号强度评估器"""

    def evaluate(self, event: SeedEvent) -> float:
        """评估信号强度 (0-1)"""
        scores = {
            "spread": self._spread_score(event),      # 传播广度: 多少平台出现
            "velocity": self._velocity_score(event),   # 上榜速度: 从0到Top3的时间
            "resonance": self._resonance_score(event),  # 多平台共振: 是否同时多平台热搜
            "engagement": self._engagement_score(event),# 互动强度: 评论数/情感极性
            "persistence": self._persistence_score(event) # 持续性: 在榜时长
        }
        return weighted_average(scores)

    def _spread_score(self, event) -> float:
        """传播广度: 出现在N个平台 → N/11"""
        return len(event.sources) / 11.0

    def _velocity_score(self, event) -> float:
        """上榜速度: 从首次出现到进入Top3的时间越短分越高"""
        # 30分钟内到Top3 = 1.0, 1小时 = 0.8, 3小时 = 0.5, 更久 = 0.2

    def _resonance_score(self, event) -> float:
        """多平台共振: 2个以上平台同时出现 = 高分"""
        # 同时3+平台 = 1.0, 2平台 = 0.7, 1平台 = 0.3

    def _engagement_score(self, event) -> float:
        """互动强度: 评论数多+情感极性大 = 高分"""
        # 基于评论数量和情感分布

    def _persistence_score(self, event) -> float:
        """持续性: 在榜时间越长越重要"""
        # 24h+ = 1.0, 12h = 0.7, 6h = 0.4, <3h = 0.2
```

## 8. 异常处理与容错

| 异常场景 | 检测方式 | 处理策略 |
|----------|----------|----------|
| NewsNow API不可用 | HTTP状态码≠200 + 超时 | 降级到直接爬取各平台(速度慢但可用) |
| Playwright被封 | 页面返回验证码/空内容 | 切换代理+Cookie，3次失败后降级跳过 |
| LLM调用超时 | 30秒无响应 | 跳过LLM增强(关键词提取/事件检测)，用规则替代 |
| 增量检测误判 | 短时间内大量"新事件" | 触发频率阈值告警，人工确认 |
| 情感标注模型异常 | 推理超时/内存溢出 | 降级到LLM情感判断 |
| 数据库写入失败 | 异常捕获 | 写入本地文件队列，后台重试 |
| 种子事件过期 | TTL到期 | 自动标记为expired，归档到MinIO |
