## 2. 关键改动

### 2.1 博主风格画像
- 新增 `src/backend/services/blogger_style_profiler.py`
- 规则降级路径无 LLM 可跑；LLM 可用时增强
- 输出字段：`topics`、`tone`、`pace`、`risk_appetite`、`persona`、`risk_impact`

### 2.2 选题推荐
- 完善 `POST /api/v3/blogger/topics/recommend`（routes_v3）
- `topic_recommender.py` 输出选题卡结构：`title`、`angle`、`expected_effect`、`risk_estimate`、`safety_score`、`rationale`、`risk_impact`
- 无热点时自动取信号 Top20；LLM 失败降级规则推荐

### 2.3 对标分析
- `competitor_comparator.py` 输出增加 `imitable_actions`（选题角度/标题结构/发布节奏）与 `risk_pattern_diff`

### 2.4 前端
- 新增 `src/frontend/src/components/TopicRecommendPanel.vue`
- 挂入 RightPanel 扩展工具 Tab
- 「预审此选题」将标题+简介回填左侧输入
