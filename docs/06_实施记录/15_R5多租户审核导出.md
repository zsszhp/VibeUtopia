# R5 多租户雏形 / 审核工作流 / 报告导出实施记录

> 测试：tests/test_r5_tenant_workflow.py（10/10）
> 全量 pytest 137 passed 9 skipped

## 1. JWT 多租户雏形

- `auth.py`：可选 JWT（`settings.JWT_SECRET`）
- `POST /api/v1/auth/token`：用户名+密码换 token（本地 admin）
- 未配置 JWT → 503，行为与旧版兼容
- `Authorization: Bearer <jwt>` 优先；API_KEY 机制保留
- `Task.owner_id`：有 JWT 写入 sub/username；无 token 为 NULL

## 2. 审核工作流

- `Task.workflow_status`：draft / pending_review / approved / rejected
- `workflow_history_json` 状态流转留痕
- `PATCH /api/v1/review/{task_id}/workflow`：状态与备注；非法流转 400
- 归属校验雏形：有 owner 的任务，他人 JWT 403；无 token 兼容放行

## 3. 报告导出

- `GET /api/v1/review/{task_id}/export?format=md|json`
- Markdown：Verdict、总分、Top 风险、改写建议、免责声明
- JSON：结构化完整字段
- 导出与工作流历史不含密钥（测试固化）

## 4. 安全说明

- 测试使用一次性口令，不入库、不进仓库
- 生产须配置 `JWT_SECRET`、`ADMIN_PASSWORD`、`API_KEY`
- 多用户账号体系仍为后续（当前单 admin 占位）

## 遗留

- 真实用户表与注册、刷新令牌、细粒度 RBAC
- 导出 PDF、邮件送达
