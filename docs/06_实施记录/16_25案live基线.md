### 4.2 误差模式

**模式 A：红色案普遍低估（4 例，BT001/005/011/013）**
四个 red 案全部停在 52–62 分的 orange 区间，距 red 阈值 76 差 14–24 分。共同特征是「政治/民族/历史/对立」类社会议题型风险，文本本身措辞相对克制、无极端脏词，多维评分在聚合时被稀释。BT005（民族宗教）偏差最大（52，需 80），说明民族宗教维度的打分权重或严重度映射偏软。

**模式 B：隐喻/反讽类漏检（1 例，BT015 — 最大单项失误）**
期望 orange（50–70），实测 19 → 直接判 green，差 31 分。该案是「暗讽时事的隐喻内容」，期望高危维度含「隐喻反讽」，但当前 11 维评估里没有独立的隐喻反讽维度，语义间接的风险信号完全没进评分。更要紧的是该案置信度 0.69 为 8 个失手中最高——**置信度与真实误差反相关**，校准面需要单独处理（详见 4.3）。

**模式 C：阈值边界敏感（3 例，BT009/017/013）**
BT009 实测 76 恰好越过 red 线（期望 ≤75），BT017 实测 49 差 2 分到 orange 线（51），BT013 实测 62 距区间下沿 70 差 8 分。这类属于分档边界抖动，不是识别能力崩溃；调阈值或加分数平滑即可回收，但要防止过拟合到本 25 案。

**模式 D：高估（2 例，BT009/023）**
BT023（道德绑架式传播）期望 50–70，实测 79 判 red，情绪极化类信号给了过高分。与模式 A 一起看，说明「社会议题/情绪类」的分数方差偏大：同一类特征有时给 52，有时给 79，一致性不足。

**模式 E：等级对、分数出界（1 例，BT016）**
期望 green [0,15]，实测 19，等级仍落在 green（≤25）故等级命中，但拉低了 score_range_accuracy。这是 score_range_accuracy（0.64）低于 valid_accuracy（0.68）的唯一来源。

### 4.3 置信度观察

- 8 个失手案中 7 个置信度挤在 0.53–0.54（medium），与命中案中的 red/orange 命中者（BT003 0.52、BT019 0.56、BT021 0.54）几乎无法区分——置信度目前**区分不出对错**。
- 最大失误 BT015 置信度 0.69，反而高于全部命中案（命中案最高 0.68），属反向校准。
- green 命中案置信度基本停在 0.67–0.68（12 例中 11 例为 0.68），呈现明显的取值离散化/饱和迹象，建议后续做 ECE 分桶复核（可复用 `data/eval/calibration_report.md` 的口径）。

### 4.4 与旧基线的对比说明

上一份 `baseline.json` 为 `valid_accuracy=0.8333 / total_cases=12`（12 案子集 live），本次为 25 案全量 live。**两者案例集不同，不可直接比较涨跌**：新增的 BT013–BT025 里包含隐喻、道德绑架、地域歧视等更难的橙色案，拉低了整体命中率。本次 0.68 应作为 25 案全量口径的新基线。

## 5. 结论与建议

- 本轮 **live 全量 25/25 有效、0 API 失败**，`baseline.json` 已由 live 写入（mode=live, total_cases=25），无需 `--limit` 补测。
- `valid_accuracy = 0.68`，`valid_ratio = 1.0`，均按真实结果记录，未做任何修饰。
- 优化优先级建议：
  1. **社会议题型 red 低估**（BT001/005/011/013）——调政治敏感/民族宗教/历史类维度的严重度映射与聚合权重，预期可回收 3–4 例。
  2. **隐喻反讽漏检**（BT015）——补隐喻/反讽语用维度或在 prompt 中显式要求识别间接风险表达。
  3. **边界分档**（BT009/017/013）——阈值附近引入平滑或二次判定，谨慎调参防过拟合。
  4. **置信度校准**——当前置信度无法区分对错且存在反向案例，建议单独跑 ECE 与误判联动分析。
- 门禁回归命令（后续改动 prompts/** 后跑）：`PYTHONPATH=src python tests/run_eval_regression.py --mode live --source backtest --baseline data/eval/baseline.json`，`valid_accuracy` 跌幅超过 5 个百分点退出码 2。
