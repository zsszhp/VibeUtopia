# ECE 校准分析（236 样本）

> 数据源：data/eval/eval_*.json 22 份 live/mock 报告中带 confidence 的案例
> 口径：confidence 分档 vs 命中率；ECE = Σ (n_i/N) × |acc − conf|

## 总览

| 指标 | 数值 |
|------|------|
| 有效样本 | 236 |
| **ECE** | **0.224** |
| 样本充足性 | 达标（≥10） |

## 结论

1. **置信度缺乏区分度**：98% 样本挤在 0.50–0.70，无法区分「会命中」与「会失手」
2. **整体低估**：该档命中率 0.83，置信仅 0.61（gap 0.22）
3. **高置信档样本极少且可能反向**（0.70–0.85 两例全失手）
4. 当前 confidence **不能对外当概率使用**，只能标「流程完整度」

## 改进方向（P1）

- 用维度分数分布/证据完整度重标定 confidence 映射
- 多次采样一致性权重提高（一致↑ → 置信↑）
- 校准集与训练/评测分离，防泄漏
- UI 文案改为「分析完整度」而非「置信概率」
