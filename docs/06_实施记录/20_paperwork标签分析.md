# paperwork 源标签与能力差距分析

> 案例：`data/test/cases/paperwork/`（36 篇真实事件文案）
> 期望标签来自 `回测案例库索引.md` 的（高/中/低）

## 1. 抽样结果（6 案，sample-runs=3）

valid_accuracy=0.33，远低于 backtest 25 案 0.96。原因不在评测代码，而在**标签口径与 11 维能力错位**。

## 2. 标签口径问题

| 索引标签 | 期望档 | 11 维是否有对应 |
|----------|--------|-----------------|
| 法律合规 / 政治敏感 / 民族宗教 / 历史虚无 | 高 | ✅ 有 |
| **隐私侵犯 / 未成年人保护 / 学术诚信 / 知识产权 / 动物保护 / 食品安全** | 高/中 | ❌ **无一等维度** |
| 职场文化 / 消费信任 / 生态破坏 | 中 | 部分可落到道德/群体 |

**结论**：约 1/3 paperwork 期望依赖「11 维未覆盖」风险类型，模型给中低分是能力边界而非随机错误。

## 3. 与 backtest 的关系

- backtest 25 案：**标签对齐 11 维**，用于回归门禁（基线 0.96）
- paperwork 36 案：**真实事件综合风险**，适合能力评估，**不与 backtest 混基线**

## 4. 建议（P1）

1. paperwork 期望改为「11 维可判定子集」重新标注（法律/政治/民族/道德/情绪/价值观）
2. 或扩展维度：未成年人、隐私、知识产权（合规审计 11 亦提出）
3. 评测增加 `--expect-source` 区分标签体系

## 5. 当前口径

`tests/run_eval_regression.py --source cases` 结果单独解读，不写入 backtest `baseline.json`。
