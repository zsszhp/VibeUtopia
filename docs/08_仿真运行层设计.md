# VibeUtopia 仿真运行层设计

> 千级Agent在模拟社交平台上自由交互与社会演化：三层Agent架构、消息总线、5平台仿真引擎、行为决策引擎、仿真调度。

## 1. 设计理念

仿真运行层是VibeUtopia的"社会实验室"。它的核心任务是：**让千级具备独立人格的Agent在模拟社交平台上自由交互，涌现出与真实社会相似的舆论传播、立场分化和情绪蔓延模式。**

设计原则：
- **自主决策**：Agent不是按脚本行动，而是基于感知-思考-行动循环自主决策
- **分层调度**：不是所有Agent都需要昂贵的LLM决策，C级Agent用规则引擎
- **异步通信**：Agent间通过消息总线异步交互，不阻塞
- **平台特化**：每个平台有独特的行为模型和推荐机制
- **实时可观测**：仿真过程中可实时监控和干预

│  │ - 更新工作记忆(新行为记录)                          │  │

### 4.3 C级Agent规则引擎

C级Agent不需要LLM决策，使用规则引擎+本地小模型：

```python
class RuleEngine:
    """C级Agent规则引擎"""

    def decide(self, agent: AgentProfile, perception: PerceptionContext) -> PlatformAction:
        """基于规则的行为决策"""

        # 规则1: 高情感内容 → 大概率点赞/转发
        if perception.content_sentiment_score > 0.6 and random() < 0.7:
            return PlatformAction(action_type="LIKE", target_id=perception.content_id)

        # 规则2: 关注的人发帖 → 30%概率查看+10%概率互动
        if perception.is_from_followee and random() < 0.3:
            if random() < 0.33:
                content = self.local_model.generate_comment(agent, perception)
                return PlatformAction(action_type="COMMENT", content=content)
            else:
                return PlatformAction(action_type="LIKE")

        # 规则3: 与自己立场一致的内容 → 更可能互动
        if self._stance_alignment(agent, perception) > 0.7 and random() < 0.5:
            return PlatformAction(action_type="SHARE")

        # 规则4: 默认 → DO_NOTHING
        return PlatformAction(action_type="DO_NOTHING")
```

### 5.3 vs BettaFish ForumEngine对比

| 维度 | BettaFish ForumEngine | VibeUtopia 消息总线 |
|------|----------------------|-------------------|
| 通信介质 | 日志文件 | Redis Streams |
| 性能 | 文件I/O，秒级延迟 | 内存操作，毫秒级延迟 |
| 扩展性 | 固定4个Agent | 支持千级Agent |
| 通信模式 | 广播(论坛) | 广播+点对点 |
| 主持机制 | ForumHost每5条触发 | Director持续调度+Watcher实时观察 |
| 消费者组 | 无 | Redis消费者组，消息不重复 |
| 持久化 | 文件永久保存 | Redis AOF，可配置保留时间 |

### 8.2 仿真循环

```python
class SimulationLoop:
    """仿真主循环"""

    async def run(self, config: SimulationConfig):
        """执行一次完整仿真"""

        # 初始化
        agents = await self._load_agents(config)
        platforms = self._init_platforms(config)
        sim_time = config.start_time

        while sim_time < config.end_time:
            # 1. 确定当前活跃Agent集合
            active_agents = self._get_active_agents(agents, sim_time)

            # 2. 按优先级分组处理
            # A级: 全部LLM决策
            a_actions = await self._process_tier_a(active_agents["A"], sim_time)
            # B级: 2步1次LLM
            b_actions = await self._process_tier_b(active_agents["B"], sim_time)
            # C级: 规则引擎
            c_actions = self._process_tier_c(active_agents["C"], sim_time)

            # 3. 提交行为到平台仿真器
            all_actions = a_actions + b_actions + c_actions
            for platform in platforms:
                platform_actions = [a for a in all_actions if a.platform == platform.name]
                reactions = await platform.process_batch(platform_actions)

                # 4. 触发通知（被评论/点赞的Agent进入下一轮活跃）
                for reaction in reactions:
                    await self._notify_agent(reaction.target_agent_id, reaction)

            # 5. 协调Agent检查
            if self._should_coordinator_check(sim_time):
                await self._run_coordinators(sim_time, platforms)

            # 6. 推进仿真时间
            sim_time += timedelta(minutes=config.time_step_minutes)

            # 7. 检查点
            if self._should_checkpoint(sim_time):
                await self._save_checkpoint(sim_time)
```
