# VibeUtopia 分析决策层设计

> 从仿真结果中提取趋势、预测未来走向、提供决策辅助：趋势预测引擎、反事实仿真、报告生成。

## 1. 设计理念

分析决策层是VibeUtopia的"大脑"。它从仿真运行层产生的海量轨迹数据中提取洞察，回答三个核心问题：

1. **舆论会往哪里走？**（趋势预测）
2. **如果换一种做法会怎样？**（反事实仿真）
3. **应该怎么做？**（决策建议）

设计原则：
- **证据驱动**：每个预测都有仿真数据支撑，不凭空推断
- **不确定性标注**：预测不是预言，必须标注置信度和不确定性
- **可验证性**：预测结果可回溯到具体的Agent行为和传播路径
- **多策略对比**：不仅给出一个答案，而是展示多种可能性

## 3. 反事实仿真引擎

### 3.1 设计理念

**"如果...会怎样？"** — 反事实仿真是VibeUtopia最强大的能力之一。它允许用户在当前仿真状态的基础上，创建多个分支，每个分支注入不同的干预行动，然后并行运行，对比各分支的结果，从而选择最优策略。

```python
class CounterfactualEngine:
    """反事实仿真引擎"""

    async def create_branches(self, base_run_id: str,
                               interventions: List[Intervention]) -> List[str]:
        """从基础仿真创建多个分支"""

        # 1. 加载基础仿真的世界快照
        snapshot = await self._load_snapshot(base_run_id)

        branch_ids = []
        for intervention in interventions:
            # 2. 深拷贝世界快照（每个分支独立）
            branch_snapshot = deepcopy(snapshot)

            # 3. 注入干预
            await self._inject_intervention(branch_snapshot, intervention)

            # 4. 创建新的仿真运行
            branch_id = await self._start_branch_simulation(
                branch_snapshot, intervention, base_run_id
            )
            branch_ids.append(branch_id)

        return branch_ids

    async def compare_branches(self, branch_ids: List[str]) -> BranchComparison:
        """对比各分支结果"""

        results = {}
        for bid in branch_ids:
            results[bid] = await self._collect_metrics(bid)

        # 生成对比报告
        comparison = BranchComparison(
            metrics=self._build_comparison_table(results),
            ranking=self._rank_branches(results),
            recommendation=self._generate_recommendation(results)
        )
        return comparison


@dataclass
class Intervention:
    """干预行动"""
    intervention_id: str
    description: str             # 干预描述
    type: str                    # silence/respond/apologize/delete/clarify/legal
    content: Optional[str]       # 干预内容(如道歉声明文本)
    timing: str                  # immediate/delayed_6h/delayed_24h
    platform: str                # weibo/bilibili/all
    inject_as: str               # blogger/official_account/media
```

## 5. 预测准确性保障机制

### 5.1 多轮仿真共识

```
┌──────────────────────────────────────────────────────┐
│              多轮仿真共识机制                           │
│                                                       │
│  问题: 单次仿真结果有随机性，不可靠                     │
│  方案: 运行3-5次仿真，取共识                           │
│                                                       │
│  仿真1: 舆论走向 = 上涨(60%)                          │
│  仿真2: 舆论走向 = 上涨(55%)                          │
│  仿真3: 舆论走向 = 持平(52%)                          │
│                                                       │
│  共识: 舆论大概率上涨(58%±4%)                          │
│  置信度: 中等 (2/3一致)                                │
│                                                       │
│  规则:                                                │
│  - 3次中2次以上一致 → 标注为"较可信"                   │
│  - 3次全部一致 → 标注为"高可信"                        │
│  - 3次各不相同 → 标注为"不确定" + 提示增加仿真次数     │
└──────────────────────────────────────────────────────┘
```

### 5.3 历史回测

```python
class Backtester:
    """历史回测 - 验证预测准确性"""

    async def backtest(self, historical_event: SeedEvent,
                        actual_outcome: str) -> BacktestResult:
        """用历史事件回测预测模型"""

        # 1. 用历史事件的种子信息运行仿真
        prediction = await self._run_prediction(historical_event)

        # 2. 对比预测与实际结果
        accuracy = self._compare(prediction, actual_outcome)

        # 3. 分析偏差原因
        deviation_analysis = await self._analyze_deviation(prediction, actual_outcome)

        return BacktestResult(
            event=historical_event.title,
            predicted=prediction,
            actual=actual_outcome,
            accuracy=accuracy,
            deviation_analysis=deviation_analysis
        )
```
