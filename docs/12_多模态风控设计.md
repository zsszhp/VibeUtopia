# VibeUtopia 多模态风控设计

> 支持视频画面和音频的多模态分析，让风控覆盖"每个画面"——原始需求明确要求"每句台词，每个画面，可能有什么风险，或者爆点"。

## 1. 设计理念

当前风控只能分析文字内容。但博主的发布物是视频——画面中可能包含敏感图像、不当着装、争议性文字（字幕/贴图），音频中可能包含不当言辞、敏感背景音乐。文字风控只能覆盖"台词"，无法覆盖"画面"。

多模态风控的目标：**从只审文字到审画面+审音频，让风控覆盖视频的每个维度。**

设计原则：
- **文字优先**：文字风控是基础，多模态是增强，不可替代文字分析
- **关键帧策略**：不可能逐帧审核，通过关键帧提取覆盖视频核心画面
- **降级可用**：每个模态都可独立降级，不因单一模态失败阻塞整体评估
- **成本可控**：视频分析成本应控制在文字分析的2-3倍以内

## 2. 整体架构

```
视频文件/链接
     │
     ├──▶ 文案提取（MVP已有：yt-dlp）
     │         │
     │         ▼
     │    文字风控流程（MVP + R1仿真增强）
     │
     ├──▶ 关键帧提取（新增）
     │         │
     │         ├──▶ OCR文字识别 → 文字风控
     │         ├──▶ 画面风险评估 → 敏感图像检测
     │         └──▶ 画面-文案一致性检查
     │
     └──▶ 音频分析（新增）
               │
               ├──▶ 语音转写 → 文字风控
               └──▶ 情感分析 → 语气/情绪风险评估

     ▼
综合风控报告 = 文字风险 + 画面风险 + 音频风险 + 交叉风险
```

## 3. 关键帧提取

### 3.1 提取策略

```python
class KeyFrameExtractor:
    """关键帧提取器"""

    STRATEGIES = {
        "scene_change": {
            "description": "场景切换检测，提取场景变化帧",
            "tool": "FFmpeg + PySceneDetect",
            "typical_frames": "10-30帧/10分钟视频",
            "priority": 0  # 最高优先
        },
        "interval": {
            "description": "固定间隔提取，确保覆盖",
            "tool": "FFmpeg",
            "interval": "30秒",  # 每30秒一帧
            "typical_frames": "20帧/10分钟视频",
            "priority": 1
        },
        "face_detection": {
            "description": "含人脸的帧（可能涉及人物形象风险）",
            "tool": "OpenCV + face_recognition",
            "priority": 2
        },
        "text_detection": {
            "description": "含文字的帧（字幕/贴图/水印）",
            "tool": "OpenCV + East text detector",
            "priority": 2
        }
    }

    async def extract(self, video_path: str) -> List[KeyFrame]:
        """提取关键帧"""

        # 1. 场景切换检测
        scene_frames = self._detect_scene_changes(video_path)

        # 2. 固定间隔补充（确保覆盖）
        interval_frames = self._extract_interval(video_path)

        # 3. 合并去重
        all_frames = self._merge_and_dedup(scene_frames, interval_frames)

        # 4. 限制总数（最多50帧）
        if len(all_frames) > 50:
            all_frames = self._rank_and_select(all_frames, max_count=50)

        return all_frames
```

### 3.2 关键帧数据模型


## 4. 画面风险评估

### 4.1 OCR文字识别

```python
class FrameOCR:
    """关键帧OCR"""

    async def recognize(self, key_frame: KeyFrame) -> List[TextRegion]:
        """识别关键帧中的文字"""

        # 使用PaddleOCR识别文字区域
        results = self.ocr.ocr(key_frame.image_path)

        text_regions = []
        for result in results:
            text_regions.append(TextRegion(
                text=result['text'],
                confidence=result['confidence'],
                position=result['position'],  # 文字在画面中的位置
                type=self._classify_text(result['text'], result['position'])
                # type: subtitle(字幕) / watermark(水印) / overlay(贴图) / background(背景文字)
            ))

        return text_regions
```

OCR识别出的文字，直接送入文字风控流程进行7维评估。

### 4.2 画面内容审核

```python
class VisualRiskAssessor:
    """画面风险评估"""

    RISK_CATEGORIES = [
        "敏感人物形象",      # 政治人物/争议人物
        "不当着装/暴露",     # 衣着不当
        "暴力血腥内容",      # 武器/血腥画面
        "争议性标志/符号",   # 敏感标志/旗帜
        "不当手势/行为",     # 具有争议性的手势
        "低俗内容",         # 低俗/擦边内容
    ]

    async def assess(self, key_frame: KeyFrame) -> VisualRiskResult:
        """评估关键帧的画面风险"""

        # 方案1: LLM视觉模型（如GPT-4V/Qwen-VL）
        # 适合：复杂场景理解、上下文判断
        llm_result = await self._assess_with_vlm(key_frame)

        # 方案2: 专用审核API（如阿里云内容安全/腾讯云图片审核）
        # 适合：标准化的审核需求、低延迟
        api_result = await self._assess_with_api(key_frame)

        # 合并结果
        return self._merge_results(llm_result, api_result)
```

## 5. 音频分析

### 5.1 语音转写

```python
class AudioAnalyzer:
    """音频分析器"""

    async def transcribe(self, video_path: str) -> AudioTranscription:
        """语音转写"""

        # 1. 提取音频轨道
        audio_path = self._extract_audio(video_path)

        # 2. 语音转写
        # 使用 faster-whisper（本地）或 云端ASR
        segments = self.whisper_model.transcribe(audio_path)

        # 3. 组装带时间戳的转写文本
        return AudioTranscription(
            full_text=" ".join(s.text for s in segments),
            segments=[
                TranscriptSegment(
                    text=s.text,
                    start=s.start,
                    end=s.end,
                    confidence=s.confidence
                ) for s in segments
            ]
        )
```

## 6. 综合风控报告

### 6.1 交叉风险检测

```
文字风险 × 画面风险 × 音频风险 = 交叉风险

例如：
- 文字提到某群体 + 画面出现争议手势 → 交叉风险升级
- 文字正常 + 画面出现敏感标志 → 纯画面风险
- 音频语气激烈 + 文字内容激进 → 交叉风险升级
```

### 6.2 多模态报告结构

```python
@dataclass
class MultimodalRiskReport:
    """多模态风控报告"""

    # 文字风险（已有）
    text_risk: EnhancedRiskReport         # R1的仿真增强风控报告

    # 画面风险（新增）
    visual_risks: List[VisualRiskResult]  # 各关键帧的画面风险
    ocr_risks: List[RiskAssessment]       # OCR文字的风险
    visual_summary: str                    # 画面风险总结

    # 音频风险（新增）
    audio_transcription: str               # 语音转写全文
    audio_risk: EnhancedRiskReport         # 转写文本的风控报告
    audio_emotion: AudioEmotionResult      # 音频情感分析
    audio_summary: str                     # 音频风险总结

    # 交叉风险（新增）
    cross_risks: List[CrossRisk]           # 文字×画面×音频交叉风险

    # 综合评估
    overall_risk: int                      # 综合风险分 0-100
    risk_level: str                        # safe/low/medium/high/critical
    key_findings: List[str]                # 关键发现
    recommendations: List[str]             # 建议
```

## 8. 降级策略

| 模态 | 主方案 | 降级方案 | 再降级 |
|------|--------|---------|--------|
| 关键帧 | 场景切换+间隔提取 | 仅间隔提取 | 仅首帧+末帧 |
| OCR | PaddleOCR | EasyOCR | 跳过OCR |
| 画面审核 | LLM视觉模型 | 云端审核API | 跳过画面审核 |
| 语音转写 | faster-whisper | 云端ASR | 使用视频字幕 |
| 情感分析 | 音频SER模型 | 文本情感分析 | 跳过情感分析 |

## 9. 实现优先级

| 优先级 | 模块 | 理由 |
|--------|------|------|
| P0 | 关键帧提取 | 多模态的基础 |
| P0 | OCR文字识别 | 低成本高价值，直接复用文字风控 |
| P1 | 画面风险评估 | 核心新增能力 |
| P1 | 语音转写 | 复用文字风控 |
| P2 | 音频情感分析 | 增强维度 |
| P2 | 交叉风险检测 | 需要各模态数据齐备 |
| P3 | 综合报告 | 前端展示需要 |
