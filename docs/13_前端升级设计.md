# VibeUtopia 前端升级设计

> 从Streamlit迁移到Vue3 + 完整可视化，让仿真过程和预测结果"看得见"。

## 1. 设计理念

Streamlit是快速原型工具，适合MVP验证。但无法支持：
- 实时仿真大屏（WebSocket + 大规模图渲染）
- 交互式传播网络（D3.js力导向图）
- 博主画像仪表盘
- 多模态审核面板

Vue3迁移的目标：**让V2.R1-R4的能力通过专业的前端完整展现。**

设计原则：
- **功能对等**：所有MVP+R1-R4功能在Vue3中等效实现
- **渐进迁移**：Streamlit和Vue3可并行运行，逐步切换
- **组件化**：每个可视化组件独立，可复用
- **性能优先**：仿真大屏支持1000节点流畅渲染

## 2. 技术栈

| 层 | 技术 | 说明 |
|----|------|------|
| 框架 | Vue3 + TypeScript | 组合式API |
| 构建 | Vite | 快速开发构建 |
| UI库 | Element Plus | 成熟的企业级Vue3组件库 |
| 状态 | Pinia | Vue3官方推荐状态管理 |
| 路由 | Vue Router | SPA路由 |
| 图表 | ECharts | 雷达图/折线图/热力图 |
| 网络图 | D3.js | 传播网络力导向图 |
| 通信 | WebSocket (native) | 仿真实时推送 |
| HTTP | Axios | API请求 |
| 样式 | TailwindCSS | 快速样式开发 |

## 6. 迁移策略

### 6.1 并行运行期

```
Streamlit (8501端口)          Vue3 (3000端口)
    │                              │
    └────── 共享后端 (8000端口) ─────┘
```

两个前端共享同一个FastAPI后端。逐步将功能从Streamlit迁移到Vue3。

### 6.2 迁移顺序

| 阶段 | 迁移内容 | Streamlit保留 |
|------|---------|--------------|
| 1 | 风控工作台 + 7维雷达图 | 视频提取、信号、图谱、人格、仿真 |
| 2 | 仿真大屏 + 传播网络 | 视频提取、信号、图谱、人格 |
| 3 | 多模态审核面板 | 信号、图谱、人格 |
| 4 | 博主画像 + 竞品对比 | 无 → 退役Streamlit |

## 7. 实现优先级

| 优先级 | 模块 | 理由 |
|--------|------|------|
| P0 | Vue3项目初始化 + 路由 + 状态管理 | 基础 |
| P0 | 风控工作台（文案输入+评估+报告） | 核心功能 |
| P0 | 7维雷达图(ECharts) | 风控报告核心可视化 |
| P1 | 仿真大屏 + 传播网络图(D3.js) | 差异化体验 |
| P1 | WebSocket实时推送 | 仿真大屏必要 |
| P2 | 情感时间线 + 平台热力图 | 增强可视化 |
| P2 | 多模态审核面板 | R4配套 |
| P3 | 仿真回放时间轴 | 体验增强 |
| P3 | 博主画像仪表盘 | R6配套 |
