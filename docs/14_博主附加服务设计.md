# VibeUtopia 博主附加服务设计

> 为博主提供风格画像、选题推荐和竞品对标——原始需求Idea2+3，"之后迁移"的附加功能。

## 1. 设计理念

博主服务是风控的附加延伸，核心场景：
- **Idea2**：深入熟悉博主视频风格→检索热点→推荐选题+预测效果
- **Idea3**：竞品账号对标→拆解成功要素→给出建议

设计原则：
- **风控为锚**：选题推荐和竞品分析始终关联风控——不只是"什么火"，更是"什么安全又有效"
- **复用优先**：复用已有的视频提取、LLM分析、信号采集、知识图谱、仿真引擎
- **成本可控**：博主服务不应依赖大规模仿真，轻量分析为主

## 2. 博主风格画像

### 2.1 数据来源

```
输入：博主账号链接（B站/抖音/小红书）
  │
  ├──▶ 批量提取历史视频文案（复用video_extractor）
  │
  ├──▶ 提取账号基本信息（粉丝数/分区/标签等，爬取或手动输入）
  │
  └──▶ 补充：已做过的风控评估历史（如有）
```

### 2.2 画像维度

```python
@dataclass
class BloggerProfile:
    """博主风格画像"""

    blogger_id: str
    platform: str
    basic_info: BasicInfo              # 基本信息

    # 5维风格画像
    vocabulary: VocabularyProfile      # 词汇偏好
    expression: ExpressionProfile      # 表达风格
    topic: TopicProfile                # 主题偏好
    audience: AudienceProfile          # 受众画像
    risk: RiskPreference               # 风险偏好

    # 衍生
    style_summary: str                 # 风格一句话总结
    strengths: List[str]               # 内容优势
    risk_areas: List[str]              # 风险倾向区域

@dataclass
class VocabularyProfile:
    """词汇偏好"""
    high_freq_words: List[str]         # 高频词Top20
    catchphrases: List[str]            # 口头禅/特色表达
    tone: str                          # 语气：正式/幽默/亲切/犀利
    vocabulary_level: str              # 词汇水平：通俗/中等/专业

@dataclass
class ExpressionProfile:
    """表达风格"""
    narrative_style: str               # 叙事型/说理型/情感型/幽默型/科普型
    structure: str                     # 开门见山/铺垫高潮/对话式/流水账
    interaction_style: str             # 互动方式：提问/吐槽/共情/教学
    pacing: str                        # 节奏：快节奏/慢叙事/混合

@dataclass
class TopicProfile:
    """主题偏好"""
    primary_topics: List[str]          # 主要内容领域
    secondary_topics: List[str]        # 次要领域
    topic_distribution: Dict[str, float]  # 主题分布
    trending_sensitivity: float        # 追热点倾向度(0-1)

@dataclass
class AudienceProfile:
    """受众画像"""
    estimated_age_range: str           # 推测受众年龄段
    estimated_gender_ratio: Dict       # 推测性别比例
    estimated_interests: List[str]     # 推测受众兴趣
    engagement_pattern: str            # 互动模式：弹幕多/评论多/收藏多

@dataclass
class RiskPreference:
    """风险偏好"""
    historical_risk_score: float       # 历史内容平均风险分
    risk_dimensions: Dict[str, float]  # 各维度风险倾向
    safe_zones: List[str]              # 安全话题区
    danger_zones: List[str]            # 高风险话题区
```

### 2.3 画像生成流程

```python
class BloggerProfiler:
    """博主画像生成器"""

    async def generate(self, account_url: str) -> BloggerProfile:
        """生成博主风格画像"""

        # 1. 提取历史视频文案
        transcripts = await self.video_extractor.batch_extract(account_url)

        # 2. LLM分析风格
        style_analysis = await self.llm_client.chat(
            prompt=BLOGGER_STYLE_PROMPT,
            variables={"transcripts": transcripts}
        )

        # 3. 关联热点数据
        topic_analysis = await self._analyze_topics(transcripts)

        # 4. 风险偏好分析（基于风控历史或LLM评估）
        risk_analysis = await self._analyze_risk_preference(transcripts)

        # 5. 组装画像
        return BloggerProfile(
            blogger_id=generate_id(),
            platform=detect_platform(account_url),
            basic_info=self._extract_basic_info(account_url),
            vocabulary=style_analysis.vocabulary,
            expression=style_analysis.expression,
            topic=topic_analysis,
            audience=style_analysis.audience,
            risk=risk_analysis,
            style_summary=style_analysis.summary,
            strengths=style_analysis.strengths,
            risk_areas=risk_analysis.danger_zones,
        )
```

## 3. 选题推荐引擎

### 3.1 推荐逻辑

```
当前热点（V2.1信号采集）
     │
     ×  博主风格画像
     │
     ├──▶ 匹配度评分：热点 × 博主擅长领域
     │
     ├──▶ 切入点生成：LLM生成3-5个不同切入角度
     │
     ├──▶ 风险预筛：每个选题的7维风险快速评估
     │
     └──▶ 效果预测：轻量仿真预测各选题的预期反应
```

### 3.2 选题推荐输出

```python
@dataclass
class TopicRecommendation:
    """选题推荐"""
    topic_id: str
    title: str                          # 选题标题
    hot_event: str                      # 关联热点事件
    angle: str                          # 切入角度
    match_score: float                  # 与博主风格的匹配度
    risk_level: str                     # 风险等级
    risk_dimensions: List[str]          # 涉及的风险维度
    estimated_reach: str                # 预期覆盖人群
    key_points: List[str]               # 内容要点建议
    cautions: List[str]                 # 注意事项
```

## 4. 竞品对标

### 4.1 对标流程

```
输入：博主A + 竞品B
     │
     ├──▶ 分别生成风格画像
     │
     ├──▶ 差异化对比
     │     ├── 主题差异
     │     ├── 风格差异
     │     ├── 受众差异
     │     └── 风险差异
     │
     ├──▶ 成功要素拆解（竞品B）
     │     ├── 选题策略
     │     ├── 表达技巧
     │     ├── 发布节奏
     │     └── 互动方式
     │
     └──▶ 差异化建议
           ├── 可借鉴的元素
           ├── 差异化方向
           └── 应避免的雷同
```

### 4.2 竞品分析输出

```python
@dataclass
class CompetitorComparison:
    """竞品对比"""
    blogger_profile: BloggerProfile
    competitor_profile: BloggerProfile

    # 差异对比
    topic_diff: DiffResult              # 主题差异
    style_diff: DiffResult              # 风格差异
    audience_diff: DiffResult           # 受众差异
    risk_diff: DiffResult               # 风险差异

    # 成功要素
    success_factors: List[SuccessFactor]  # 竞品的成功要素

    # 建议
    learnings: List[str]                # 可借鉴的元素
    differentiation: List[str]          # 差异化方向
    avoid_list: List[str]               # 应避免的雷同
```

## 7. 实现优先级

| 优先级 | 模块 | 理由 |
|--------|------|------|
| P0 | 博主账号分析（视频批量提取+风格画像） | 基础能力 |
| P0 | 博主画像数据模型 | 存储 |
| P1 | 选题推荐引擎 | 核心价值 |
| P1 | 博主画像前端Tab | 用户可见 |
| P2 | 竞品对标 | 需要画像能力成熟 |
| P2 | 竞品对比前端Tab | 用户可见 |
| P3 | 流量预测 | 需要R4轻量仿真支撑 |
| P3 | 文案生成辅助 | 锦上添花 |
