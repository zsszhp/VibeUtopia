## 1. 设计理念 [暂不实现]

博主服务是风控的附加延伸，核心场景：
- **Idea2**：深入熟悉博主视频风格 → 检索热点 → 推荐选题+预测效果
- **Idea3**：竞品账号对标 → 拆解成功要素 → 给出建议

设计原则：
- **风控为锚**：选题推荐和竞品分析始终关联风控——不只是"什么火"，更是"什么安全又有效"
- **复用优先**：复用已有的视频提取、LLM分析、信号采集、知识图谱、仿真引擎
- **成本可控**：博主服务不应依赖大规模仿真，轻量分析为主

> 以上原则在未来实现时仍然适用，但当前不做任何开发。

## 2. 博主风格画像 [暂不实现]

### 2.1 数据来源

```
输入：博主账号链接（B站/抖音/小红书）
  │
  ├──▶ 批量提取历史视频文案（复用video_extractor）
  │
  ├──▶ 提取账号基本信息（粉丝数/分区/标签等，爬取或手动输入）
  │
  └──▶ 补充：已做过的风控评估历史（如有）
```

    """博主画像生成器 [暂不实现]"""

        """生成博主风格画像"""

        # 1. 提取历史视频文案

## 3. 选题推荐引擎 [暂不实现]

### 3.1 推荐逻辑

```
当前热点（信号采集层）
     │
     ×  博主风格画像
     │
     ├──▶ 匹配度评分：热点 × 博主擅长领域
     │
     ├──▶ 切入点生成：LLM生成3-5个不同切入角度
     │
     ├──▶ 风险预筛：每个选题的7维风险快速评估
     │
     └──▶ 效果预测：轻量仿真预测各选题的预期反应
```
