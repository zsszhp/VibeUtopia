## 需要你手动操作的事项

### 必须手动完成（AI无法自动完成）

| 序号 | 事项 | 具体操作 | 卡住原因 |
|------|------|---------|---------|
| 1 | **GitHub推送** | 终端执行: `git push github main --tags` | 网络连接被重置，需在网络稳定时重试 |
| 2 | **配置API Key** | 编辑`.env`文件，填入DEEPSEEK_API_KEY等 | 需要你的真实密钥，AI无法生成 |
| 3 | **PyTorch安装** | `pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121` | 2GB+下载，需确认GPU型号选对应CUDA版本 |
| 4 | **安装后验证** | 启动后端: `python -m uvicorn backend.main:app --reload`，访问 http://localhost:8000/docs 确认5个核心API可响应 | 需要API Key才能实际调用LLM |

### 可选安装（不影响核心功能）

| 序号 | 事项 | 操作 | 影响范围 |
|------|------|------|---------|
| 5 | Neo4j | 下载安装或Docker | 知识图谱功能需要，Lite模式可跳过 |
| 6 | MySQL | Windows安装包 | 多用户/高并发需要，SQLite降级可用 |
| 7 | ChromaDB | `pip install chromadb` | 阶段3-4向量检索需要，当前不阻塞 |
| 8 | Python 3.10+ | conda升级 | 部分新库兼容性更好，3.9当前可用 |

### 不需要换Linux

当前Windows 11环境完全可以运行VibeUtopia的全部核心功能。Lite模式（全API调用）对操作系统无特殊要求。只有极少数Linux专属工具（如某些爬虫依赖），在API优先策略下不需要。
