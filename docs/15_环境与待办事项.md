## 需要你手动操作的事项

### 必须手动完成 (按 16 文档顺序)

1. **GitHub 推送**: `git push github main`
2. **Ubuntu 环境搭建**: 按照 **[16_开发环境搭建指南](./16_开发环境搭建指南.md)** 在 Ubuntu 上完成所有安装。
3. **Docker 启动**: `docker compose up -d` 启动 MySQL + Neo4j。
4. **API Key 配置**: 在 `.env` 中填入你的密钥。
5. **验证连接**: 运行 `uvicorn backend.main:app --reload` 确认 8000 端口可用。
