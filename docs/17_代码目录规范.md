# VibeUtopia 代码目录规范 (17)

## 1. 目标
为了应对从 MVP 到万级 Agent 仿真的复杂性演进，建立清晰的职责边界，防止 `backend/` 目录陷入混乱。

## 3. 开发规范 (Best Practices)

### 3.1 异步优先
- 所有 I/O 操作（数据库、LLM API、文件读取）必须使用 `async/await`。
- 严禁在主线程使用 `time.sleep()`，必须使用 `asyncio.sleep()`。

### 3.2 类型标注
- 所有函数必须包含类型标注 (Type Hints)。
- 使用 Pydantic 进行输入验证和输出序列化。

### 3.3 数据库访问
- 统一通过 `backend/db/` 下的 Repository 或 Session 访问。
- 严禁在 `routes.py` 中直接编写复杂的 SQL/ORM 逻辑。

### 3.4 异常处理
- 使用自定义异常类并结合 FastAPI 的 `exception_handler` 返回标准错误码。

### 3.5 模型调用
- 所有 LLM 调用必须通过 `backend/services/llm/`，以便于统一管理 Token 统计、重试逻辑和 Tier 切换。

---

## 4. 迁移路径 (MVP -> V2)

1. **短期 (阶段1)**: 维持 `backend/` 下的扁平目录，但逻辑上按上述规范分包。
2. **中期 (阶段2)**: 将 `routes.py` 的 2000+ 行代码拆分到 `backend/api/v1/`。
3. **长期 (阶段3+)**: 将 `simulation` 独立为子包，支持独立部署。
