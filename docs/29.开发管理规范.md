# Ubuntu 22.04/24.04 单分区1T硬盘 多项目开发环境管理规范
**版本**：v1.0  
**适用场景**：单分区1T硬盘、多项目开发（AI/工业检测/Web等）、对标Windows Anaconda使用习惯  
**核心思想**：严格遵循FHS标准，构建"全局资源共享+项目完全隔离"的分层架构，兼顾稳定性、可维护性和资源利用率

---

## 一、核心原则（必须遵守）
1. **FHS标准优先**：所有文件/软件严格按照Linux文件系统层次结构标准存放
2. **隔离优先**：不同项目的运行环境完全隔离，避免依赖冲突
3. **全局共享**：大文件（大模型、Docker镜像）和通用服务（数据库）全局共享，避免重复存储
4. **代码与数据分离**：代码放在`/home`（便于备份/版本控制），运行时大数据放在`/var`
5. **权限最小化**：个人目录操作无需sudo，系统级操作才使用sudo

## 三、全局共享资源管理规范
### 3.1 全局大模型仓库（所有AI项目共用）
**统一路径**：`/var/lib/models/`  
**目的**：避免每个项目重复下载大模型，节省数百GB空间

#### 初始化命令
```bash
# 创建全局模型目录并设置正确权限
sudo mkdir -p /var/lib/models/{ollama,vllm,huggingface}
sudo chown -R $USER:$USER /var/lib/models

# 配置Hugging Face缓存路径
echo 'export HF_HOME=/var/lib/models/huggingface' >> ~/.bashrc
source ~/.bashrc

# 迁移Ollama模型到全局目录
mv ~/.ollama/models/* /var/lib/models/ollama/
rm -rf ~/.ollama/models
ln -s /var/lib/models/ollama ~/.ollama/models
```

#### 使用方式
在项目的`.env`文件中指定模型路径：
```env
OLLAMA_MODEL_PATH=/var/lib/models/ollama/qwen3:72b
HUGGINGFACE_MODEL_PATH=/var/lib/models/huggingface/bert-base-uncased
```

### 3.2 全局数据库服务
**原则**：启动一个全局Docker实例，每个项目创建独立的数据库/集合隔离数据

| 数据库 | 全局路径 | 项目隔离方式 |
|--------|----------|--------------|
| MySQL 8.0 | `/var/lib/mysql/` | 每个项目创建独立数据库和用户 |
| Neo4j 5.x | `/var/lib/neo4j/` | 每个项目创建独立数据库 |
| ChromaDB | `/var/lib/chroma/` | 每个项目使用独立的集合名称 |

#### MySQL项目隔离示例
```sql
-- 为VibeUtopia项目创建独立数据库和用户
CREATE DATABASE vibeutopia_db;
CREATE USER 'vibe_user'@'%' IDENTIFIED BY 'your_secure_password';
GRANT ALL PRIVILEGES ON vibeutopia_db.* TO 'vibe_user'@'%';
FLUSH PRIVILEGES;
```

### 3.3 全局工具链安装规范
| 安装方式 | 推荐路径 | 适用场景 |
|----------|----------|----------|
| apt包管理器 | `/usr/bin` | 系统基础工具（git、docker、python3.11、google-chrome等） |
| 手动编译 | `/usr/local/bin` | 全局通用工具（vLLM、Ollama、cmake等） |
| 独立二进制包 | `/opt/软件名` | 大型独立软件（JetBrains IDE、VS Code等） |
| 个人级工具 | `~/.local/bin` | 仅个人使用的小工具、脚本 |

### 3.4 全局缓存管理
**目的**：将大缓存从个人目录迁移到`/var/cache`，避免占满个人空间

#### 初始化命令
```bash
# Chrome缓存迁移
mkdir -p /var/cache/google-chrome/$USER
mv ~/.cache/google-chrome/Default/Cache /var/cache/google-chrome/$USER/
ln -s /var/cache/google-chrome/$USER/Cache ~/.cache/google-chrome/Default/Cache

# pip缓存配置
mkdir -p /var/cache/pip/$USER
pip config set global.cache-dir /var/cache/pip/$USER

# npm缓存配置
mkdir -p /var/cache/npm/$USER
npm config set cache /var/cache/npm/$USER
```

## 五、多层级环境隔离体系（对标Windows Anaconda）
### 5.1 隔离级别选择指南
| 隔离级别 | 工具 | 适用场景 | 隔离程度 | 对标Windows |
|----------|------|----------|----------|-------------|
| 1. Python环境隔离 | `venv`（内置）/ `conda` | 纯Python项目，依赖差异小 | Python包级 | Anaconda虚拟环境 |
| 2. 语言版本隔离 | `pyenv` / `nvm` | 需要不同版本的Python/Node.js | 语言运行时级 | Anaconda多Python版本 |
| 3. 系统依赖隔离 | `conda-forge` / `micromamba` | 需要CUDA、OpenCV等系统依赖 | 系统库级 | Anaconda带C库的环境 |
| 4. 完全隔离 | Docker / Dev Containers | 复杂多服务项目、依赖差异极大 | 操作系统级 | WSL2 + 独立虚拟机 |

### 5.2 Python环境隔离（主力方案）
#### 5.2.1 首选：Python内置`venv`（轻量无依赖）
**完全对标Windows Anaconda虚拟环境**，是Python3.3+官方内置工具

| 操作 | Windows Anaconda | Linux venv |
|------|------------------|------------|
| 创建环境 | `conda create -n env_name python=3.11` | `python3.11 -m venv venv` |
| 激活环境 | `conda activate env_name` | `source venv/bin/activate` |
| 退出环境 | `conda deactivate` | `deactivate` |
| 导出依赖 | `conda list --export > requirements.txt` | `pip freeze > requirements.txt` |
| 导入依赖 | `pip install -r requirements.txt` | `pip install -r requirements.txt` |
| 删除环境 | `conda remove -n env_name --all` | `rm -rf venv` |

#### 5.2.2 备选：`conda` / `micromamba`（AI/数据科学项目）
适合需要复杂系统依赖（如CUDA、cuDNN）的项目，推荐安装**Miniconda**（轻量版）

```bash
# 创建包含CUDA12.1的环境
conda create -n defect python=3.11 cudatoolkit=12.1
# 激活环境
conda activate defect
# 安装PyTorch
conda install pytorch torchvision torchaudio pytorch-cuda=12.1 -c pytorch -c nvidia
```

### 5.3 语言版本隔离
#### 5.3.1 Python版本管理：`pyenv`
解决不同项目需要不同Python版本的问题
```bash
# 安装pyenv
curl https://pyenv.run | bash
# 安装指定Python版本
pyenv install 3.10.15
pyenv install 3.11.9
# 项目局部Python版本（进入目录自动切换）
cd ~/projects/ai/old-project
pyenv local 3.10.15
```

#### 5.3.2 Node.js版本管理：`nvm`
```bash
# 安装nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
# 安装Node.js版本
nvm install 20
nvm use 20
```

### 5.4 完全隔离：Docker/Dev Containers
适合复杂多服务项目，彻底解决"在我电脑上能跑"的问题
- 全局共享Docker引擎（`/var/lib/docker`）
- 每个项目有自己的`docker-compose.yml`定义专属服务
- 推荐使用VS Code Dev Containers，一键启动完整开发环境

## 六、谷歌相关文件管理规范
### 6.1 Chrome浏览器
- 安装：`sudo apt install google-chrome-stable`（自动到`/usr/bin`）
- 个人配置（书签/扩展/密码）：`~/.config/google-chrome/`（**定期加密备份到Google Drive**）
- 缓存：已迁移到`/var/cache/google-chrome/$USER`
- 下载目录：`~/Downloads`，按项目创建子目录（如`~/Downloads/VibeUtopia`）

### 6.2 Google Drive同步（首选rclone）
rclone是行业标准云存储挂载工具，支持90+云服务
```bash
# 安装rclone
curl https://rclone.org/install.sh | sudo bash
# 配置Google Drive账号
rclone config
# 自动挂载（添加到~/.bashrc）
echo 'if [ -x "$(command -v rclone)" ]; then
    mkdir -p ~/GoogleDrive
    rclone mount gdrive: ~/GoogleDrive --daemon --vfs-cache-mode writes
fi' >> ~/.bashrc
```

### 6.3 多项目密钥管理
- 所有API密钥、数据库密码等敏感信息**加密存放在Google Drive的`密钥/`目录**
- 每个项目的`.env`文件只存放本地配置，**绝对不能提交到Git**
- 定期备份所有密钥到离线存储

## 七、备份策略（单分区环境必备）
### 7.1 每日自动备份（脚本实现）
- 备份内容：所有项目代码、`~/.config`目录、`/etc`关键配置
- 备份位置：`~/backups/daily/`
- 保留周期：7天

### 7.2 每周全量备份
- 备份内容：每日备份内容 + MySQL/Neo4j数据库全量备份
- 备份位置：`~/backups/weekly/`
- 保留周期：4周

### 7.3 云端备份
- 备份内容：每周全量备份的加密压缩包
- 备份位置：Google Drive
- 保留周期：3个月

### 7.4 离线备份
- 备份内容：最重要的项目代码和文档
- 备份位置：外接移动硬盘
- 频率：每月一次

## 八、日常操作规范与避坑指南
### 8.1 必须遵守的规则
1. 每个项目必须使用独立的虚拟环境
2. 永远不要用`sudo pip install`安装任何包
3. 永远不要在全局Python环境安装项目依赖
4. 虚拟环境、大文件和敏感信息绝对不能提交到Git
5. 所有全局大文件必须存放在`/var`目录下
6. 定期清理Docker无用资源和系统缓存

### 8.2 绝对不能做的事
- ❌ 不要把项目代码放在`/opt`或`/usr`目录下
- ❌ 不要混用`venv`和`conda`在同一个项目
- ❌ 不要在容器内存储数据（必须挂载到宿主机）
- ❌ 不要修改`/bin`、`/sbin`、`/boot`等系统核心目录
- ❌ 不要删除`/var/log`下的系统日志文件

### 8.3 常用管理命令
```bash
# 查看磁盘使用情况
df -h
# 查看大文件
du -sh /var/lib/* | sort -hr
# 清理Docker无用资源
docker system prune -a
# 清理pip缓存
pip cache purge
# 查看所有Python虚拟环境
ls -d ~/projects/*/venv
# 查看所有conda环境
conda env list
```

## 九、快速上手操作清单
1. **创建全局目录结构**
   ```bash
   sudo mkdir -p /var/lib/models/{ollama,vllm,huggingface} /var/cache/{pip,npm,google-chrome}/$USER
   sudo chown -R $USER:$USER /var/lib/models /var/cache/{pip,npm,google-chrome}
   mkdir -p ~/projects/{ai,web,embedded,tools} ~/backups/{daily,weekly} ~/tmp
   ```

2. **配置全局环境变量**
   ```bash
   echo 'export HF_HOME=/var/lib/models/huggingface' >> ~/.bashrc
   echo 'export PATH=$HOME/.local/bin:$PATH' >> ~/.bashrc
   source ~/.bashrc
   ```

3. **安装基础工具**
   ```bash
   sudo apt update && sudo apt install -y git docker-compose python3.11 python3.11-venv google-chrome-stable
   ```

4. **安装rclone并配置Google Drive**
   ```bash
   curl https://rclone.org/install.sh | sudo bash
   rclone config
   ```

5. **创建第一个项目**
   ```bash
   cd ~/projects/ai
   mkdir VibeUtopia && cd VibeUtopia
   python3.11 -m venv venv
   source venv/bin/activate
   # 创建标准项目目录
   mkdir src tests docs data scripts
   touch .env .gitignore requirements.txt README.md
   ```
