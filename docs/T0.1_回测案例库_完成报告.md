## 案例库设计特点

### 1. 结构化期望定义

每个案例不仅包含期望风险等级，还定义了：
- **各维度期望**: 每个风险维度的期望严重程度和分数范围
- **平台反应期望**: 各平台期望的情绪倾向和负面比例
- **关键证据**: 该案例中应被识别出的关键风险证据

示例:
```python
RiskDimensionExpectation(
    dimension_name="法律合规",
    expected_severity="high",
    score_range=[70, 95],
    key_evidence=["代孕违法", "威胁举报人"],
)
```

### 2. 多维度覆盖

案例覆盖 9 大类别、10+ 风险维度：
- 法律合规、道德伦理、消费欺诈、群体冒犯
- 性别议题、隐私侵犯、政治敏感、学术诚信
- 未成年人保护、食品安全、职场违规等

### 3. 真实事件改编

所有案例基于 2024-2026 年真实社会事件改编：
- 网红小英卖惨塌房 (2024-09)
- 张雨绮代孕风波 (2026-01)
- 全红婵饭圈侵入式监控 (2024-08)
- AI 一键脱衣黑产 (2025-03)
- 优思益假洋牌事件 (2024-11)
- 等...

### 4. 风险等级平衡

- 高风险：11 个 (40.7%)
- 中风险：11 个 (40.7%)
- 低风险：5 个 (18.5%)

分布相对均衡，避免偏向某一等级。

## 使用方式

### 1. 运行回测测试

```bash
# 模拟模式（不需要 LLM API Key）
python3 -m backend.services.backtest_runner

# 真实 LLM 模式（需要配置 API Key）
# 在.env 中设置 LLM_API_KEY 后运行
python3 -m backend.services.backtest_runner
```

### 2. 在代码中使用案例库

```python
from backend.services.backtest_cases import (
    get_all_cases,
    get_cases_by_category,
    get_cases_by_risk_level,
    CaseCategory,
    RiskLevel,
)

# 获取所有案例
cases = get_all_cases()

# 获取所有高风险案例
high_risk_cases = get_cases_by_risk_level(RiskLevel.HIGH)

# 获取所有消费维权案例
consumer_cases = get_cases_by_category(CaseCategory.CONSUMER)

# 获取特定案例
case = get_case_by_id("CASE_001")
```

### 3. 集成到 CI/CD

```yaml
# .github/workflows/backtest.yml
jobs:
  backtest:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v2
      - name: Run backtest
        run: python3 -m backend.services.backtest_runner
      - name: Check accuracy
        run: |
          accuracy=$(python3 -c "import json; print(json.load(open('tests/T0_backtest_report.json'))['summary']['overall_accuracy'])")
          if (( $(echo "$accuracy >= 0.6" | bc -l) )); then
            echo "Backtest passed: ${accuracy}"
          else
            echo "Backtest failed: ${accuracy}"
            exit 1
          fi
```
