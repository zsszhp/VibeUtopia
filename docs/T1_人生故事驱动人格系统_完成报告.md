## 核心交付物

### 1. A/B/C三级人格生成器

**文件**: `backend/services/persona/life_story_generator.py` (543行)

#### A-tier: AI访谈生成器
- **实现**: `LifeStoryInterviewer` 类
- **机制**: 6轮结构化访谈 → 数万字人生故事
- **访谈主题**:
  1. 童年与家庭 (3000字)
  2. 教育与成长 (3000字)
  3. 职业与事业 (3000字)
  4. 社交与关系 (2500字)
  5. 价值观与信仰 (2500字)
  6. 网络行为与态度 (2500字)
- **输出**: 完整人生故事 + 7层人格 + Big Five + 初始记忆

#### B-tier: CGSS采样+LLM丰富
- **实现**: `CGSSSampler` 类
- **机制**: 人口统计采样 → LLM推理L2-L7 → 千字故事
- **数据源**: 13种CGSS人口统计组合(按权重采样)
- **输出**: 人生故事(约1000字) + 7层人格 + Big Five

#### C-tier: 模板变体
- **实现**: `TemplateVariator` 类
- **机制**: 原型模板+随机参数变体 → 百字梗概
- **模板类型**: 主流用户/争议用户/边缘用户/KOL/跨界用户
- **输出**: 百字梗概 + 7层人格 + Big Five(推断)

### 2. 人格工厂统一入口

**实现**: `PersonaFactory` 类
- 根据tier选择生成策略
- 批量生成支持(可指定tier分布)
- 自动质量校验(QualityValidator)
- 默认分布: A-tier 10%, B-tier 33%, C-tier 57%

### 3. Memory Stream向量记忆存储

**文件**: `backend/services/persona/memory_stream.py` (343行)

- **ChromaDB优先**: 持久化部署，支持向量检索
- **降级策略**: ChromaDB不可用时自动降级到MySQL/SQLite关键词检索
- **三因子检索**:
  - Recency(0.5): 指数衰减，新鲜记忆优先
  - Importance(0.3): 重要性评分
  - Relevance(0.2): 查询相关度
- **记忆类型**: observation / reflection / plan

### 4. API端点新增

**文件**: `backend/routes.py` (新增约180行)

| 方法 | 路径 | 说明 |
|------|------|------|
| `POST` | `/api/v1/persona/generate` | 生成单个人生故事人格 |
| `POST` | `/api/v1/persona/generate-batch` | 批量生成人生故事人格 |

| `POST` | `/api/v1/memory/retrieve` | 三因子检索记忆 |

## 技术实现细节

### 数据流

```
用户请求 → PersonaFactory → 根据tier选择策略
    ├─ A-tier: LifeStoryInterviewer → 6轮LLM访谈 → 人生故事 → 7层人格提取 → Big Five推断
    ├─ B-tier: CGSSSampler → 人口统计采样 → LLM生成故事+人格
    └─ C-tier: TemplateVariator → 模板+随机变体 → 梗概
                ↓
        QualityValidator → 质量校验与修复
                ↓
        MemoryStreamStore → 初始记忆存储(ChromaDB)
```

### 7层人格结构

```json
{
    "L1_basic": {"age": "年龄段", "gender": "性别", "education": "学历", ...},
    "L2_values": {"political_stance": "立场", "consumerism": 5.0, ...},
    "L3_knowledge": {"professional_fields": ["领域"], "cognitive_level": "等级"},
    "L4_behavior": {"expression_style": "风格", "interaction_preference": "偏好"},
    "L5_correction": {"self_censorship": "程度", "sensitive_triggers": ["触发词"]},
    "L6_social": {"influence_level": 5.0, "group_identity": ["群体"]},
    "L7_evolution": {"emotional_baseline": "基线", "recent_experiences": ["经历"]}
}
```

### Big Five人格特质

```json
{
    "openness": 0.0-1.0,          // 开放性
    "conscientiousness": 0.0-1.0, // 尽责性
    "extraversion": 0.0-1.0,      // 外向性
    "agreeableness": 0.0-1.0,     // 宜人性
    "neuroticism": 0.0-1.0        // 神经质
}
```

   - 修复不一致的价值观
   - 提升整体人格质量
