## 实施内容

### 1. 核心模块实现

#### 1.1 PromptVersionManager（版本管理器）
**文件**: `backend/services/prompt_version_manager.py` (448 行)

**核心功能**:
- `register_version()` - 注册新 Prompt 版本
- `get_version()` - 获取指定版本
- `get_latest_version()` - 获取最新版本
- `get_all_versions()` - 获取所有版本
- `create_ab_test()` - 创建 A/B 测试
- `record_ab_test_result()` - 记录测试结果
- `conclude_ab_test()` - 完成测试并得出结论
- `get_recommended_version()` - 推荐最佳版本
- `import_from_file()` - 从文件导入
- `export_to_file()` - 导出到文件

**数据结构**:
```python
PromptVersion:
  - prompt_name: str
  - version: str
  - content: str
  - created_at: datetime
  - metadata: Dict

PromptABTestResult:
  - prompt_name: str
  - version_a: str
  - version_b: str
  - metrics_a: Dict[str, float]
  - metrics_b: Dict[str, float]
  - sample_size: int
  - winner: str
```

#### 1.2 PromptABTestRunner（A/B 测试运行器）
**文件**: `backend/services/prompt_ab_test_runner.py` (253 行)

**核心功能**:
- `run_test()` - 运行完整的 A/B 测试
- `_evaluate_with_version()` - 使用指定版本评估文案
- `run_platform_prompt_ab_test()` - 平台 Prompt 专用测试

**评估指标**:
- **accuracy** - 风险等级准确率
- **avg_risk_score** - 平均风险分数
- **avg_response_time** - 平均响应时间
- **parse_success_rate** - JSON 解析成功率

**测试流程**:
1. 加载两个版本的 Prompt
2. 对每个测试案例分别用两个版本评估
3. 对比预测结果与预期等级
4. 计算各版本指标
5. 记录到 A/B 测试管理器
6. 得出结论并推荐胜出版本

#### 1.3 CLI 管理工具
**文件**: `backend/services/prompt_manager_cli.py` (243 行)

**支持命令**:
```bash
# 注册新 Prompt 版本
python backend/services/prompt_manager_cli.py register <prompt> <version> <file> [--metadata JSON]

# 列出所有版本
python backend/services/prompt_manager_cli.py list

# 显示版本详情
python backend/services/prompt_manager_cli.py show <prompt> <version> [--content]

# 创建 A/B 测试
python backend/services/prompt_manager_cli.py create-ab-test <prompt> <version_a> <version_b> [--name]

# 运行 A/B 测试
python backend/services/prompt_manager_cli.py run-ab-test <prompt> <version_a> <version_b> [--cases] [--output]

# 查看 A/B 测试历史
python backend/services/prompt_manager_cli.py history [--prompt]

# 推荐最佳版本
python backend/services/prompt_manager_cli.py recommend <prompt>
```

#### 3.2 A/B 测试运行脚本
**文件**: `tests/run_prompt_ab_test.py`

**执行流程**:
1. 加载测试案例（15 个）
2. 列出所有可用 Prompt 版本
3. 对 risk_assessment 进行 A/B 测试（如有多个版本）
4. 显示测试结果和详细指标
5. 保存报告到 `data/ab_tests/ab_test_report_*.json`

## 使用示例

### 示例 1: 注册新 Prompt 版本

```bash
# 修改 risk_assessment Prompt 后注册为新版本
python backend/services/prompt_manager_cli.py register \
  risk_assessment \
  v2.0 \
  backend/prompts/risk_assessment_v2.txt \
  --metadata '{"description":"优化维度交叉影响规则","author":"AI Assistant"}'
```

### 示例 2: 查看版本历史

```bash
python backend/services/prompt_manager_cli.py list
```

输出:
```
📦 risk_assessment
   • v1.0 (2026-05-14 11:58) - 初始版本
   • v20260514115816 (2026-05-14 12:30) - T4 优化版本
   • v2.0 (2026-05-15 10:00) - 阶段 2.5 优化版本
   ⭐ 推荐版本：v2.0
```

### 示例 3: 运行 A/B 测试

```bash
python backend/services/prompt_manager_cli.py run-ab-test \
  risk_assessment \
  v1.0 \
  v2.0 \
  --cases data/ab_test_cases.json \
  --output data/ab_tests/report_v1.0_vs_v2.0.json
```

### 示例 4: 查看 A/B 测试历史

```bash
python backend/services/prompt_manager_cli.py history --prompt risk_assessment
```

### 示例 5: 获取推荐版本

```bash
python backend/services/prompt_manager_cli.py recommend risk_assessment
```
