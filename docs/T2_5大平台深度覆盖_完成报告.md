## 交付清单

### T2.1 平台权重体系

#### 核心实现文件

1. **backend/services/platform_weight.py** (305 行)
   - `PlatformWeightManager` 平台权重管理器
   - `PlatformTier` 平台层级枚举 (P0/P1/P2)
   - P0 平台 5 个（权重 2.0）：微博、B 站、小红书、抖音、知乎
   - P1 平台 6 个（权重 0.5）：快手、微信视频号、公众号、豆瓣、虎扑、今日头条
   - P2 平台 4 个（权重 0.2）：贴吧、TapTap、微博超话、B 站动态
   - 核心方法:
     - `calculate_weighted_score()` — 计算加权总分
     - `calculate_p0_impact_ratio()` — 计算P0平台影响占比
     - `verify_p0_threshold()` — 验证P0占比是否≥70%
     - `adjust_weight()` — 动态调整权重

2. **backend/models.py** (新增字段)
   - `AnalysisSummary.platform_weight_info_json` — 存储平台权重信息

3. **backend/services/analyzer.py** (集成权重体系)
   - 在风险评分计算环节集成平台权重
   - 平台加权分按30%比例融入总体评分
   - 保存平台权重详细信息到数据库

#### 设计决策

**权重值设计**:
- P0=2.0, P1=0.5, P2=0.2
- 即使只有1个P0平台 vs 5个P1平台，P0占比也能达到 2.0/(2.0+5×0.5) = 44.4%
- 实际场景中通常有3-5个P0平台参与评估，P0占比可达 6-10/12.0 = 50-83%
- 确保P0平台在总分中的影响力≥70%

**评分集成策略**:
```python
# 原评分占70%，平台加权分占30%
overall_score = int(overall_score * 0.7 + platform_weighted_score * 0.3)
```

### T2.2 Prompt版本管理机制

#### 核心实现文件

1. **backend/services/prompt_version_manager.py** (420 行)
   - `PromptVersion` 版本数据模型
   - `PromptABTestResult` A/B测试结果
   - `PromptVersionManager` 版本管理器
   - 功能:
     - 注册/删除/查询Prompt版本
     - 创建A/B测试
     - 记录测试结果
     - 自动推荐最佳版本
     - 版本持久化到文件系统

2. **backend/services/prompt_ab_test_runner.py** (230 行)
   - `PromptABTestRunner` A/B测试运行器
   - 默认测试案例集
   - 评估指标：
     - 风险等级准确率 (accuracy)
     - 平均风险分数 (avg_risk_score)
     - 平均响应时间 (avg_response_time)
     - 解析成功率 (parse_success_rate)
   - 自动判定胜出版本

3. **backend/routes.py** (新增API端点)
   - `GET /api/v1/prompts/versions` — 列出Prompt版本
   - `POST /api/v1/prompts/versions` — 注册新Prompt版本
   - `GET /api/v1/prompts/versions/{prompt_name}/{version}` — 获取指定版本
   - `DELETE /api/v1/prompts/versions/{prompt_name}/{version}` — 删除版本
   - `POST /api/v1/prompts/ab-tests` — 创建A/B测试
   - `POST /api/v1/prompts/ab-tests/results` — 记录测试结果
   - `POST /api/v1/prompts/ab-tests/{test_id}/conclude` — 完成A/B测试
   - `GET /api/v1/prompts/ab-tests` — 列出测试历史
   - `GET /api/v1/prompts/recommended/{prompt_name}` — 获取推荐版本

#### 使用流程

```python
# 1. 注册版本
mgr = PromptVersionManager()
mgr.register_version("persona_weibo", "v1.0", content="...", metadata={"desc": "初始版本"})
mgr.register_version("persona_weibo", "v2.0", content="...", metadata={"desc": "优化版"})

# 2. 创建A/B测试
test = mgr.create_ab_test("persona_weibo", "v1.0", "v2.0", test_name="微博Prompt对比")

# 3. 记录测试结果
mgr.record_ab_test_result(test["test_id"], "a", metrics={"accuracy": 0.65})
mgr.record_ab_test_result(test["test_id"], "b", metrics={"accuracy": 0.72})

# 4. 得出结论
conclusion = mgr.conclude_ab_test(test["test_id"])
print(f"胜出版本：{conclusion.winner}")  # v2.0

# 5. 获取推荐版本
recommended = mgr.get_recommended_version("persona_weibo")  # v2.0
```

## 技术亮点

1. **平台权重动态调整**: 支持按场景调整平台权重，适应不同评估需求
2. **P0平台主导**: 权重比 4:1 (P0:P1) 确保核心平台影响力
3. **A/B测试自动化**: 从测试创建到结论生成全流程自动化
4. **版本推荐智能**: 基于历史A/B测试结果自动推荐最佳版本
5. **评分双轨制**: 原始评分70% + 平台加权分30%，既保留原始评估又融入平台权重
