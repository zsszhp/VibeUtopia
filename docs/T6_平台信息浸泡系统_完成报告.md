#### 2.2 关注度概率计算算法

```python
def _calc_attention_probability(self, persona: dict, topic: dict) -> float:
    """
    计算 Agent 对某话题的关注概率
    
    基础概率：0.3
    加分项:
    - 与专业领域 (expertise) 相关：+0.3
    - 与信息来源偏好 (info_sources) 匹配：+0.2
    - 与社会立场 (social_stances) 相关：+0.2
    - 高影响力 Agent (influence_level > 0.5): +0.1
    
    上限：0.95
    """
```

#### 2.3 初始态度推理 Prompt

使用 LLM 基于 Agent 人格特征推理对热点话题的初始态度：

```
输入：
- Agent 7 层人格特征 (L2-L7)
- 热点话题信息 (标题、平台、分类、关键词、情感)

输出：
{
    "attitude": "supportive|opposing|neutral|concerned",
    "reasoning": "推理原因 (50-100 字)",
    "emotional_intensity": 0.0-1.0
}
```

#### 2.4 浸泡分数计算公式

```
immersion_score = (absorbed_score × 0.4) + (attitude_score × 0.4) + (intensity_avg × 0.2)

其中:
- absorbed_score = min(absorbed_count / (days × posts_per_day), 1.0)
- attitude_score = min(attitudes_count / 5, 1.0)
- intensity_avg = 平均情感强度
```

## 技术亮点

### 1. 人格驱动的注意力机制

浸泡系统不是随机吸收热点，而是基于 Agent 的 7 层人格特征进行选择性关注：

- **L3 专业领域 (expertise)**: 与 Agent 专业相关的话题关注度 +30%
- **L3 信息来源 (info_sources)**: Agent 常用平台的话题关注度 +20%
- **L2 社会立场 (social_stances)**: 与 Agent 立场一致的议题关注度 +20%
- **L6 影响力等级 (influence_level)**: 高影响力 Agent 更关注时事 +10%

### 2. LLM 驱动的态度推理

使用 LLM 基于完整人格特征推理初始态度，而非简单规则匹配：

```python
# Prompt 注入 7 层人格特征
- 专业领域 (L3)
- 信息来源 (L3)
- 社会立场 (L2)
- 认知盲区 (L3)
- 影响力等级 (L6)
```

### 3. 记忆写入机制

浸泡生成的观察记忆写入 `AgentMemory` 表：

```python
# 1. 浏览记忆
"看到{platform}上的热点：{title}"

# 2. 态度记忆
"对{title}的态度：{attitude}, 原因：{reasoning}"
```

记忆权重 = 情感强度 × 10，确保强烈态度在后续仿真中有更高检索优先级。

### 4. 浸泡质量量化

通过 `immersion_score` (0-1) 量化浸泡质量：

- **吸收广度 (40%)**: 吸收的话题数量 / 预期数量
- **态度深度 (40%)**: 形成的态度数量 / 5 个核心话题
- **情感强度 (20%)**: 平均情感强度

## 准确率收益验证路径

### 预期收益：+8%

**收益来源**:
1. Agent 对热点有"近期态度"→ 反应更贴近现实 (+5%)
2. 选择性关注机制→ 减少"无知 Agent"导致的偏差 (+2%)
3. 情感强度加权→ 高情感记忆优先级更高 (+1%)

**验证方式**:
1. **A/B 测试**: 浸泡 Agent vs 未浸泡 Agent 对热点话题的反应差异
2. **回测验证**: 使用历史案例库，对比浸泡前后的预测准确率
3. **统计显著性**: 浸泡效果需达到 p < 0.05

### 验收标准（蓝图要求）

| 指标 | 目标值 | 测量方法 |
|------|--------|---------|
| Big Five 一致性 r | > 0.7 | 重复测试相关性 |
| 浸泡效果统计显著性 | p < 0.05 | t 检验浸泡 vs 未浸泡 |
| 回测命中率 | ≥ 75% | 历史案例库验证 |

## 与仿真系统集成

### 集成点

平台浸泡系统是仿真运行层的前置模块，在以下环节被调用：

```
仿真启动流程:
1. 生成 Agent (07 世界构建层)
2. 平台浸泡 (T6 本模块) ← 新增
3. 进入仿真循环 (08 仿真运行层)
```

### 集成代码示例

```python
from backend.services.platform_immersion import PlatformImmersion

# 1. 仿真开始前执行浸泡
immersion = PlatformImmersion()
result = await immersion.immerse(
    agent_id=agent.agent_id,
    persona=agent.persona,
    hot_topics=hot_topics,
    immersion_days=7,
    posts_per_day=20,
    db=db,
)

# 2. 浸泡完成后进入仿真
if result["status"] == "completed":
    simulator.run(
        agent_id=agent.agent_id,
        immersion_score=result["immersion_score"],
        # ...其他参数
    )
```
