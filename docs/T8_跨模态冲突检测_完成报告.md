## 核心功能

### 检测流程

```
1. 输入三模态内容（文案、画面描述、音频转写）
2. LLM 分析各模态独立风险信号
3. 检测模态之间的冲突（如文案积极但画面消极）
4. 识别"单模态安全但其他模态有风险"的情况
5. 输出冲突列表 + 总体冲突分数 + 隐藏风险标记
```

### 冲突检测 Prompt

```python
CROSS_MODAL_PROMPT = """分析三个模态的内容，检测风险信号冲突：
1. 各模态是否包含独立的风险信号
2. 模态之间是否存在冲突（如文案积极但画面消极）
3. 是否存在"某模态安全但其他模态有风险"的情况

输出 JSON:
{
    "conflicts": [{"type": "...", "description": "...", "risk_score": 0-100}],
    "overall_conflict_score": 0-100,
    "has_hidden_risk": true/false,
    "summary": "..."
}"""
```

### 分数集成策略

```python
def integrate_cross_modal_score(overall_score, conflict_score, has_hidden_risk):
    adjusted = overall_score
    
    # 如果有隐藏风险，总体分 +15
    if has_hidden_risk:
        adjusted = max(adjusted, overall_score + 15)
    
    # 如果冲突分数高（>50），总体分 +10
    if conflict_score > 50:
        adjusted = max(adjusted, overall_score + 10)
    
    return min(100, adjusted)
```

```python

detector = CrossModalConflictDetector()

print(f"隐藏风险：{result['has_hidden_risk']}")
```

## 技术实现细节

### 1. 多模态输入处理

- **文案**：限制前 1000 字符
- **画面描述**：OCR 识别 + 物体检测结果
- **音频转写**：语音识别结果

### 2. LLM + 规则双引擎

- **LLM 主力**：使用 cross_modal_prompt 进行深度分析
- **规则兜底**：敏感词检测，防止 LLM 漏报

### 3. 冲突类型识别

| 类型 | 检测逻辑 |
|------|---------|
| 文案 vs 画面 | 文案安全关键词 vs 画面风险关键词 |
| 文案 vs 音频 | 文案情感极性 vs 音频情感极性 |
| 画面 vs 音频 | 画面内容 vs 音频提及内容 |
