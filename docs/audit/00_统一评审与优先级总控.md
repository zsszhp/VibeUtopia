# VibeUtopia 产品完善 · 统一评审与优先级总控

> 角色：产品评审会纪要（多角色 Agent 团队二次调研后的统一结论）
> 范围：功能闭环、UX/UI、算法可信度、工程化、商业化准备
> 定位策略（用户确认）：**个人创作者优先**，分阶段扩展 MCN / 品牌 / 平台
> 近期目标（用户确认）：可用性与操作体验、核心算法可信度、功能闭环、工程可交付（四项并重）
> 交付深度（用户确认）：完整产品蓝图

---

## 1. 总评结论

VibeUtopia 在**能力广度**上已显著超出同类开源项目：11 维风控、多模态视频、千级 Agent 仿真、信号采集、博主服务、细粒度视频理解均有实现痕迹，文档体量也大。

但统一评审的核心判断是：

> **能力已经堆到 80 分，体验与可信度卡在 40 分。**
> 当前产品更像「给工程师看的多功能调试台」，而不是「创作者发布前 3 分钟能用完、敢信结论的风控助手」。

三条主线问题：

| 主线 | 现状一句话 | 后果 |
|------|-----------|------|
| **任务闭环断裂** | 输入→分析→改写→复验→对比 链路有多处确定性 bug 与死代码 | 用户走不通完整价值 |
| **结论不可读、不可信** | 「能不能发」埋在右栏第 11 个区块；错误静默；置信度/证据下钻缺失 | 不敢据此决策 |
| **算法与数据未校准** | 回测受 API 429 污染；两套风险阈值并存；评测集未产品化 | 预测能力无法证明 |

## 4. 统一优先级与阶段划分

### 阶段 R1 · 信任与闭环（本轮实施主包）
目标：创作者 10 分钟内走通「输入 → 看懂结论 → 改 → 复验」

- 前端 P0 包（UX-01~05、UI-01~05）
- 后端 P0 包（BE-01、BE-02、BE-04）
- 算法可解释（ALG-02 证据下钻最小版、阈值统一）
- 文档与启动路径修复（ENG-04）
- 测试可一键运行并修红（ENG-01、ENG-02）

### 阶段 R2 · 可信与度量
- 回测去污染、评测集门禁（ALG-01、ALG-06）
- token/成本/延迟计量（ALG-05）
- 置信度与不确定性产品化（ALG-03）
- API 契约测试 + 最小 E2E

### 阶段 R3 · 视频理解升维（战略，见 design/31）
- 事件/叙事层架构落地（替代纯逐帧）
- 细粒度猎手层强化
- 新旧对比评测证明

### 阶段 R4 · 功能闭环扩展
- 博主知识引擎 / 选题推荐 / 对标拆解 产品化（原始需求 2、3）
- 仿真结果→决策映射简化（去伪精确）

### 阶段 R5 · 机构与商业化
- MCN 多账号、审核流、报告导出
- 多租户与计费准备

## 5. 与原始诉求的对齐声明

本轮实施**不偏离**「发布前帮博主避雷、不压抑创意」的初心：

1. 主界面一切以「能否发布 + 哪里改」为第一视觉优先级
2. 算法输出必须可解释到句/秒，并标明不确定度
3. 仿真与知识图谱作为增强，不抢主流程
4. 个人创作者路径优先打磨，机构能力后置
