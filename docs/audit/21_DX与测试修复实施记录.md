## 3. 残留风险与后续建议

1. **MySQL/Neo4j 真实链路未在本机启动验证**（本机无 Docker 数据库实例）。`docker compose -f scripts/docker-compose.yml up -d` 需要 `.env` 中的 `MYSQL_ROOT_PASSWORD` / `MYSQL_PASSWORD` / `NEO4J_PASSWORD`（compose 已改为 env 注入，不再硬编码口令）。
2. **chromadb 集成测试当前为 skip**。安装 chromadb 后 `tests/test_chromadb_*` 会自动取消 skip，需再跑一轮确认。
3. **前端端口/构建未做浏览器级人工验证**（仅核对 `vite.config.ts` 的 `port: 3000` 与文档/脚本一致）。
4. **`pytest` 的 `PytestReturnNotNoneWarning` 已消除**，但 `tests/scripts/*` 下的手工脚本仍带 `return dict` 风格（它们不是 pytest 收集目标，不影响一键运行）。
5. **依赖仍无上界/锁文件**（审计 P1-8）：本次按要求未升级大版本，仅补 `requirements-dev.txt`。锁文件治理建议后续单独立项。
6. **`docs/guides/24/25` 中的 Dockerfile、备份脚本、迁移 runner 等幽灵引用**不在本次范围（任务只要求改 README 与 doc16）。
