# VibeUtopia 前端设计

## 文档定位
- 本文档在主线中的角色：定义前端唯一入口的设计方案、技术栈、视觉要素
- 与"发前风控优先"的关系：前端围绕"提交内容→获取报告"单流程设计，无多余入口

## 本文档边界
- 本文档负责：前端技术栈、页面布局、视觉要素、组件设计
- 本文档不负责：后端API设计（见`02_系统架构设计.md`）、风险评估逻辑（见`09_分析决策层设计.md`）

## 对准确率的直接贡献
- 机制1：清晰的风险展示（证据链+置信度）让用户能准确理解风险
- 机制2：实时分析进度让用户了解仿真深度，合理信任结果
- 验证方式：用户可用性测试

---

## 1. 设计理念

**一个页面，一个流程。** 前端唯一入口是"内容预审工作台"，所有功能围绕"提交内容→获取风险报告"串联。

Streamlit前端**完全废弃**，仅保留Vue3前端。

设计原则：
- **暗色主题**：科技感+数据驱动，打造"AI风险智能中心"视觉印象
- **数据密集**：风险仪表盘+平台热力图+传播图，信息密度高但不杂乱
- **实时反馈**：分析流水线动画+流式结果输出+Agent活跃状态

## 2. 技术栈

| 组件 | 选择 | 理由 |
|------|------|------|
| 框架 | Vue3 + TypeScript | 已有代码基础 |
| UI库 | **Naive UI** | 暗色主题原生支持更好，设计感比Element Plus更强 |
| 图表 | **ECharts** (已有) + D3.js | ECharts做仪表盘，D3做传播图 |
| 动画 | **Lottie** + CSS transitions | 流水线动画+过渡效果 |
| 状态管理 | Pinia (已有) | |
| HTTP | Axios (已有) | |
| 样式 | **Tailwind CSS 4** (已有) | |
| 通信 | WebSocket (native) | 仿真实时推送 |

> **关键变更：Element Plus → Naive UI**。Element Plus偏后台管理系统风格，Naive UI设计感更现代，暗色主题更精致，组件如DataTable/Progress/Timeline更符合数据密集型界面需求。

### 3.1 左栏（240px固定）

- **上传区域**：拖拽/选择文件，支持视频/文本/混合
- **历史记录**：最近分析记录列表
- **平台热力图**：28平台卡片网格，背景色按风险等级渐变

### 3.2 主内容区（自适应）

- **分析流水线动画**：节点连线动画，每步完成亮起+数据流粒子
- **风险仪表盘**：圆形gauge(0-100)，红/黄/绿阈值渐变，动画过渡
- **风险时间线**：视频进度条+风险点标记，点击跳转+展开详情

### 3.3 右栏（320px可折叠）

- **风险详情**：点击风险点展开详情（证据链+置信度）
- **Agent反应**：气泡式展示各Agent反应，可展开查看推理过程
- **传播路径图**：D3.js力导向图，节点=Agent，边=传播关系
- **修改建议**：针对高风险句子的替代方案

## 6. 前端-后端通信

### 6.1 REST API（主要）

| 方法 | 端点 | 用途 |
|------|------|------|
| POST | `/api/review` | 提交内容预审 |
| GET | `/api/review/{task_id}` | 获取预审结果 |
| GET | `/api/review/{task_id}/progress` | 获取分析进度 |
| GET | `/api/history` | 历史记录 |
| GET | `/api/models` | 可用模型列表 |

### 6.2 WebSocket（分析进度推送）


## 7. 关键组件设计

### 7.1 RiskGauge — 风险仪表盘

- 圆形gauge，0-100分
- 红(70+)/橙(50-70)/黄(30-50)/绿(<30) 渐变
- 动画过渡（数值变化时平滑动画）
- 中心显示风险等级文字

### 7.2 AnalysisPipeline — 分析流水线

- 5个节点：输入→理解→评估→推演→报告
- 节点间连线，数据流动画（粒子效果）
- 当前步骤高亮+脉冲动画
- 完成步骤打勾+稳定发光

### 7.3 PlatformHeatmap — 平台热力图

- 25+平台卡片网格
- 背景：绿→黄→红渐变（按风险等级）
- 点击展开：该平台具体反应统计+Agent评论

### 7.4 PropagationGraph — 传播路径图

- D3.js力导向图
- 节点：Agent（大小=影响力，颜色=态度）
- 边：传播关系（粗细=传播强度）
- 动态扩散动画

### 7.5 RiskTimeline — 风险时间线

- 视频进度条+风险点标记
- 点击标记跳转到对应位置
- 展开显示风险详情（证据链+改写建议）

## 关键流程/结构

- 输入：用户在左栏上传内容
- 处理：主内容区展示分析过程+结果
- 输出：右栏展示风险详情+修改建议

## 依赖与降级

- 依赖：后端API可用性、WebSocket连接
- 失败降级策略：
  - WebSocket断开 → 降级为轮询API
  - API不可用 → 显示"服务暂不可用"提示
  - 传播图渲染卡顿 → 限制节点数+WebGL渲染

## 验收标准

- 指标：页面加载时间、分析结果展示完整性
- 阈值：首屏加载<2s，1000节点传播图渲染<2s
- 通过条件：单页面完成从输入到报告的全部交互流程
