# VibeUtopia 细粒度视频理解设计

## 文档定位
- 本文档在主线中的角色：定义视频细粒度理解的技术方案——解决视频中短暂画面（十几帧）和小区域细节的检测与理解问题，补齐现有"关键帧+VLM"管线的盲区
- 与"发前风控优先"的关系：细粒度理解是风控的最后一公里——地图缺失台湾、代码文件夹暴露开源项目名等"几帧定生死"的场景，现有管线极易漏检，本文档方案直接堵住这类最高风险漏洞
- 与`12_多模态风控设计.md`的关系：本文档是多模态风控的增强模块，在现有关键帧提取+VLM理解的基础上，新增密集帧扫描、区域放大、专项检测器三层能力

## 本文档边界
- 本文档负责：密集帧采样策略、区域放大与多尺度分析、地图完整性审核、代码/文件夹溯源检测、敏感符号专项检测、短暂异常画面检测
- 本文档不负责：基础关键帧提取（见`12_多模态风控设计.md`）、风险评估逻辑（见`09_分析决策层设计.md`）、前端展示（见`13_前端升级设计.md`）

## 对准确率的直接贡献
- 机制1：密集帧扫描确保"几帧画面"不被遗漏，将短暂画面检出率从~30%提升至~85%
- 机制2：区域放大+多尺度分析确保"小区域细节"可被VLM识别，将小文字/小符号识别率从~40%提升至~80%
- 机制3：专项检测器（地图审核/代码溯源）对已知高频风险场景提供确定性检测，召回率≥90%
- 验证方式：构建"细粒度风险案例库"（含地图缺失、代码暴露、敏感符号等20+案例），对比有/无细粒度理解的检出率

## 1. 问题定义与技术可行性

### 1.1 核心问题

现有视频理解管线存在三大盲区：

| 盲区 | 典型案例 | 现有管线缺陷 | 后果 |
|------|---------|------------|------|
| **短暂画面漏检** | 地图画面仅出现3-5秒（90-150帧），问题区域仅占画面5% | 场景切换检测可能跳过；均匀采样30秒一帧，3秒画面仅1/10概率被采到 | 漏检率~70% |
| **小区域细节丢失** | 地图中台湾缺失仅占画面1-2%；文件夹名仅占画面0.5% | VLM处理整帧时分辨率不足，小文字/小符号无法识别 | 识别率~40% |
| **语义关联缺失** | 文件夹名"ByteTrack"与GitHub开源项目的关联 | VLM缺乏代码溯源知识，无法判断是否为开源项目 | 检出率~0% |

### 1.2 大模型视频理解原理

当前主流视频理解大模型的工作方式：

```
视频输入 → 帧采样（8-64帧）→ 视觉编码器（ViT）→ 时序建模 → LLM推理 → 输出
```

**关键原理：**
1. **帧采样策略**：均匀采样或基于场景切换采样，通常8-64帧覆盖整个视频。Qwen2-VL支持动态帧率采样，最长~20分钟视频
2. **视觉编码**：每帧通过ViT编码为token序列。Qwen2-VL的Naive Dynamic Resolution机制保留原始分辨率，M-RoPE位置编码分解为时间/高度/宽度三维度
3. **时序建模**：通过时空注意力（TimeSformer）、3D卷积（VideoLLaMA2的STC连接器）或简单帧拼接（LLaVA-NeXT）建模帧间关系
4. **LLM推理**：视觉token与文本token拼接后输入LLM，进行理解和问答

**细粒度理解的瓶颈：**
- **采样瓶颈**：30fps视频中10帧≈0.33秒，均匀采样8帧/分钟时，0.33秒画面被采到的概率仅~4%
- **分辨率瓶颈**：VLM处理整帧时，1%面积的区域在8B参数模型中仅对应1-2个token，信息严重压缩
- **知识瓶颈**：VLM缺乏特定领域知识（如哪些代码是开源项目、地图应包含哪些区域）

### 1.3 技术可行性结论

| 问题 | 技术可行性 | 核心方案 | 预期效果 |
|------|-----------|---------|---------|
| 短暂画面漏检 | ✅ 可行 | 密集帧扫描+时序异常检测 | 检出率30%→85% |
| 小区域细节丢失 | ✅ 可行 | 区域放大+多尺度VLM分析 | 识别率40%→80% |
| 地图完整性审核 | ✅ 可行 | OCR+地理知识库比对 | 召回率≥90% |
| 代码/文件夹溯源 | ⚠️ 部分可行 | OCR+代码搜索引擎 | 召回率~60%（受OCR准确率和代码库覆盖度限制） |
| 敏感符号检测 | ✅ 可行 | 专项检测器+VLM辅助 | 召回率≥85% |

> **结论**：技术上可以实现，但需要"密集采样+区域放大+专项检测器"三管齐下，不能仅依赖VLM的端到端理解。

## 3. 密集帧扫描器

### 3.1 设计理念

现有关键帧管线以"场景切换"为主，30秒间隔为辅，对于3-5秒的短暂画面极易漏检。密集帧扫描器采用"先密后筛"策略：先以1fps全量抽帧，再通过帧差异评分筛选出需要细审的"异常帧"。

### 3.2 抽帧策略

```python
class DenseFrameScanner:
    """密集帧扫描器——确保短暂画面不被遗漏"""

    STRATEGIES = {
        "dense_1fps": {
            "description": "1fps全量抽帧，确保每秒至少1帧被覆盖",
            "tool": "FFmpeg",
            "typical_frames": "600帧/10分钟视频",
            "priority": 0,
        },
        "scene_change_supplement": {
            "description": "场景切换帧补充（复用PySceneDetect）",
            "tool": "PySceneDetect",
            "typical_frames": "10-30帧/10分钟视频",
            "priority": 1,
        },
        "motion_diff": {
            "description": "运动差异帧——与前后帧差异超过阈值的帧",
            "tool": "OpenCV frame diff",
            "typical_frames": "50-100帧/10分钟视频",
            "priority": 2,
        },
    }

    async def scan(self, video_path: str) -> list[DenseFrame]:
        all_frames = []

        # 1. 1fps全量抽帧
        dense_frames = self._extract_1fps(video_path)

        # 2. 场景切换帧补充
        scene_frames = self._detect_scene_changes(video_path)

        # 3. 运动差异帧补充
        motion_frames = self._detect_motion_diff(video_path, threshold=0.15)

        # 4. 合并去重
        all_frames = self._merge_and_dedup(dense_frames, scene_frames, motion_frames)

        # 5. 帧差异评分——筛选"异常帧"
        scored_frames = self._score_frame_anomaly(all_frames)

        # 6. 分层：高异常帧必审 + 低异常帧抽审
        high_anomaly = [f for f in scored_frames if f.anomaly_score > 0.7]
        low_anomaly = [f for f in scored_frames if f.anomaly_score <= 0.7]

        # 低异常帧每5帧抽1帧（降低计算量）
        sampled_low = low_anomaly[::5]

        return high_anomaly + sampled_low
```

### 3.3 帧差异评分

```python
def _score_frame_anomaly(self, frames: list[DenseFrame]) -> list[DenseFrame]:
    """帧差异评分——检测与前后帧差异大的"异常帧""""
    for i in range(1, len(frames) - 1):
        prev_diff = self._compute_frame_diff(frames[i].image, frames[i-1].image)
        next_diff = self._compute_frame_diff(frames[i].image, frames[i+1].image)
        frames[i].anomaly_score = max(prev_diff, next_diff)
    return frames

def _compute_frame_diff(self, img1, img2) -> float:
    """计算两帧的差异度（0-1）"""
    gray1 = cv2.cvtColor(img1, cv2.COLOR_BGR2GRAY)
    gray2 = cv2.cvtColor(img2, cv2.COLOR_BGR2GRAY)
    diff = cv2.absdiff(gray1, gray2)
    return np.mean(diff) / 255.0
```

## 4. 区域放大分析器

### 4.1 设计理念

VLM处理整帧时，画面1-2%面积的小区域仅对应1-2个token，信息严重压缩。区域放大分析器先检测帧中的"感兴趣区域"（文字区、地图区、代码区、符号区），再裁剪放大后送入VLM/OCR进行细粒度分析。

### 4.2 区域检测策略

```python
class RegionAmplifier:
    """区域放大分析器——让小区域细节可被VLM识别"""

    REGION_DETECTORS = {
        "text": {
            "description": "文字区域检测（字幕/水印/贴图/文件名）",
            "detector": "EAST / DB文本检测器",
            "min_area_ratio": 0.005,    # 最小面积占比0.5%
            "amplify_ratio": 4,          # 放大4倍
        },
        "map": {
            "description": "地图区域检测",
            "detector": "地图分类器（ResNet微调）",
            "min_area_ratio": 0.05,
            "amplify_ratio": 3,
        },
        "code_terminal": {
            "description": "代码/终端区域检测（深色背景+等宽字体）",
            "detector": "启发式规则（深色背景比例>70% + 等宽字体检测）",
            "min_area_ratio": 0.03,
            "amplify_ratio": 4,
        },
        "sensitive_symbol": {
            "description": "敏感符号/标志区域检测",
            "detector": "YOLOv8微调（旗帜/标志/徽章检测）",
            "min_area_ratio": 0.01,
            "amplify_ratio": 5,
        },
    }

    async def analyze(self, frame: DenseFrame) -> list[RegionDetail]:
        """检测并放大帧中的感兴趣区域"""
        regions = []

        # 1. 文字区域检测
        text_regions = self._detect_text_regions(frame)
        for region in text_regions:
            amplified = self._amplify_region(frame, region, ratio=4)
            ocr_result = await self._fine_ocr(amplified)
            regions.append(RegionDetail(
                region_type="text",
                bbox=region.bbox,
                amplified_image=amplified,
                ocr_text=ocr_result.text,
                confidence=ocr_result.confidence,
            ))

        # 2. 地图区域检测
        map_regions = self._detect_map_regions(frame)
        for region in map_regions:
            amplified = self._amplify_region(frame, region, ratio=3)
            map_result = await self._audit_map_completeness(amplified)
            regions.append(RegionDetail(
                region_type="map",
                bbox=region.bbox,
                amplified_image=amplified,
                map_audit=map_result,
            ))

        # 3. 代码/终端区域检测
        code_regions = self._detect_code_regions(frame)
        for region in code_regions:
            amplified = self._amplify_region(frame, region, ratio=4)
            code_result = await self._trace_code_origin(amplified)
            regions.append(RegionDetail(
                region_type="code_terminal",
                bbox=region.bbox,
                amplified_image=amplified,
                code_trace=code_result,
            ))

        # 4. 敏感符号区域检测
        symbol_regions = self._detect_sensitive_symbols(frame)
        for region in symbol_regions:
            amplified = self._amplify_region(frame, region, ratio=5)
            symbol_result = await self._assess_symbol_risk(amplified)
            regions.append(RegionDetail(
                region_type="sensitive_symbol",
                bbox=region.bbox,
                amplified_image=amplified,
                symbol_risk=symbol_result,
            ))

        return regions
```

### 4.3 区域放大方法

```python
def _amplify_region(self, frame: DenseFrame, region: Region, ratio: int) -> Image:
    """裁剪并放大区域，使用超分辨率增强细节"""
    x1, y1, x2, y2 = region.bbox
    cropped = frame.image[y1:y2, x1:x2]

    # 超分辨率放大（ESRGAN/Real-ESRGAN轻量版）
    if ratio >= 4 and self.sr_model is not None:
        amplified = self.sr_model.enhance(cropped, outscale=ratio)
    else:
        amplified = cv2.resize(cropped, None, fx=ratio, fy=ratio, interpolation=cv2.INTER_LANCZOS4)

    return amplified
```

## 5. 专项检测器

### 5.1 地图完整性审核器

**场景**：博主在视频中展示地图时，缺失台湾、南海诸岛等区域，即使地图仅出现几帧、仅占画面一小部分。

**方案**：

```python
class MapCompletenessAuditor:
    """地图完整性审核器——检测地图中是否缺失特定区域"""

    # 中国地图必须包含的区域（经纬度范围）
    REQUIRED_REGIONS = {
        "台湾": {"lat_range": (21.9, 25.3), "lon_range": (120.0, 122.0)},
        "南海诸岛": {"lat_range": (3.5, 21.0), "lon_range": (109.5, 117.5)},
        "钓鱼岛": {"lat_range": (25.7, 26.0), "lon_range": (123.0, 124.5)},
        "藏南地区": {"lat_range": (26.5, 29.5), "lon_range": (92.0, 97.0)},
        "阿克赛钦": {"lat_range": (34.5, 37.5), "lon_range": (76.5, 80.0)},
    }

    async def audit(self, amplified_map_image: Image) -> MapAuditResult:
        """审核地图完整性"""

        # Step 1: OCR提取地图上的文字标注
        ocr_texts = await self._ocr_map_texts(amplified_map_image)

        # Step 2: VLM理解地图内容——识别地图类型和覆盖范围
        map_understanding = await self._vlm_understand_map(amplified_map_image)

        # Step 3: 地理知识库比对——检查必须区域是否存在
        missing_regions = self._check_required_regions(map_understanding, ocr_texts)

        # Step 4: 风险评估
        risk_level = "critical" if missing_regions else "safe"

        return MapAuditResult(
            is_complete=len(missing_regions) == 0,
            missing_regions=missing_regions,
            ocr_texts=ocr_texts,
            map_description=map_understanding.description,
            risk_level=risk_level,
            confidence=map_understanding.confidence,
        )

    def _check_required_regions(self, map_understanding, ocr_texts) -> list[str]:
        """检查必须区域是否在地图中出现"""
        missing = []
        all_text = " ".join(ocr_texts).lower()
        map_desc = map_understanding.description.lower()

        for region_name, coords in self.REQUIRED_REGIONS.items():
            # 方法1：文字标注检查
            if region_name in all_text or region_name in map_desc:
                continue

            # 方法2：VLM直接判断（在理解结果中检查）
            if map_understanding.covers_region(region_name, coords):
                continue

            missing.append(region_name)

        return missing
```

### 5.2 代码溯源检测器

**场景**：博主在视频中展示了代码编辑器/终端/文件夹画面，声称是自研项目，但实际是开源项目。

**方案**：

```python
class CodeOriginTracer:
    """代码溯源检测器——检测视频中的代码是否来自开源项目"""

    async def trace(self, amplified_code_image: Image) -> CodeTraceResult:
        """溯源代码来源"""

        # Step 1: OCR提取代码/文件夹名
        ocr_result = await self._ocr_code_region(amplified_code_image)
        extracted_texts = ocr_result.texts

        # Step 2: 识别代码特征
        code_features = self._extract_code_features(extracted_texts)

        # Step 3: 在开源代码库中搜索
        matches = []
        for feature in code_features:
            if feature.type == "project_name":
                # 项目名搜索（GitHub API / SourceGraph）
                gh_results = await self._search_github(feature.text)
                matches.extend(gh_results)
            elif feature.type == "file_path":
                # 文件路径搜索
                path_results = await self._search_code_path(feature.text)
                matches.extend(path_results)
            elif feature.type == "code_snippet":
                # 代码片段搜索（codesearch / ast-grep）
                code_results = await self._search_code_snippet(feature.text)
                matches.extend(code_results)

        # Step 4: 匹配度评估
        verified_matches = self._verify_matches(matches, code_features)

        return CodeTraceResult(
            extracted_texts=extracted_texts,
            code_features=code_features,
            matches=verified_matches,
            is_likely_opensource=len(verified_matches) > 0,
            confidence=self._compute_confidence(verified_matches),
        )

    def _extract_code_features(self, texts: list[str]) -> list[CodeFeature]:
        """从OCR文本中提取代码特征"""
        features = []
        for text in texts:
            # 检测项目名（如 "ByteTrack", "YOLOv5"）
            if self._looks_like_project_name(text):
                features.append(CodeFeature(type="project_name", text=text))
            # 检测文件路径（如 "src/models/detector.py"）
            if "/" in text and ("." in text.split("/")[-1]):
                features.append(CodeFeature(type="file_path", text=text))
            # 检测代码片段（包含缩进、括号、关键字等）
            if self._looks_like_code(text):
                features.append(CodeFeature(type="code_snippet", text=text))
        return features
```

### 5.3 敏感符号检测器

**场景**：视频中短暂出现争议性标志、旗帜、手势等，即使仅出现几帧、仅占画面小区域。

**方案**：

```python
class SensitiveSymbolDetector:
    """敏感符号检测器——检测视频中的争议性标志/旗帜/手势"""

    SYMBOL_CATEGORIES = [
        "争议性旗帜",       # 特定国家/组织旗帜
        "争议性标志",       # 敏感组织/运动标志
        "争议性手势",       # 具有争议性的手势
        "争议性徽章/纹章",  # 敏感组织徽章
        "不当贴图/水印",    # 含敏感信息的贴图
    ]

    async def detect(self, frame: DenseFrame) -> list[SymbolRiskResult]:
        """检测帧中的敏感符号"""

        results = []

        # Step 1: YOLOv8目标检测——定位可能的敏感符号区域
        detections = self.yolo_detector.detect(frame.image)

        for det in detections:
            if det.confidence < 0.5:
                continue

            # Step 2: 裁剪放大
            amplified = self._amplify_region(frame, det.bbox, ratio=5)

            # Step 3: VLM细审——确认是否为敏感符号
            vlm_result = await self._vlm_assess_symbol(amplified, det.category)

            if vlm_result.is_sensitive:
                results.append(SymbolRiskResult(
                    symbol_type=det.category,
                    bbox=det.bbox,
                    description=vlm_result.description,
                    risk_level=vlm_result.risk_level,
                    confidence=vlm_result.confidence,
                    timestamp=frame.timestamp,
                ))

        return results
```

## 6. 短暂异常画面检测

### 6.1 时序异常检测

对于视频中短暂出现的异常画面（如闪过的争议图片、瞬间切换的不当内容），使用时序动作检测模型定位异常区间：

```python
class TemporalAnomalyDetector:
    """时序异常检测器——定位视频中的短暂异常画面"""

    async def detect(self, video_path: str) -> list[TemporalAnomaly]:
        """检测视频中的短暂异常画面"""

        # Step 1: 提取视频特征（使用预训练的视频编码器）
        features = self._extract_video_features(video_path)

        # Step 2: 帧级差异分析——检测与上下文不一致的帧
        anomaly_scores = self._compute_anomaly_scores(features)

        # Step 3: 聚类异常区间
        anomaly_segments = self._cluster_anomalies(anomaly_scores, threshold=0.6)

        # Step 4: 对每个异常区间进行VLM审核
        results = []
        for segment in anomaly_segments:
            # 提取异常区间的关键帧
            key_frames = self._extract_segment_frames(video_path, segment)

            # VLM审核
            for frame in key_frames:
                vlm_result = await self._vlm_review_frame(frame)
                if vlm_result.has_risk:
                    results.append(TemporalAnomaly(
                        start_time=segment.start,
                        end_time=segment.end,
                        duration=segment.end - segment.start,
                        anomaly_type=vlm_result.risk_category,
                        description=vlm_result.description,
                        confidence=vlm_result.confidence,
                    ))

        return results
```

### 6.2 帧差异异常检测

```python
def _compute_anomaly_scores(self, features: list) -> list[float]:
    """计算每帧的异常评分——与前后N帧的差异"""
    window_size = 5
    scores = []

    for i in range(len(features)):
        # 计算当前帧与前后窗口帧的平均差异
        start = max(0, i - window_size)
        end = min(len(features), i + window_size + 1)
        neighbors = features[start:i] + features[i+1:end]

        if not neighbors:
            scores.append(0.0)
            continue

        avg_diff = np.mean([cosine_distance(features[i], n) for n in neighbors])
        scores.append(avg_diff)

    return scores
```

### 8.1 计算量控制

密集帧扫描的主要计算开销在于VLM调用次数。控制策略：

1. **帧差异预筛选**：仅对anomaly_score > 0.7的帧进行VLM分析，通常占全量帧的5-15%
2. **区域检测预筛选**：仅对检测到感兴趣区域的帧进行专项分析
3. **缓存去重**：相同/相似画面不重复调用VLM
4. **分级处理**：高异常帧全量分析，低异常帧抽检

## 关键流程/结构

- 输入：视频文件 + 现有多模态分析结果
- 处理：密集帧扫描 → 区域放大分析 → 专项检测器 → 结果融合
- 输出：FineGrainedRiskReport（地图审核+代码溯源+敏感符号+时序异常+风险升级）

## 依赖与降级

- 依赖：
  - 现有多模态管线（关键帧提取、VLM、OCR）
  - FFmpeg（密集帧提取）
  - OpenCV（帧差异计算、区域裁剪）
  - 文本检测模型（EAST/DB，用于区域检测）
  - YOLOv8（敏感符号检测，Pro模式）
  - GitHub Search API / SourceGraph（代码溯源）
  - 超分辨率模型（Real-ESRGAN轻量版，Pro模式）
- 失败降级策略：
  - 密集帧扫描失败 → 复用现有关键帧
  - 区域放大失败 → VLM直接分析整帧
  - 地图审核失败 → VLM直接判断（低置信度）
  - 代码溯源失败 → 跳过（标注"未验证"）
  - 敏感符号检测失败 → VLM全帧扫描（增加耗时）
