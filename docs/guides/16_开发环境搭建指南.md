# VibeUtopia 开发环境搭建指南 (16)

## 1. 操作系统：Ubuntu 22.04 LTS / 24.04 LTS

| 优势 | 说明 |
|------|------|
| **Docker 原生** | 无 WSL2 虚拟层，容器 I/O 性能比 Windows 高 30-50% |
| **ext4 文件系统** | ChromaDB 大量小文件读写场景下比 NTFS 快 2-3x |
| **PyTorch/CUDA** | NVIDIA 官方首推平台，驱动兼容性最佳 |
| **生产一致性** | 开发与部署同为 Linux，消除环境差异导致的 bug |
| **systemd 服务管理** | FastAPI/Celery 等进程可注册为系统服务，开机自启 |

## 2. 基础软件安装

### 2.1 系统级依赖 (一键安装)

```bash
# 系统更新
sudo apt update && sudo apt upgrade -y

# 基础工具
sudo apt install -y build-essential curl wget git unzip software-properties-common

# FFmpeg (多模态视频处理)
sudo apt install -y ffmpeg

# 验证
ffmpeg -version
git --version
```

### 2.2 Python 3.11 + uv 包管理器

```bash
# 安装 Python 3.11
sudo add-apt-repository ppa:deadsnakes/ppa -y
sudo apt install -y python3.11 python3.11-venv python3.11-dev

# 设置默认 Python (可选)
sudo update-alternatives --install /usr/bin/python3 python3 /usr/bin/python3.11 1

# 安装 uv (极速包管理器，替代 pip)
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.bashrc

# 验证
python3.11 --version   # 3.11.x
uv --version           # 0.6+
```

### 2.3 Node.js 20 LTS + pnpm

```bash
# 安装 Node.js 20 LTS (通过 NodeSource)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 安装 pnpm
npm install -g pnpm

# 验证
node -v   # v20.x
pnpm -v   # 9.x
```

### 2.4 Docker + Docker Compose

```bash
# 安装 Docker (官方脚本)
curl -fsSL https://get.docker.com | sh

# 添加当前用户到 docker 组 (免 sudo)
sudo usermod -aG docker $USER
newgrp docker

# 验证
docker --version
docker compose version
```

### 2.5 NVIDIA 驱动 + CUDA (有 GPU 时)

```bash
# 安装 NVIDIA 驱动 (推荐 550+)
sudo apt install -y nvidia-driver-550

# 重启后验证
nvidia-smi

# 安装 NVIDIA Container Toolkit (Docker GPU 直通)
distribution=$(. /etc/os-release;echo $ID$VERSION_ID)
curl -fsSL https://nvidia.github.io/libnvidia-container/gpgkey | sudo gpg --dearmor -o /usr/share/keyrings/nvidia-container-toolkit-keyring.gpg
curl -s -L https://nvidia.github.io/libnvidia-container/$distribution/libnvidia-container.list | \
  sed 's#deb https://#deb [signed-by=/usr/share/keyrings/nvidia-container-toolkit-keyring.gpg] https://#g' | \
  sudo tee /etc/apt/sources.list.d/nvidia-container-toolkit.list
sudo apt update && sudo apt install -y nvidia-container-toolkit
sudo nvidia-ctk runtime configure --runtime=docker
sudo systemctl restart docker

# 验证 Docker GPU 直通
docker run --rm --gpus all nvidia/cuda:12.1.0-base-ubuntu22.04 nvidia-smi
```

## 3. 数据库启动 (Docker Compose)

在项目根目录执行：

```bash
docker compose up -d
```

**验证服务**：
```bash
# MySQL
docker exec vibeutopia-mysql mysql -uvibe_user -pvibe_password -e "SELECT 1;"

# Neo4j
curl -s http://localhost:7474 | head -5

# 查看状态
docker compose ps
```

| 服务 | 端口 | 用户名 | 密码 |
|------|------|--------|------|
| MySQL | 3306 | vibe_user | vibe_password |
| Neo4j Browser | 7474 | neo4j | vibeutopia2024 |
| Neo4j Bolt | 7687 | neo4j | vibeutopia2024 |

## 4. 后端环境配置

### 4.1 创建虚拟环境并安装依赖

```bash
cd ~/projects/VibeUtopia

# 创建虚拟环境
uv venv --python 3.11
source .venv/bin/activate

# 安装依赖
uv pip install -r requirements.txt

# (有 GPU 时) 安装 PyTorch CUDA 版
uv pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
```

### 4.2 配置环境变量

```bash
cp .env.example .env
```

**`.env.example` 注释规范**：
建议参考以下结构，让开发者直接看注释就能跑通：
```env
# ========== LLM 模型配置 ==========
# 主力模型（推荐 DeepSeek-V4-Pro，性价比最优）
LLM_API_KEY=sk-your-api-key-here
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat

# ========== 可选：多模态模型 ==========
# 用于视频画面理解（不配则跳过视频分析，使用文本降级）
VISION_API_KEY=
VISION_MODEL=qwen-vl-plus

# ========== 数据库配置 ==========
# 默认使用 SQLite（无需配置即可运行）
# 如需 MySQL/Neo4j，请取消下方注释
# DATABASE_URL=mysql+pymysql://vibe_user:vibe_password@localhost:3306/vibeutopia
```

## 6. 启动服务

### 6.1 开发者 QuickStart 流程（目标：5分钟跑通）

如果用户只需快速体验功能（Phase A 阶段）：

```bash
# 1. 克隆代码
git clone https://github.com/xxx/VibeUtopia.git

# 2. 配置环境
cp .env.example .env  # 填入 API Key

# 3. 启动所有服务（前后端+数据库）
docker-compose up -d

# 4. 打开浏览器访问
# http://localhost:8080
```

### 6.2 本地开发一键启动脚本 (start.sh)

```bash
#!/bin/bash
# start.sh - 一键启动 VibeUtopia

# 启动数据库
docker compose up -d

# 启动后端
source .venv/bin/activate
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload &

# 启动前端
cd frontend && pnpm dev &

echo "✅ 后端: http://localhost:8000/docs"
echo "✅ 前端: http://localhost:5173"
```

### 6.2 手动启动

```bash
# 终端 1 - 后端
source .venv/bin/activate
uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload

# 终端 2 - 前端
cd frontend && pnpm dev
```

## 9. 常见问题 FAQ

**Q: ChromaDB 报 sqlite3 版本过低?**
```bash
pip install pysqlite3-binary
# 在 backend/__init__.py 顶部添加:
# import pysqlite3; import sys; sys.modules["sqlite3"] = pysqlite3
```

**Q: Docker 端口被占用?**
```bash
sudo lsof -i :3306  # 查看占用进程
sudo kill -9 <PID>  # 终止占用进程
```

**Q: NVIDIA 驱动安装后 nvidia-smi 无输出?**
```bash
sudo reboot  # 驱动安装后必须重启
```
