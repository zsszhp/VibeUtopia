## 快速开始

### 5 分钟上手

1. **打开平台**：在浏览器中访问 VibeUtopia 地址
2. **输入内容**：在左侧面板粘贴待分析的文本内容
3. **选择深度**：选择分析深度（快速/标准/深度）
4. **提交分析**：点击「开始分析」按钮
5. **查看结果**：等待分析完成后，右侧面板展示完整报告

### 分析深度说明

| 深度 | 预计耗时 | 适用场景 |
|------|----------|----------|
| 快速 | ~1分钟 | 初步筛查，快速判断 |
| 标准 | ~3分钟 | 日常审核，全面评估 |
| 深度 | ~10分钟 | 重要内容，深度分析 |
| 大规模仿真 | ~30分钟 | 高风险内容，大规模推演 |

## 文本分析流程

### 步骤

1. 在左侧面板选择「文本」输入模式
2. 将待审核的文本内容粘贴到输入框
3. （可选）选择目标平台，如微博、抖音、B站等
4. 选择分析深度
5. 点击「开始分析」

### 分析过程

提交后，系统会依次执行5个步骤：

| 步骤 | 说明 | 进度 |
|------|------|------|
| 内容理解 | 解析文本结构和语义 | 0% |
| 风险评估 | 11维风险评分 | 30% |
| 信号采集 | 关联当前热点 | 50% |
| 仿真推演 | 模拟平台反应 | 70% |
| 报告生成 | 汇总分析结果 | 90% |

您可以通过 WebSocket 实时查看进度更新。

## 视频分析流程

### 步骤

1. 在左侧面板选择「视频」输入模式
2. 上传视频文件（支持 mp4/mov/avi/webm，最大 100MB）
3. 等待上传完成
4. 选择分析深度
5. 点击「开始分析」

### 视频分析包含

- **关键帧提取**：自动提取视频关键画面
- **OCR 文字识别**：识别画面中的文字内容
- **音频转写**：将视频中的语音转为文字
  - 本地 Whisper 模型（默认）
  - 阿里 Paraformer 云端转写（需配置 API Key）
- **画面风险评估**：检测画面中的视觉风险
- **交叉风险检测**：文本、画面、音频之间的矛盾和冲突

## 混合输入分析

选择「混合」模式可同时提交文本和视频：

1. 在文本框中输入或粘贴文本内容
2. 同时上传视频文件
3. 系统会将文本内容与视频提取的内容合并分析
4. 自动检测跨模态的风险冲突

## 分析结果解读

### 11 维风险评估

系统从 11 个维度对内容进行风险评分：

**红线维度（触碰即高风险）**

| 维度 | 说明 |
|------|------|
| 政治敏感 | 涉政人物、领土主权、外交红线、政治体制批评 |
| 法律合规 | 广告法违规、侵权、虚假宣传、法律红线 |
| 民族宗教 | 民族歧视、宗教冒犯、文化禁忌 |
| 事实错误 | 医疗谣言、科学谬误、虚假信息 |
| 平台禁区 | 规避审核手段、平台规则漏洞 |

**高敏感维度**

| 维度 | 说明 |
|------|------|
| 性别议题 | 性别对立、物化歧视、刻板印象强化 |
| 群体冒犯 | 地域歧视、职业歧视、年龄歧视、群体标签化 |
| 道德伦理 | 违背公序良俗、主流价值观冲突 |
| 时事踩雷 | 不当蹭热点、关联翻车事件 |

**动态维度**

| 维度 | 说明 |
|------|------|
| 情绪极化 | 煽动仇恨、制造对立、极端言论 |
| 价值观倾向 | 历史虚无主义、拜金主义、反社会倾向 |

### 风险等级

| 等级 | 颜色 | 分数范围 | 含义 |
|------|------|----------|------|
| 低风险 | 🟢 绿色 | 0-25 | 内容安全，可正常发布 |
| 中等风险 | 🟡 黄色 | 26-55 | 存在轻微风险，建议关注 |
| 高风险 | 🟠 橙色 | 56-75 | 风险较高，建议修改 |
| 极高风险 | 🔴 红色 | 76-100 | 风险极高，强烈建议修改或不发布 |

### 置信度

置信度反映分析结果的可信程度：

- **0.8-1.0**：高置信度，结果可靠
- **0.6-0.8**：中等置信度，结果基本可信
- **0.4-0.6**：低置信度，建议人工复核

### 不确定性来源

当置信度较低时，系统会标注不确定性来源：

- 转写质量不佳
- 评估维度不完整
- 证据不充分
- 平台数据缺失

## 改写建议使用

### 功能说明

系统针对检测到的风险项，提供具体的改写建议：

- **原文**：标记的风险文本
- **建议**：修改后的安全文本
- **维度**：对应的风险维度

### 使用建议

1. 优先处理高风险维度的改写建议
2. 改写后可重新提交分析验证效果
3. 结合反事实仿真评估改写效果

## 仿真推演功能

### 功能说明

通过 Agent 仿真模拟内容发布后的传播过程：

- **Agent 数量**：根据仿真规模级别确定
- **传播阶段**：种子期 → 一级传播 → 社区扩散 → 极化 → 主流化 → 衰退
- **输出结果**：传播路径、情感分布、关键影响者

### 仿真规模

| 级别 | Agent 数 | 等效个体 | 适用场景 |
|------|----------|----------|----------|
| 轻量 | 10 | 1万 | 快速预判 |
| 标准 | 50 | 5万 | 常规分析 |
| 深度 | 200 | 20万 | 重要内容 |
| 大规模 | 500+ | 50万+ | 高风险内容 |

## 极化趋势解读

### 极化指数

极化指数反映内容可能引发的对立程度：

| 范围 | 等级 | 含义 |
|------|------|------|
| 0-0.3 | 低 | 讨论较为理性 |
| 0.3-0.6 | 中 | 出现分歧 |
| 0.6-0.8 | 高 | 明显对立 |
| 0.8-1.0 | 极高 | 严重极化 |

### 趋势方向

- **上升**：极化程度在加剧
- **稳定**：极化程度保持不变
- **下降**：极化程度在缓解

## 热点关联说明

### 功能说明

系统自动将待分析内容与当前各平台热点进行关联：

- **关联分数**：内容与热点的相关程度（0-1）
- **风险加成**：关联热点可能带来的额外风险
- **热点来源**：关联热点的平台和标题

### 使用场景

- 了解内容是否踩中当前敏感热点
- 评估热点叠加效应带来的额外风险
- 为发布时机选择提供参考

## 博主画像功能

### 功能说明

对博主的发布历史进行风险画像分析：

- **风险容忍度**：博主整体的风险偏好
- **风险模式**：风险变化的规律（稳定型/波动型/上升型）
- **高风险维度**：博主容易触发风险的维度
- **趋势预测**：未来风险走势预判
- **维度变化**：各维度的变化趋势和速率

### 使用方式

1. 输入博主 ID
2. 系统分析该博主的历史分析记录
3. 生成风险画像和趋势预测

---

## 竞品对比功能

### 功能说明

将博主与同领域竞品进行风险维度对比：

- **维度对比**：各风险维度的分数对比
- **领域均值**：同领域的平均风险水平
- **相对位置**：博主在领域中的风险排名
- **优势/劣势**：风险维度的优劣势分析
- **差异化建议**：基于对比结果的改进建议

### 使用方式

1. 输入博主 ID
2. 输入竞品 ID 列表
3. 指定所属领域
4. 查看对比分析报告

## 反事实仿真

### 功能说明

模拟修改内容后的风险变化：

1. 选择修改策略：
   - **删除**：直接删除风险句子
   - **替换**：用安全表述替换
   - **软化**：降低表述强度
   - **改写**：重新组织表达
2. 系统自动生成修改后的文本
3. 对比修改前后的风险分数变化
4. 给出修改建议和预估效果

### 使用场景

- 评估不同修改策略的效果
- 选择最优修改方案
- 量化修改带来的风险降低

## 决策辅助

### 功能说明

基于风险评估报告，提供发布决策建议：

| 建议类型 | 说明 |
|----------|------|
| 直接发布 | 风险低，可直接发布 |
| 条件发布 | 修改指定内容后可发布 |
| 建议修改 | 风险较高，建议修改后再评估 |
| 不建议发布 | 风险极高，不建议发布 |

### 决策报告包含

- **修改优先级**：按优先级排列的修改建议
- **预估效果**：修改后的预期风险降低
- **关键风险因素**：主要的风险驱动因素
- **决策推理**：建议的推理过程

## 设置配置

### 模型配置

在设置面板中可以：

1. **查看当前硬件层级**：Lite/Standard/Pro/Ultra
2. **查看推荐模型**：根据硬件自动推荐
3. **切换模型**：手动覆盖使用的模型
4. **查看 Key 池状态**：各厂商 API Key 的使用情况

### 信号采集配置

1. **启动/停止调度器**：控制信号采集的运行
2. **选择调度模式**：
   - 实时模式：高频采集
   - 标准模式：常规采集
   - 经济模式：低频采集
   - 手动模式：仅手动触发

### 本地模型配置

1. **检测 Ollama**：检测本地是否安装 Ollama
2. **检测 vLLM**：检测本地是否运行 vLLM 服务
3. **下载模型**：一键下载推荐的本地模型
4. **缓存管理**：查看和清理模型缓存

### 知识图谱配置

1. **查看图谱状态**：Neo4j 连接状态和统计信息
2. **浏览图谱**：可视化查看知识图谱
3. **实体搜索**：搜索图谱中的实体
4. **路径查询**：查询两个实体间的关系路径
