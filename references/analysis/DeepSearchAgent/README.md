# DeepSearchAgent-Demo

## 项目信息

- **仓库**: https://github.com/666ghj/DeepSearchAgent-Demo
- **许可证**: MIT
- **领域**: 深度搜索、工具调用

## 项目定位

纯LLM驱动的深度搜索Agent，无Agent框架依赖。通过迭代搜索策略（初搜→分析→深搜），使用工具自适应选择（搜索/代码/推导），实现精准信息获取。

## 核心架构

```
初搜 ──▶ 分析 ──▶ 深搜
  │         │         │
选择工具  评估充足性  调整策略
```

## 精华借鉴

| 精华项 | 说明 |
|--------|------|
| 无框架设计 | 纯LLM驱动，无外部框架依赖，极简 |
| 迭代搜索策略 | 初搜→分析→深搜，逐步逼近答案 |
| 工具自适应选择 | LLM根据上下文自主决定使用哪个工具 |

## 采纳决策

| 项 | 决策 | 目标阶段 |
|----|------|---------|
| 迭代搜索策略 | 采纳 | 1-2 |
| 工具自适应选择 | 采纳 | 3-4 |
| 无框架纯LLM驱动 | 不采纳 | - |
| 无持久化状态 | 不采纳 | - |
