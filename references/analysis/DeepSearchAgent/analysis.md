# DeepSearchAgent 深度分析

## 核心实现

### 迭代搜索策略

```
初搜 ──▶ 分析 ──▶ 深搜
  │         │         │
选择工具  评估充足性  调整策略
```

1. **初搜**：根据查询生成搜索词，选择合适的搜索工具
2. **分析**：评估搜索结果，判断信息是否充足
3. **深搜**：基于分析结果调整搜索策略，深入挖掘

### 工具自适应选择

- 根据当前任务阶段自动选择工具
- 搜索工具：web_search（国内+国际）
- 代码工具：code_execution
- 推导工具：reasoning

### 节点流水线

（与BettaFish共享）
```
FirstSearchNode → FirstSummaryNode → ReflectionNode → ReflectionSummaryNode → ReportFormattingNode
```

## 精华与糟粕

| 类别 | 内容 | 说明 |
|------|------|------|
| **精华** | 无框架设计 | 纯LLM驱动，无外部框架依赖，极简 |
| **精华** | 迭代搜索策略 | 初搜→分析→深搜，逐步逼近答案 |
| **精华** | 工具自适应选择 | LLM根据上下文自主决定使用哪个工具 |
| **糟粕** | 无持久化状态 | 搜索间无记忆，无法积累知识 |
| **糟粕** | 工具定义硬编码 | 不可扩展，新增工具需改代码 |
| **糟粕** | 无并行搜索 | 串行执行，效率低 |

## 改进项

| 改进项 | 改进方式 |
|--------|----------|
| 无记忆→有记忆 | 集成Memory Stream记忆系统 |
| 硬编码→可配置 | 工具定义外部化（YAML配置） |
| 串行→并行 | 支持多个搜索Agent并行工作 |
