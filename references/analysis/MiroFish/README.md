# MiroFish

## 项目信息

- **仓库**: https://github.com/666ghj/MiroFish
- **许可证**: AGPL-3.0
- **领域**: 多Agent仿真、知识图谱

## 项目定位

基于OASIS框架构建的平行数字世界仿真系统。使用Zep Cloud知识图谱从种子文档构建世界模型，生成具备独立人格的Agent，在模拟的Twitter/Reddit平台上进行社交互动，最终通过AI分析仿真结果提取趋势。

## 核心架构

```
阶段1: 图谱构建 ──▶ 阶段2: 环境配置 ──▶ 阶段3: 仿真运行 ──▶ 阶段4: 结果分析 ──▶ 阶段5: 可视化
(GraphBuilder)      (SimManager)       (OASIS Engine)      (AI Analyzer)      (Dashboard)
```

## 精华借鉴

| 精华项 | 说明 |
|--------|------|
| 知识图谱驱动的世界构建 | 从种子文档自动构建世界模型，Agent从实体生成 |
| LLM增强的人格生成 | 不仅是填表，而是LLM推理出有深度的人格描述 |
| LLM驱动的仿真配置 | 自动生成时间/事件/活动配置，减少人工设计 |
| 双平台并行仿真 | 同时模拟Twitter和Reddit，覆盖不同社交模式 |
| 中国时区感知的时间模型 | 按中国用户作息分配活跃度 |
