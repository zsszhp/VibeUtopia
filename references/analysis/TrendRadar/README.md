# TrendRadar

## 项目信息

- **仓库**: https://github.com/sansan0/TrendRadar
- **许可证**: GPL-3.0
- **领域**: 信号采集、舆情监控

## 项目定位

定时新闻聚合 + AI分析管道，通过 NewsNow 代理API聚合11+平台热搜，结合RSS补充源，使用LiteLLM进行5维度热点分析，支持多渠道推送。

## 核心架构

```
[定时调度器] ──▶ [热榜爬虫 DataFetcher] ──▶ [增量检测] ──▶ [AI分析器] ──▶ [多渠道推送]
                    │                                        │
              [RSS爬虫 RssFetcher] ──────────────────────▶│
```

## 精华借鉴

| 精华项 | 说明 |
|--------|------|
| NewsNow API统一聚合 | 一个API覆盖11+平台，零维护成本 |
| 增量检测+排名时间线 | 精确追踪热点生命周期 |
| LiteLLM多模型接口 | 100+模型统一调用，自带fallback |
| 时间线调度系统 | 灵活可配置，覆盖多种使用场景 |
| 3阶段JSON解析降级 | 健壮的LLM输出处理 |
