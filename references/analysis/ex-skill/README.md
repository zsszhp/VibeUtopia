# ex-skill

## 项目信息

- **仓库**: https://github.com/perkfly/ex-skill
- **许可证**: MIT
- **领域**: 人格构建、用户画像

## 项目定位

从用户真实聊天记录中提取人格特征，构建5层人格结构（基础属性→价值观→知识背景→行为模式→纠偏层），实现人格量化与存储。

## 核心架构

```
Layer 1: 基础属性
├── 年龄、性别、地域、职业、收入、学历

Layer 2: 价值观
├── 政治倾向、社会立场、消费观、教育观

Layer 3: 知识背景
├── 专业领域、信息来源、认知盲区

Layer 4: 行为模式
├── 发帖习惯、互动风格、活跃时段、表达偏好

Layer 5: 纠偏层
├── 行为边界、自我约束、避免行为、冲突处理策略
```

## 精华借鉴

| 精华项 | 说明 |
|--------|------|
| 5层人格分层设计 | 结构清晰，从基础到高级逐层递进 |
| 从真实数据提取人格 | 基于真实行为而非凭空编造 |
| 人格量化与存储 | 可计算、可比较、可持久化 |
