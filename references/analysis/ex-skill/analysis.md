# ex-skill 深度分析

## 核心实现：5层人格结构

```
Layer 1: 基础属性
├── 年龄、性别、地域、职业、收入、学历

Layer 2: 价值观
├── 政治倾向、社会立场、消费观、教育观

Layer 3: 知识背景
├── 专业领域、信息来源、认知盲区

Layer 4: 行为模式
├── 发帖习惯、互动风格、活跃时段、表达偏好

Layer 5: 纠偏层
├── 行为边界、自我约束、避免行为、冲突处理策略
```

## 人格提取流程

1. 输入：用户聊天记录
2. LLM分析：提取各层特征
3. 量化：将特征转化为结构化数据
4. 存储：持久化人格Profile

## 精华与糟粕

| 类别 | 内容 | 说明 |
|------|------|------|
| **精华** | 5层人格分层设计 | 结构清晰，从基础到高级逐层递进 |
| **精华** | 从真实数据提取人格 | 基于真实行为而非凭空编造 |
| **精华** | 人格量化与存储 | 可计算、可比较、可持久化 |
| **糟粕** | 依赖单一数据源 | 仅从聊天记录提取，维度有限 |
| **糟粕** | 层间权重固定 | 无法动态调整各层对行为的影响 |
| **糟粕** | 无人格演化机制 | 生成后即固化，不随时间/事件变化 |

## 改进项

| 改进项 | 改进方式 |
|--------|----------|
| 5层→7层 | 增加社会关系层+动态演化层 |
| 单一数据源→多数据源 | 聊天+评论+图谱+统计数据 |
| 固定权重→动态权重 | 基于场景动态调整各层影响力 |
| 无演化→有演化 | 新增动态演化层，支持态度偏移和事件影响 |
