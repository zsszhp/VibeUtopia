# ex-skill 深度技术分析

> 基于 5层人格结构系统

---

## 1. 项目概述

- **Star数**: 少量
- **主要语言**: Python
- **License**: 未明确
- **一句话描述**: 基于5层人格结构的用户画像提取系统，通过LLM分析用户聊天记录，提取从基础属性到行为模式的完整人格Profile

### 1.1 核心思想

ex-skill的核心理念是：**用户的人格可以通过其聊天记录被系统化地提取和建模**。这类似于心理学中的人格测评，但完全基于用户的自然语言行为数据。

---

## 2. 5层人格结构详解

### 2.1 Layer 1: 基础属性

```
年龄、性别、地域、职业、收入、学历
```

**提取方法**: 从用户的直接表述中推断
- "我今年28岁" → 年龄=28
- "我在北京工作" → 地域=北京
- "我是程序员" → 职业=程序员

**特点**: 最容易提取，准确性最高

### 2.2 Layer 2: 价值观

```
政治倾向、社会立场、消费观、教育观
```

**提取方法**: 从用户对社会话题的态度推断
- 对特定政策的支持/反对 → 政治倾向
- 对消费行为的态度 → 消费观（节俭/享乐/理性）

**特点**: 需要较多上下文，可能有偏差

### 2.3 Layer 3: 知识背景

```
专业领域、信息来源、认知盲区
```

**提取方法**: 从用户谈论的话题和知识深度推断
- 频繁讨论某个领域 → 专业领域
- 引用的信息来源 → 信息来源偏好
- 明显误解的话题 → 认知盲区

**特点**: 帮助理解用户的知识结构和信息获取习惯

### 2.4 Layer 4: 行为模式

```
发帖习惯、互动风格、活跃时段、表达偏好
```

**提取方法**: 从用户的行为数据推断
- 发帖频率和时间 → 活跃时段
- 回复他人的方式 → 互动风格（友善/对抗/中立）
- 用词习惯 → 表达偏好（正式/口语/专业）

**特点**: 最容易被行为数据验证

### 2.5 Layer 5: 纠偏层

```
行为边界、自我约束、避免行为、冲突处理策略
```

**提取方法**: 从用户在冲突场景中的选择推断
- 遇到争议时的反应 → 冲突处理策略
- 主动回避的话题 → 避免行为
- 自我审查的迹象 → 行为边界

**特点**: 最高层，决定Agent的行为安全边界

## 3. 人格提取流程

```
用户聊天记录 → LLM分析 → 特征提取 → 量化 → 结构化 → 持久化
```

### 3.1 Prompt设计

```
请分析以下用户聊天记录，提取用户的5层人格特征：

Layer 1 - 基础属性: 年龄、性别、地域、职业、收入、学历
Layer 2 - 价值观: 政治倾向、社会立场、消费观、教育观
Layer 3 - 知识背景: 专业领域、信息来源、认知盲区
Layer 4 - 行为模式: 发帖习惯、互动风格、活跃时段、表达偏好
Layer 5 - 纠偏层: 行为边界、自我约束、避免行为、冲突处理策略

聊天记录:
{messages}

请以JSON格式输出各层特征。
```

### 3.2 量化策略

每个特征需要量化为结构化数据：
- **类别特征**: 使用枚举值（如政治倾向: 左/中/右）
- **数值特征**: 使用0-1分数（如收入水平: 0.3=低收入, 0.7=高收入）
- **文本特征**: 保留原始描述

## 4. 与VibeUtopia项目的深度关联

### 4.1 Agent人格系统设计

ex-skill的5层结构可以直接作为VibeUtopia Agent人格系统的设计参考：

| ex-skill层级 | VibeUtopia Agent对应 | 用途 |
|-------------|---------------------|------|
| Layer 1 基础属性 | Agent基本档案 | 身份定义 |
| Layer 2 价值观 | Agent价值体系 | 决策倾向 |
| Layer 3 知识背景 | Agent知识库 | 能力范围 |
| Layer 4 行为模式 | Agent行为风格 | 交互方式 |
| Layer 5 纠偏层 | Agent安全边界 | 行为约束 |

### 4.2 用户人格提取

VibeUtopia可以借鉴ex-skill的方法，从用户的社交数据中提取人格Profile：
- 分析用户在各平台的发帖记录
- 提取5层人格特征
- 构建用户数字孪生（Digital Twin）
- 用于个性化内容推荐和社交仿真

### 4.3 人格演化

ex-skill的静态提取可以扩展为动态演化：
- 定期重新提取人格特征
- 追踪人格变化轨迹
- 检测异常行为（人格突变）

### 4.4 人格驱动的Agent行为

```
用户人格Profile → Agent人格参数 → Agent行为决策
```

例如：
- 高"政治倾向"分数 → Agent更积极地参与政治话题讨论
- 高"冲突处理策略"分数 → Agent在争议中更倾向于妥协
- 低"行为边界"分数 → Agent需要更强的纠偏约束

---

## 5. 精华与糟粕

### 5.1 精华

1. **系统化的人格分层**: 从浅到深，从稳定到易变
2. **可操作的量化方案**: 每层都有明确的量化方法
3. **纠偏层设计**: 独特的安全边界层，防止Agent行为失控
4. **LLM驱动**: 利用LLM的理解能力，无需手动规则

### 5.2 糟粕

1. **层级间耦合**: 各层之间可能有重叠（如价值观影响行为模式）
2. **文化偏差**: 5层结构可能不适用于所有文化背景
3. **隐私问题**: 从聊天记录提取人格涉及隐私
4. **静态快照**: 人格是动态变化的，单次提取不准确

---

## 6. 总结

ex-skill的5层人格结构是一个简洁而全面的用户建模框架。对于VibeUtopia，其最大价值在于提供了一个**从基础属性到行为约束的完整人格建模方案**，可以直接指导Agent人格系统的设计。
