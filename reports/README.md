# VibeUtopia 报告目录

## 目录结构

```
reports/
  analysis/    # 深度分析报告（每次批量分析的完整结果）
  summary/     # 分析质量评估汇总（评分、问题、优化方向）
```

## 文件命名规范

格式：`{日期}-{简短描述}.md`

示例：
- `2026-05-07-八案例深度分析报告.md`
- `2026-05-07-分析质量评估汇总.md`
- `2026-05-08-评分稳定性验证报告.md`

## 报告类型说明

| 类型 | 目录 | 内容 | 产出时机 |
|------|------|------|----------|
| 深度分析 | `analysis/` | 每个案例的评分、风险维度、Agent反应、交叉效应、改写建议 | 每次批量测试后 |
| 质量评估 | `summary/` | 汇总评分对比、系统优劣势、待改进问题、下步优化方向 | 每轮迭代后 |
