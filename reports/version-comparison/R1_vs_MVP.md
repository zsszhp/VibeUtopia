# V2.R1 vs MVP 版本对比报告

> 仿真增强风控 vs 静态Prompt风控

## 功能对比

| 功能 | MVP | V2.R1 | 改进 |
|------|-----|-------|------|
| 风险评估 | 4个静态Prompt | 7维评估 + 热点关联 + 实体风险链 | 多维度增强 |
| 热点关联 | 无 | 文案关键词 ↔ 当前热点事件匹配 | 新增 |
| 实体风险链 | 无 | 命名实体 → 知识图谱 → 争议事件追踪 | 新增 |
| 动态权重 | 固定权重 | 基于热点热度动态调整7维权重 | 新增 |
| 仿真增强 | 无(仅静态人格模拟) | 100Agent × 6h 轻量仿真(可选) | 新增 |
| 可信度标注 | 无 | 多源可信度标注(基线+信号+实体+仿真) | 新增 |
| 评估模式 | 单一模式 | quick(快速)/deep(深度仿真) | 新增 |
| API | /analyze | /analyze/v2 + /risk/context + /entities/{name}/risk-chain | 新增3个端点 |

## 性能对比

| 指标 | MVP | V2.R1(quick) | V2.R1(deep) |
|------|-----|-------------|-------------|
| 分析耗时 | ~30秒 | ~45秒 | ~5分钟 |

## 量化评估

- 评估维度扩展: 7维 → 7维 + 热点关联 + 实体风险链 (+2个增强维度)
- 新增功能: 4项（信号关联、实体风险链、动态权重、可信度标注）
- API端点: 1个 → 4个 (+3个)
- 用户体验: 单一评估 → 快速/深度双模式

## Go/No-Go 判定

- **条件**: 仿真风控比MVP准确率提升>15%
- **当前状态**: 待实测验证（需运行测试脚本获取实际数据）
- **预判**: 信号关联和实体风险链可提供显著增强，deep模式仿真需验证成本效益
