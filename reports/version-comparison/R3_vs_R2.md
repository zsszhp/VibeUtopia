# V2.R3 vs V2.R2 版本对比报告

> 趋势预测与决策辅助 - 核心价值交付

## 功能对比

| 功能 | V2.R2 | V2.R3 | 改进 |
|------|-------|-------|------|
| 趋势预测 | 无 | 4阶段预测引擎 | 新增(核心价值) |
| 舆论模式 | 无 | 5种模式分类 | 新增 |
| 反事实仿真 | 无 | 创建分支+注入干预+对比 | 新增 |
| 报告生成 | 无 | 4类报告(风控/仿真/趋势/决策) | 新增 |
| 仿真共识 | 无 | 3-5次仿真取共识+不确定性标注 | 新增 |
| 决策建议 | 无 | 4级风险等级+行动建议 | 新增 |
| API端点 | 5个R2端点 | +9个R3端点 | +9个 |

## 趋势预测能力

| 时间范围 | 置信度目标 | 预测维度 |
|----------|-----------|----------|
| 短期(1-6h) | 0.7-0.9 | 方向+幅度+关键转折点 |
| 中期(1-3天) | 0.5-0.7 | 方向+概率分布+不确定性 |
| 长期(1-2周) | 0.3-0.5 | 大致方向+关键变量 |

## 5种舆论模式

| 模式 | 特征 | 典型场景 |
|------|------|----------|
| 快速爆发型 | 上榜快、情感强、多平台共振 | 突发丑闻、明星塌房 |
| 缓慢升温型 | 缓慢升温、多轮讨论 | 社会议题、政策讨论 |
| 争议分裂型 | 两方对立、情绪升温 | 性别话题、地域话题 |
| 短暂热度型 | 快速上榜、快速消退 | 娱乐八卦、小趣闻 |
| 持续发酵型 | 持续上榜、新角度不断 | 政策争议、社会事件 |

## Go/No-Go 判定

- **条件**: 短期预测方向准确率>65%
- **状态**: 待实测
- **降级方案**: 55-65% → 降低预测粒度+增加不确定性标注
