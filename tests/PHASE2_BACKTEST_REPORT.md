## 限制与问题

### 1. API 配额限制
- **问题**: LongCat API Key 在测试过程中多次触发 429 限流
- **影响**: 5 个案例未完成（25 个中的 20%）
- **解决**: 等待配额恢复后重试剩余案例

### 2. 数据库表缺失
- **问题**: `signal_records` 表不存在
- **影响**: 信号关联功能降级，无法利用热点事件增强风险评估
- **解决**: 运行信号采集脚本初始化数据

### 3. Red 类识别准确率偏低
- **问题**: 50% 的 Red 类被识别为 Orange
- **原因**: 风险评估阈值设置偏保守
- **优化建议**: 调整红线维度权重或降低 HIGH 阈值
