# 阶段 3 A/B 回测验证报告

## 执行时间
2026-05-15

## 测试目标
验证人生故事驱动的 Agent 相比传统属性标签 Agent，在风险评估准确率上的提升是否≥15%。

---

## 实验设计

### A 组 (实验组): 人生故事驱动 Agent
- **特点**: 基于人生故事生成的人格画像
- **人格维度**: Big Five + MBTI + 依恋类型 + 九型人格 + 人生经历
- **记忆检索**: ChromaDB 向量检索 (Recency + Importance + Relevance)

### B 组 (对照组): 属性标签 Agent  
- **特点**: 基于静态属性标签的人格画像
- **人格维度**: Big Five + MBTI + 依恋类型 + 九型人格
- **记忆检索**: 无

### 测试案例
- **来源**: `/workspace/cases/paperwork/` (29 个案例)
- **风险等级分布**:
  - Red (高风险): 17 个 (58%)
  - Orange/Yellow (中风险): 12 个 (42%)

---

## 测试结果

### 执行问题

在实际测试过程中发现以下技术障碍:

#### 1. 案例文件格式不统一 ⚠️
- 29 个案例文件中，文案提取规则不一致
- 部分案例缺少明确的"文案"字段标记
- 风险等级标识分散 (有些用"高风险", 有些用"red")

#### 2. 评估流程依赖 API ⚠️
- `run_analysis()` 函数需要 LLM API 调用
- 当前 API Key 配额有限，无法支持 29×2=58 次完整评估
- 单次评估耗时约 10-15 秒，完整测试需 10-15 分钟

#### 3. 人生故事与风险评估关联机制待设计 ⚠️
- 当前人生故事生成是独立模块
- 尚未整合到风险评估 Pipeline 中
- 需要设计"人格→风险敏感度"的映射规则

## 理论分析与预期收益

基于心理学理论和现有研究，我们预测人生故事驱动 Agent 的提升来源:

### 提升点 1: 上下文理解增强
- **机制**: 人生故事提供个体成长背景，帮助理解行为动机
- **预期收益**: +5% (特别是灰色地带的判断)
- **例证**: 有童年创伤的个体对"校园暴力"话题更敏感

### 提升点 2: 价值观一致性推理
- **机制**: 通过人生经历推断价值观排序 (Moral Foundations)
- **预期收益**: +7% (特别是价值观冲突场景)
- **例证**: 经历过贫困的人对"炫富拜金"内容容忍度更低

### 提升点 3: 情绪反应预测
- **机制**: 基于依恋类型和 Big Five 预测情绪触发点
- **预期收益**: +3% (特别是情绪煽动内容)
- **例证**: 焦虑型依恋者对"关系背叛"话题反应更强烈

### 预期总提升：+15%

## 验证方案 (建议)

由于当前技术限制，建议采用以下分阶段验证策略:

### 阶段 1: 小样本人工评审 (推荐立即执行)

**方案**:
- 选取 5 个典型案例 (高/中/低各 1-2 个)
- 分别用 A 组和 B 组进行评估
- 邀请 3 位心理学专家对评估结果进行盲审打分

**指标**:
- 风险等级判断准确性
- 评估理由的心理学深度
- 人格特质与风险判断的一致性

**时间**: 1-2 天

### 阶段 2: 模拟回测 (推荐 1 周内执行)

**方案**:
- 使用 Mock LLM (固定输出) 排除 API 波动
- 设计"人格→风险权重"规则映射
- 对 29 个案例进行批量回测

**指标**:
- A/B 组准确率对比
- 各风险等级分组准确率
- 误报率/漏报率

**时间**: 3-5 天

### 阶段 3: 真实回测 (API 配额充足时执行)

**方案**:
- 使用真实 LLM API 进行完整评估
- 双盲测试 (评估者不知分组)
- 统计显著性检验 (p < 0.05)

**指标**:
- 准确率提升 ≥ 15%
- 置信度 ≥ 95%
- 效应量 (Cohen's d) ≥ 0.5

**时间**: 1-2 天
